# Spec：农屿官网 · 功能介绍分区改造

| 关联 Spec | `docs/nongyu-web-site/specs/品牌官网落地页.md`（本轮修订其「功能」段） |

## 1. 背景

官网落地页已上线（Hero + 六功能 GIF 块 + 下载 + 联系）。现已备齐竖屏产品截图（`apps/nongyu-web-site/assets/`），需将功能介绍改为「分区 + 手机竖屏图 + 可编辑文案占位」，多图分区支持左右滑动切换；文案由产品方后续亲自填写。

## 2. 目标

1. 功能介绍改为 **6 个分区**（产品介绍 + 五大能力），媒体统一 **手机竖屏比例（约 9:16）**。
2. 多图分区（课表 / 二课 / Agent）支持 **拖滑切换 + 圆点指示**；无自动轮播。
3. 各分区文案区为 **明显占位符**，便于产品方对照位置填写，不阻塞布局交付。
4. 保留现有 Hero、下载、联系、页脚行为与视觉基调（川农新绿）；去掉「主题与个性化」展示块。

## 3. 边界（非目标）

- 不改下载 / 联系 / 页脚业务逻辑与配置契约（`downloadAndroidUrl` 等）
- 不改 Hero 品牌主张与主 CTA 语义（仍保留独立首屏）
- 不使用 `course2.mp4`（本轮仅 jpg）
- 不做自动轮播、不做视频播放器
- 不写死最终营销文案（占位即可）
- 不做多路由内容站、不做 CMS
- 本轮 **跳过** 独立技术方案文档（`tech/`）；确认 Spec 后写实施计划并编码

## 4. 详细需求

### 4.1 信息架构（相对既有落地页的变更）

| 区块               | 变更说明                                                             |
| ------------------ | -------------------------------------------------------------------- |
| Hero `#hero`       | **保留**；不塞产品截图                                               |
| 功能 `#features`   | **重做**：其下 6 个子分区（见 §4.2）；顶栏「功能」仍锚到 `#features` |
| 下载 / 联系 / 页脚 | **保留**                                                             |
| 主题与个性化       | **删除**该展示块                                                     |

### 4.2 功能分区（顺序固定）

| #   | 分区 ID（建议）   | 标题（展示用，可微调用词） | 媒体资源（相对 `assets/`，实现时拷至可静态服务路径如 `public/features/`） | 媒体形态 |
| --- | ----------------- | -------------------------- | ------------------------------------------------------------------------- | -------- |
| 1   | `#feature-intro`  | 认识农屿                   | `home.jpg`                                                                | 单图     |
| 2   | `#feature-jiaowu` | 教务功能                   | `jiaowu1.jpg`                                                             | 单图     |
| 3   | `#feature-course` | 课表功能                   | `course1.jpg` … `course5.jpg`（按序号）                                   | 多图轮播 |
| 4   | `#feature-second` | 二课功能                   | `second1.jpg` … `second3.jpg`                                             | 多图轮播 |
| 5   | `#feature-agent`  | Agent 功能                 | `agent1.jpg`、`agent2.jpg`                                                | 多图轮播 |
| 6   | `#feature-plaza`  | 广场功能                   | `center.jpg`                                                              | 单图     |

说明：分区标题用于 UI 与占位；最终介绍正文由产品方填写，本轮用占位文案（§4.4）。

### 4.3 版式与媒体窗

- **桌面**：奇数块「左文右媒」，偶数块「左媒右文」（与现站交替逻辑一致）
- **移动**：一律「上文下媒」
- **媒体窗**：统一约 **9:16** 竖屏「圆角设备窗」（对齐设计准则 Signature）；`object-fit: cover`（或 contain，全站统一一种，优先 cover 填满窗）
- 单图 / 轮播外框尺寸契约一致，避免切换时布局跳动
- 图片缺失时：保持窗尺寸，显示轻量占位（标题 +「图片占位」），**不得破版**

同步更新 `design-system/web-site/MASTER.md`：功能区媒体宽高比由 **16/10** 改为 **9/16**。

### 4.4 文案占位

每个分区文案区至少包含：

- 分区标题（可用上表标题）
- **正文占位**一行或多行，文案须一眼可辨为待填，例如：  
  `【待填写：认识农屿 · 产品介绍】`、`【待填写：教务功能介绍】` 等（与分区一一对应）
- 正文占位通过配置（如 `site-config`）集中管理，便于产品方后续只改配置/文案字段

禁止：用旧 GIF 版长文案冒充已完稿终稿（避免误以为已定稿）。

### 4.5 多图轮播（课表 / 二课 / Agent）

| 项     | 要求                                                                          |
| ------ | ----------------------------------------------------------------------------- |
| 切换   | 支持触摸左右滑动、鼠标拖滑（或等价 pointer 拖动）切换当前图                   |
| 指示   | 圆点指示当前页；点击圆点可跳转                                                |
| 自动播 | **禁止**自动轮播                                                              |
| 无障碍 | 轮播区域有合适 `aria`（如区域标签、当前页状态）；尊重减少动态效果时可弱化过渡 |
| 范围   | 仅多图分区启用；单图分区无圆点、无滑动手势必要                                |

不要求左右箭头按钮（可选增强，非本轮必做）。

### 4.6 资源与配置

- 源文件位于 `apps/nongyu-web-site/assets/`；构建可访问路径由实现放入 `public/`（或 Vite 静态约定），Spec 不绑定目录名，但 **文件名与分组** 以上表为准
- `course2.mp4`：**不引用、不展示**
- 配置结构建议由「单 gif 字段」演进为：`images: string[]`（长度 1 = 单图；>1 = 轮播）+ `description`（占位正文）

### 4.7 视觉与动效（继承）

- 色板、字体、顶栏、进入显现、CTA hover、`prefers-reduced-motion`：继承《品牌官网落地页》Spec 与 `MASTER.md`
- 轮播切换允许短位移/淡入；减少动态效果开启时改为瞬时切换或极短过渡

### 4.8 不变更项

- Hero 文案与 CTA、下载双端行为、联系复制、页脚署名与版权年
- 无登录、无服务端业务耦合

## 5. 业务流程

```text
访问官网
  → Hero 建立品牌认知
  → 进入 #features：自上而下浏览 6 分区
      → 单图区：阅读占位文案 + 竖屏截图
      → 多图区：左右滑动 / 点圆点切换截图
  → 下载 / 联系（行为不变）
```

---

## 6. 验收标准与测试方案

1. **Hero**：仍无产品截图挤占首屏；品牌权重最高。
2. **分区顺序**：认识农屿 → 教务 → 课表 → 二课 → Agent → 广场；无「主题与个性化」。
3. **竖屏**：六区媒体窗视觉比例均为手机竖屏（约 9:16），非 16:10 横幅。
4. **资源**：`home` / `jiaowu1` / `course1–5` / `second1–3` / `agent1–2` / `center` 正确展示；无 mp4。
5. **轮播**：课表 5 张、二课 3 张、Agent 2 张可滑动切换；圆点与当前页一致；无自动播放。
6. **文案**：各区正文为「【待填写：…】」类占位，可后续只改正文配置。
7. **响应式**：桌面交替、移动堆叠；窄屏可完成滑动与复制/下载原流程。
8. **减少动态效果**：开启后无长动画干扰；轮播仍可切换。

测试方式：Chrome + 窄屏人工验收；多图区分别滑至首尾页检查圆点。
