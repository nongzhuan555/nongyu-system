# Spec：农屿品牌官网落地页

| 项       | 内容                                                   |
| -------- | ------------------------------------------------------ |
| 应用     | `apps/nongyu-web-site`                                 |
| 需求类型 | **业务需求**                                           |
| PRD      | `docs/forhuman/rawprds/nongyu-web-site/农屿官网PRD.md` |
| 状态     | **已实现（待人工验收）**                               |

---

## 1. 背景

农屿客户端已具备课表、教务、二课、广场、农屿 AI 等能力，需要独立品牌官网向川农学生展示产品价值、提供下载入口与团队联系方式。旧官网可暂时并存；本 Spec 约束新落地页的 WHAT，不绑定具体框架细节（实现阶段再定）。

---

## 2. 目标

1. 交付**单页**品牌落地页，完成：认知（是什么）→ 能力（六功能）→ 行动（下载）→ 联系。
2. 视觉与 RN「川农新绿」浅色主题一致，高级简约，带克制流畅动效。
3. 功能 GIF **可替换**：开发期占位，到图后只换资源、不改布局契约。
4. 下载链接与联系文案**可配置**，避免硬编码失效外链。

---

## 3. 边界（非目标）

- 不做 App 功能在线试用 / Agent 嵌入演示
- 不做暗色 / 粉樱主题、不做主题切换
- 不做多路由内容站（文档、博客、活动 CMS）
- 不做邮箱联系、不做 ICP（本轮）
- 不做真实 iOS 分发链接（展示「即将开放」）
- 不做登录、埋点后台、与 Node 业务 API 强耦合（本轮静态/配置即可）
- 不强制本轮编写长篇技术方案（见 §8；简单落地页默认可跳过 tech 文档，由用户确认）

---

## 4. 详细需求

### 4.1 信息架构（单页锚点）

| 区块 ID（建议） | 名称   | 职责                        |
| --------------- | ------ | --------------------------- |
| （顶栏）        | Nav    | 品牌 + 锚点跳转 + 主 CTA    |
| `#hero`         | Hero   | 品牌主张 + 主 CTA           |
| `#features`     | 功能   | 六块能力展示（含 GIF/占位） |
| `#download`     | 下载   | Android / iOS 获取方式      |
| `#contact`      | 联系   | 公众号、QQ 群               |
| （页脚）        | Footer | 工作室署名与版权            |

顶栏锚点文案：**功能** → `#features`，**下载** → `#download`，**联系** → `#contact`。  
「立即下载」滚至 `#download`（顶栏与 Hero 共用语义）。

### 4.2 顶栏

- 左侧品牌字标：**农屿**（可后续替换为 Logo 图，本轮文字即可）
- 中/右：锚点链接 + 主按钮「立即下载」
- 滚动后允许轻量背景模糊/阴影，保持可读，不遮挡内容
- 移动端：锚点可收纳为简洁菜单或横向可滑，但必须仍能到达三区

### 4.3 Hero

| 元素        | 内容                                                        |
| ----------- | ----------------------------------------------------------- |
| 品牌/主标题 | 农屿                                                        |
| 副标题      | 专属川农er的校园助手                                        |
| 说明        | 无广告课表、教务与二课聚合、农屿 AI，你想要的，农屿都能做到 |
| CTA         | 立即下载 → `#download`                                      |

首屏应读作**一个构图**：品牌名是最强信号，副标题与说明不得压过品牌。禁止首屏堆砌功能列表、数据条、多 CTA。

### 4.4 功能展示（六块，顺序固定）

| #   | 标题         | 说明文案（可微调用词，语义不可删）                             |
| --- | ------------ | -------------------------------------------------------------- |
| 1   | 智能课表     | 周视图课表、自定义日程、同学间共享与差异对比，支持桌面小组件   |
| 2   | 教务聚合     | 教务通知、成绩、专业排名、考试安排、培养方案等常用查询一站到达 |
| 3   | 二课查询     | 浏览二课活动与个人学分、综测信息；本版为只读查询，不含报名     |
| 4   | 农屿 AI      | 用自然语言查询教务、二课、课表与广场；教师/教室课表也可问 AI   |
| 5   | 校园广场     | 官方公告、反馈墙与大院，获取通知并参与反馈                     |
| 6   | 主题与个性化 | 川农新绿等外观与课表偏好，让日常打开更顺手                     |

**版式**

- 桌面：奇数块「左文右媒」，偶数块「左媒右文」（或等价交替）
- 移动：一律「上文下媒」
- 媒体区：固定宽高比容器（建议约 **16:10** 或 **4:3**，全站统一），圆角；未提供 GIF 时显示占位（功能标题 + 文案「动图占位」）
- 资源约定：例如 `public/features/01-course.gif` … `06-theme.gif`；缺失则自动回退占位，**不得破版**

### 4.5 下载

| 平台    | 行为                                                                                                      |
| ------- | --------------------------------------------------------------------------------------------------------- |
| Android | 若配置了 APK（或下载页）URL：主按钮可点并打开该 URL；未配置：按钮禁用或展示「即将开放」，**禁止**跳转假链 |
| iOS     | 固定展示「即将开放」（本轮无链接）                                                                        |

可附一行说明：Android 侧载安装；以学校网络环境为准（文案简短即可）。

配置项（实现时名称可调整，语义必须有）：

- `downloadAndroidUrl`：空字符串表示未就绪
- （预留）`downloadIosUrl`：本轮忽略或恒空

### 4.6 联系

| 渠道       | 展示值       | 交互                                          |
| ---------- | ------------ | --------------------------------------------- |
| 微信公众号 | 农屿校园助手 | 一键复制；成功有可见反馈（如 Toast/文案切换） |
| QQ 群      | 327303003    | 同上                                          |

本轮无邮箱。联系区可与下载区同屏或紧邻，但锚点 `#contact` 必须可达。

### 4.7 页脚

- 「农屿工作室」
- 版权年（如 `© 2026`，年号以实现时为准或取当前年）
- 不展示 ICP（预留位置可选，默认不渲染）

### 4.8 视觉与动效

**色板（与 RN 川农新绿浅色对齐，实现须落为 CSS 变量）**

| Token 语义                    | 色值                  |
| ----------------------------- | --------------------- |
| brand / primary               | `#0A7C59`             |
| brandMuted / primaryContainer | `#D4E9DF`             |
| onBrand                       | `#FFFFFF`             |
| background                    | `#FAFBFA`             |
| surface                       | `#FFFFFF`             |
| text                          | `#111827` / `#1F2937` |
| textSecondary                 | `#424945` 一级        |
| outline                       | `#CFE3DA`             |

**风格**：大留白、圆角、轻阴影或细描边；避免卡片堆砌首屏；避免紫色渐变模板风。  
**动效（至少）**：① 区块进入视口时轻量显现 ② 主按钮/功能媒体 hover 微反馈 ③ 顶栏滚动状态变化；均需尊重 `prefers-reduced-motion: reduce`（减为瞬时或关闭）。

**设计准则文档**：实现前或实现同期补齐 `design-system/web-site/MASTER.md`（当前目录缺失），色板与字体选择与本 Spec 一致。

### 4.9 响应式与质量底线

- 可用宽度覆盖常见手机与桌面（约 360px～1440px+）
- 可聚焦控件有可见 focus 态
- 外链（若有）`rel`/`target` 行为安全合理
- 无障碍：复制按钮、下载按钮有明确 accessible name

### 4.10 文案与品牌

- 对外称呼：**农屿**；团队：**农屿工作室**
- 受众默认：四川农业大学在读本科生
- 不夸大未上线能力；二课「不含报名」、iOS「即将开放」必须诚实

## 5. 业务流程

```text
访问官网
  → 阅读 Hero，理解产品
  → 滚动/锚点浏览六功能（看 GIF 或占位）
  → 点击「立即下载」进入下载区
      → Android 有链接则下载/跳转
      → 无链接或 iOS：看到「即将开放」
  → 需要帮助：联系区复制公众号或 QQ 群号
```

无登录、无服务端业务流。

## 6. 验收标准与测试方案

### 6.1 UI / 交互验收

1. **首屏**：品牌「农屿」视觉权重最高；副标题与 CTA 完整可见（移动端允许轻滚，但不得首屏塞满六功能）。
2. **顶栏**：三个锚点与「立即下载」均可滚到正确区块；滚动后顶栏仍可读。
3. **功能**：六块标题与说明齐全；桌面交替、移动堆叠；无 GIF 时占位尺寸与有图时一致（替换 GIF 后无布局跳动或跳动极小）。
4. **下载**：`downloadAndroidUrl` 为空时不可打开虚假地址；有值时可打开；iOS 为「即将开放」。
5. **联系**：两项复制成功有反馈；文案与 PRD 一致。
6. **主题**：页面主色为川农新绿系，非暗色站。
7. **动效**：正常模式有进入/hover/顶栏反馈；系统「减少动态效果」开启时无干扰性长动画。
8. **页脚**：含农屿工作室与版权年。

### 6.2 测试方式

- 人工：Chrome / Safari（或 WebKit）桌面 + 窄屏；检查锚点、复制、下载配置开关（空/非空各测一次）
- 可选：Lighthouse 基础无障碍与性能扫一眼（非门禁，除非后续单列）
