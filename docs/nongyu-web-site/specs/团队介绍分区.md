# Spec：农屿官网 · 团队介绍分区

| 项       | 内容                     |
| -------- | ------------------------ |
| 应用     | `apps/nongyu-web-site`   |
| 需求类型 | **业务需求**             |
| 状态     | **已实现（待人工验收）** |

## 背景与目标

在落地页最下方（联系区之后、页脚之前）增加「农屿团队介绍」分区；正文由产品方自行填写，本轮仅占位。

## 边界

- 不新增独立「联系我们」长文案区；保留现有 `#contact` 公众号/QQ
- 不改下载与功能区

## 详细需求

- 锚点：`#team`；顶栏增加「团队」链至该区
- 标题：农屿团队介绍（可配置）
- 正文：`【待填写：农屿团队介绍】`（可配置，支持多段换行）
- 版式：安静文案区，与现有 section 风格一致，无强制配图

## 验收

滚动至页底可见团队介绍；顶栏「团队」可锚到；改 `site-config.team` 即更新文案。
