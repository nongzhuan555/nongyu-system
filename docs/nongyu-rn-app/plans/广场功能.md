## 2. 实施步骤

### 2.1 API 与鉴权

1. 新增 `src/api/appClient.ts`（命名可微调）
   - 统一 envelope 解析（从 `appAuth.ts` 抽出或复用）
   - `getAppAccessToken()`：`session.token` → `__DEV__` 时 `EXPO_PUBLIC_DEV_APP_TOKEN`
   - `appFetch(path, init)` 自动带 `Authorization`
2. 重构 `appAuth.ts` 尽量走同一解析逻辑（避免双份 envelope 代码）
3. 新增 `src/modules/center/api/posts.ts`：list / detail / create / delete / latestAnnouncement / myPosts
4. 新增 `src/modules/center/constants/subtypes.ts`：映射表与发帖选项

### 2.2 广场 UI

1. `src/modules/center/screens/CenterScreen.tsx`：分段 + 列表
2. 组件：`PostCard`、`PostList`（FlashList + 上拉/下拉）、空/错/骨架、发帖 FAB
3. 路由：
   - `app/(tabs)/center.tsx` → 接真实屏
   - `app/center/post/[id].tsx` 详情
   - `app/center/compose.tsx` 发帖
4. `_layout.tsx` 注册上述 Stack 屏

### 2.3 首页通知

1. `useNoticeBootstrap` 改真实请求；无数据回退 `FIXED_NOTICE` 占位（禁止隐藏栏位）
2. `NoticeBar` 点击一律 → `/home/notice`（公告列表）

### 2.4 我的帖子

1. `mine.tsx` 增加「我的帖子」入口（占位页上即可）
2. `app/mine/posts.tsx` + 模块屏：列表含 `viewCount`、删除确认

### 2.5 联调

1. 在 `apps/nongyu-rn-app/.env`（或 Expo 约定本地 env，**gitignore**）设置：
   - `EXPO_PUBLIC_API_BASE_URL`
   - `EXPO_PUBLIC_DEV_APP_TOKEN=<联调 mock JWT>`
2. 确认 Node `dev` 已起；必要时 Admin 发一条公告、App 发反馈/大院帖
3. 按 Spec §6 清单点验

### 2.6 收尾

1. `pnpm --filter nongyu-rn-app` 侧 lint / type-check；根目录 format 按仓库约定
2. Spec 状态改为「已实现」；必要时补一行开发文档索引
3. 若有 Bug 修复写入 `docs/common/BugLog.md`
