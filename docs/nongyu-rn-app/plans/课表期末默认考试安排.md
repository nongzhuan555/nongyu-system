## 2. 实施步骤

### 2.1 考试列表面板复用

1. 新建 `apps/nongyu-rn-app/src/modules/jiaowu/components/ExamSchedulePanel.tsx`（或 `course/components` 若更偏课表宿主；**推荐放 jiaowu**，课表引用教务组件）：
   - 内含：`useJiaowuQuery({ resource: "exam", … })`、`useDeferredLocalSearch`、列表卡片、loading/error/empty/refresh/search。
   - Props（建议）：
     - `embedded?: boolean`：`true` 时**不**渲染 `JiaowuPageShell` 的返回顶栏，仅内容区（搜索+列表+RefreshControl）；`false`/缺省供独立页用完整 Shell。
   - 或拆成：`useExamSchedule()` + 纯展示 `ExamScheduleList`，由 Shell / CourseScreen 各自包壳。优先 **hook + list** 更清晰。
2. `ExamScreen.tsx` 改为：`JiaowuPageShell` + 复用 list/hook，行为与现网一致。

### 2.2 判定函数

1. 在 `course/model/semesterWeek.ts`（或邻近 `courseFinished.ts`）新增：

```ts
isSemesterCoursesFinished(args: {
  semesterStart: Date | null;
  courses: CourseEntry[];
  now?: Date;
}): boolean
```

2. 实现：`semesterStart` 非空、`courses.length > 0`、`computeCurrentWeek(...) > maxWeekFromCourses(courses)`。

### 2.3 CourseScreen 视图切换

1. 本地 state：`coursePane: "week" | "exam"`；`userOverrodePane: boolean`（或合并为「会话覆盖」）。
2. `const semesterFinished = isSemesterCoursesFinished({ semesterStart, courses })`（仅 self、非 readOnly peer）。
3. `useFocusEffect`：
   - focus：若 `semesterFinished && viewMode === "self"` 且无会话覆盖 → `coursePane = "exam"`；否则若未 finished → `coursePane = "week"` 并清覆盖。
   - blur：清除会话覆盖（下次 focus 重新默认）。
4. peer/diff：强制展示 week；忽略 exam pane。
5. 渲染：
   - `coursePane === "exam" && semesterFinished && self` → 考试面板（embedded）；
   - 否则现有周视图树。

### 2.4 顶栏

1. 本人 + `semesterFinished`：
   - exam：标题可改为「考试安排」或主标题下副文案；右侧/actions 增加「查看课表」。
   - week：保留「农屿课程表」；actions 增加「考试安排」（与刷新、查看他人并存，注意换行/挤压，优先文字按钮短文案）。
2. peer/diff：不显示上述按钮。

### 2.5 测试（人工）

对照 Spec §6 A1–A8。重点：blur 再 focus 重置；学期未结束无按钮；peer 无考试。

### 2.6 文档

编码完成后 Spec/本计划状态改为「已实现」。

## 3. 注意事项

- 判定只用 `maxWeekFromCourses`，勿用 `maxWeekFromAll`。
- Tab 常驻：必须用 focus/blur，不能只靠 mount。
- 考试面板不要引入 peer 学号参数。
- 抽组件时保持教务独立路由标题「考试安排（正考）」不变。
- 周视图在切到 exam 时可不卸载（`display: none` / 条件渲染二选一）；若条件渲染，切回 week 应仍能滑动到合理周次。
