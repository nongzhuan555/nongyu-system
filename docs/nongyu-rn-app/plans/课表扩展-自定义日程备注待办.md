## 2. 实施步骤

### 2.1 M1 数据契约与 id 稳定

1. `model/types.ts`：新增 `ScheduleEntry` / `CourseNote` / `CourseTodo` / `GridSchedule`；`GridCell` 扩展
2. `mapJiaowuCourseItems.ts`：id 改为 `stableCourseId(name, day, start, end)`（FNV-1a 哈希）
3. `weekMatrix.ts`：`buildWeekMatrixWithSchedules(courses, schedules, week)`；课程优先，日程填空格
4. `CourseScreen` / `WeekPager`：适配新矩阵结构

### 2.2 M2 Node 后端

1. `migrations/002_course_ext.sql`：三张表 + 索引
2. `modules/course-ext/repo.ts`：`list/create/update/delete` 三类（按 uid）
3. `modules/course-ext/mapper.ts`：row ↔ DTO，`weeks_list` JSON 互转
4. `modules/course-ext/routes.ts`：Router + Zod + `requireAppAuth`
5. `app.ts`：`app.use("/api/app/course-ext", appCourseExtRouter)`
6. 手工 curl 验证

### 2.3 M3 RN 数据层

1. `courseExtLocalStore.ts`：三类 read/write/clearByStudentId
2. `courseExtApi.ts`：fetch 客户端，注入 token
3. `courseExtRepository.ts`：CRUD + `pullCourseExt`
4. React Query hooks（`useSchedules/useNotes/useTodos` + mutations）

### 2.4 M4 RN UI

1. `ScheduleCard.tsx`：沿用 CourseCard 样式，小图标区分
2. `ScheduleFormSheet.tsx`：BottomSheet 表单（title/content/location/day/period/weeks）；添加/编辑/删除
3. `WeekGrid`：空格子 `onPress` → 打开 `ScheduleFormSheet`；渲染 `GridSchedule`
4. `CourseNotesSection.tsx`：备注列表 + 新增输入 + 删除
5. `CourseTodosSection.tsx`：待办列表 + 完成 checkbox + 新增 + 删除
6. `CourseDetailSheet.tsx`：扩展加入 notes/todos section

### 2.5 M5 Agent tools

1. `course/agent/course-tools.ts`：14 个 tool（见 Spec §4.4.3）
2. `agent/agent.ts`：`tools` 追加 `...courseTools`；systemPrompt 补课表扩展能力

### 2.6 M6 登出清理 + 验收

1. `performJiaowuLogout`：追加清 `course:entries/schedules/notes/todos` + 背景图文件 + React Query
2. Spec §6 验收清单逐项点验
3. `pnpm --filter nongyu-rn-app lint` / `type-check`
4. `pnpm --filter nongyu-node-server` lint / test
5. 更新 Spec / Tech / Plan 状态

## 3. 注意事项

- id 稳定化后旧本地课表 id 失效，首版升级需重新 fetch 教务课表（清本地 `course:entries`）
- 写操作本地立即生效，远程失败不阻断 UI；下次 pull 远程权威覆盖
- Node 接口必须 `requireAppAuth` + uid 隔离；Agent tool 经同一 token
- 严格按 Spec 边界，不扩 scope；偏离先停改文档
- 不主动 git commit
