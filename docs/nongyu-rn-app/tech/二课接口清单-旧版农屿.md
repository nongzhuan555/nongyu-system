## 1. 会话约定（旧版）

| 项       | 旧版用法                                                                                                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Base URL | **现网采用 `https://jk.sicau.edu.cn`**（2026-08-15 已验登录通）。旧 APK 配置项名 `SECOND_CLASS_BASE_URL`；业务 path 为相对路径。APK 内另见过 `fpa.sicau.edu.cn` 绝对登录地址，现网勿用。 |

- App 内路由形如 `second/userInfo`（非 HTTP API）
- minify 粘连误读的学院域名绝对 URL（如 `fjylxy.sicau.edu.cn/...`）
- 仓库外第三方 PocketUni 新版 API（与旧农屿契约不同，启用前需单独对齐）
