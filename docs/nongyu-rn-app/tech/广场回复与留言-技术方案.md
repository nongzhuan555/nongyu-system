## 3. 关键设计

### 3.1 Toast 扩展支持 onPress

现有 toast 仅 `Toast.hide()`。扩展 `AppToastOptions`：

```ts
export type AppToastOptions = {
  description?: string;
  duration?: number;
  /** 点击 toast 回调；不传则点击仅 hide */
  onPress?: () => void;
};
```

渲染层：`onPress` 存在时，toast 容器包 `Pressable`，点击触发 `onPress` 后 `Toast.hide()`；不传则保持原行为。新回复 toast 传入 `onPress: () => router.push(\`/center/post/${postId}\`)`。

### 3.2 前台检测 hook（`useForegroundState`）

抽取通用 hook，复用既有 `AppState.addEventListener` 模式：

```ts
export function useForegroundState(): boolean {
  const [active, setActive] = useState(AppState.currentState === "active");
  useEffect(() => {
    const sub = AppState.addEventListener("change", (s) => setActive(s === "active"));
    return () => sub.remove();
  }, []);
  return active;
}
```

### 3.3 列表轮询（`useCenterListPolling`）

`PostFeedList` 内根据 `postType` 与前台状态决定 `refetchInterval`：

```ts
const isForeground = useForegroundState();
const pollable = mode !== "mine" && (postType === "feedback" || postType === "courtyard");
const refetchInterval = pollable && isForeground ? 30_000 : false;

const query = useInfiniteQuery({
  queryKey,
  queryFn: ...,
  refetchInterval,
  refetchPage: (page, idx) => idx === 0,  // 仅 refetch 第 1 页
  // ...
});
```

- `announcement` 分段 / `mine` 模式：`refetchInterval = false`（不轮询）。
- 后台：`isForeground=false` → 停止；回前台 → 自动恢复。
- 轮询失败：TanStack Query 默认 retry 1，静默不 toast。

### 3.4 新回复轮询 Host（`PostRepliesPollerHost`）

挂载于 `app/_layout.tsx` 的 `AuthRoot` 内，与 `TelemetryHost` 同级：

```tsx
export function PostRepliesPollerHost() {
  const isForeground = useForegroundState();
  const token = useSessionStore((s) => s.token);
  const hydrated = useSessionStore((s) => s.hydrated);
  const router = useRouter();
  const seenIdsRef = useRef<Set<number>>(new Set());

  const query = useQuery({
    queryKey: ["posts", "me", "new-replies"],
    queryFn: fetchNewPostReplies,
    refetchInterval: isForeground && hydrated && token ? 30_000 : false,
    enabled: hydrated && Boolean(token),
    staleTime: 0,
    refetchOnWindowFocus: false,
    refetchOnMount: true,
    refetchIntervalInBackground: false,
    onSuccess: (data) => {
      const fresh = data.filter((r) => !seenIdsRef.current.has(r.replyId));
      fresh.forEach((r) => {
        seenIdsRef.current.add(r.replyId);
        const title = r.postTitle;
        const msg =
          r.kind === "admin_reply"
            ? `你的反馈帖《${title}》已被管理员回复`
            : `你的大院帖《${title}》收到新留言`;
        toast.info(msg, {
          onPress: () => router.push(`/center/post/${r.postId}`),
        });
      });
      // 防止集合无限增长：保留最近 200 条
      if (seenIdsRef.current.size > 200) {
        seenIdsRef.current = new Set([...seenIdsRef.current].slice(-200));
      }
    },
  });
  return null;
}
```

- 服务端已置位 `notified_author`，`seenIdsRef` 仅做客户端幂等兜底（避免 onSuccess 在快速 refetch 时重复触发）。
- 回前台时 `refetchInterval` 恢复，TanStack Query 自动触发一次 refetch。

### 3.5 详情页扩展

`PostDetailScreen` 按 `postType` 渲染：

- `feedback`：正文下方 `<AdminReplyBlock reply={post.adminReply} />`（只读）。
- `courtyard`：正文下方 `<CommentList comments={post.comments} onDelete={...} />` + 底部 `<CommentComposer postId={post.id} onPosted={...} />`。
- `announcement`：不渲染。

留言创建乐观更新：`useMutation` 的 `onMutate` 先向 query 缓存追加临时项，失败回滚；成功后 `invalidateQueries(['posts','detail',id])` 拉取权威数据。

### 3.6 「我的帖子」角标

`MyPostsScreen` 卡片根据 `replyCount` / `hasReply` 渲染：

- feedback：`hasReply` → 「已回复」（success 色）；否则「未回复」（textSecondary）。
- courtyard：`replyCount > 0` → 「N 条留言」；否则「暂无留言」。

## 5. 注意事项

- **refetchInterval 首次引入**：确认 TanStack Query v5 版本支持 `refetchInterval` 函数式 / boolean；`refetchPage` 控制仅刷第 1 页。
- **轮询不刷屏**：列表轮询静默；新回复 toast 仅对 fresh 项触发。
- **后台停止**：`refetchIntervalInBackground: false` + `isForeground` gate 双保险。
- **未登录不轮询**：`enabled: hydrated && Boolean(token)`。
- **乐观更新回滚**：留言创建失败回滚缓存并 toast，输入内容保留。
- **主题无关**：颜色全走语义 token，复用 `createThemedStyles`。
- **FlashList 兼容**：留言列表用 `ScrollView` + map（数量不大）或 FlashList（若量大）；详情页非长列表，优先 ScrollView。
- **QueryClient 默认 staleTime 30s**：与轮询 30s 一致，避免轮询间额外触发；详情 query 可设 `staleTime: 0` 保证进入即拉新。
