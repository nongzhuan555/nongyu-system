# 二课鉴权方案

> 状态：登录与只读查询已实网调通（2026-08-15）  
> 适用范围：`apps/nongyu-rn-app` 二课相关能力；`nongyu-tool-second` / Agent `secondTools`  
> 实现细节见 `packages/nongyu-tool-second/TECH.md`

## 1. 目标

- 二课会话与农屿 App Token、教务 Cookie **分层**：二课只使用 `x-access-token`。
- 学号可与教务相同；**密码可能不同**（i川农 / 二课密码），单独 SecureStore 持久化。
- 本轮只读；报名写操作不进代码路径。

## 2. 角色与依赖

| 层       | 职责                | 载体                                                                         |
| -------- | ------------------- | ---------------------------------------------------------------------------- |
| 二课会话 | 访问 i川农 JSON API | `nongyu-tool-second`：`secondLogin` / `setLoginData` / 内存 `x-access-token` |
| 本地敏感 | 二课密码            | `expo-secure-store` key `second_password`                                    |
| 本地会话 | token 备份          | MMKV `second:access_token`                                                   |
| 农屿身份 | 与二课无关          | Node App Token（登出时顺带清二课会话）                                       |

## 3. 主流程

```text
用户在二课首页输入学号 + 二课密码
  → secondLogin(loginName, password, sid)
  → 成功：工具内存 setAccessToken + setLoginData
  → SecureStore 存 second_password；MMKV 备份 token
```

冷启动：

```text
restoreSecondTokenFromStorage()
若有农屿学号 + second_password → setLoginData（供 token 失效自动重登）
refreshSecondAuthFlag()
```

农屿登出 / Token 作废：`clearSecondToolSession()` + 清 SecureStore 二课密码（随 `clearCredentials`）。

## 4. 否决项

- 不以 `fpa.sicau.edu.cn` 为 Base URL
- 不把个人密码 / 长期 token 写入仓库
- 本轮不实现报名等写操作
