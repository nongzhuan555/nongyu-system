## 1. 技术选型

沿用 `docs/nongyu-rn-app/技术选型.md`，本需求落地如下：

| 领域           | 选型                                                     | 说明                                                            |
| -------------- | -------------------------------------------------------- | --------------------------------------------------------------- |
| UI             | StyleSheet + Design Token（`src/theme`）                 | 不迁 `react-native-paper`；Phase 1 保旧观感，Phase 2 收拢 Token |
| 横向切周       | 水平分页 `FlatList`（`pagingEnabled` + `getItemLayout`） | 对齐旧版；学期周数通常 ≤20                                      |
| 详情弹层       | `@gorhom/bottom-sheet`                                   | 大半屏；依赖已有 Reanimated / Gesture Handler                   |

## 2. 技术方案

### 2.1 模块目录

```text
apps/nongyu-rn-app/
  app/(tabs)/course.tsx                 # 路由壳 → CourseScreen
  src/modules/course/
    screens/CourseScreen.tsx            # 页头（开学日入口）+ WeekPager
    components/
      WeekPager.tsx                     # 水平 FlatList 切周
      WeekGrid.tsx                      # 单周：表头 + 5×7 网格
      CourseCard.tsx                    # 卡片（三字段 / 按压态）
      CourseDetailSheet.tsx             # BottomSheet 详情
      SemesterStartPicker.tsx           # 日期选择封装
      BackToCurrentWeekFab.tsx          # Phase 2：回本周
    model/
      types.ts                          # CourseEntry、GridCell、WeekPage 等
      semesterWeek.ts                   # 开学日 ↔ 周号 ↔ 周一日期
      weekMatrix.ts                     # list → 周矩阵（含 span）
      colors.ts                         # 课程名 → 色板稳定哈希
      courseTimes.ts                    # 10 节次起止时间常量
    data/
      courseRepository.ts               # listCourses() 抽象
      mockCourses.ts                    # mock 数据（可参考旧 course.json 转换）
    store/courseUiStore.ts              # 开学日、高亮列、展示周索引
```

参照迁移源（只读）：`old-code/nongyu/src/modules/Course/`（`CourseTable`、`CourseDetailModal`、`semesterDate`、色板与 `COURSE_TIMES`）。

### 2.2 领域模型

```ts
/** 节次 1–10；大课区间 row = floor((startPeriod-1)/2)，0–4 */
type CourseEntry = {
  id: string;
  name: string;
  teacher: string;
  room: string;
  day: 1 | 2 | 3 | 4 | 5 | 6 | 7;
  startPeriod: number;
  endPeriod: number;
  weeks: { start: number; end: number };
  weeksList?: number[];
  odd: boolean;
  even: boolean;
};

/** 网格主格：spanRows 表示向下合并的大课区间数（≥1） */
type GridPrimary = {
  kind: "primary";
  course: CourseEntry;
  spanRows: number;
};

/** 被连堂主格占用的占位，渲染时跳过 */
type GridOccupied = {
  kind: "occupied";
  primaryRow: number;
};

type GridCell = GridPrimary | GridOccupied | null;
```

**周匹配**：优先 `weeksList`；否则 `[weeks.start, weeks.end]` + 单双周过滤（对齐旧 `weekMatches`）。

**连堂（T4-B）**：

1. 先按 `startPeriod` 落入大课区间行，写入 `primary`，`spanRows = ceil((endPeriod - startPeriod + 1) / 2)`（与旧「一大课区间=2 小节」一致，需与真实起止节次校验）。
2. 被跨到的下方格子标 `occupied`，指向主格行。
3. **Phase 1**：可先强制 `spanRows = 1` 仅占起始大课区间（迁移可视等价优先）；**Phase 2**：启用真实 `spanRows` 做合并单元格高度。

同一格多门课：取列表首条为展示课（Spec 约定）；其余忽略至后续 Spec。

### 2.3 周次与开学日（T2）

| 状态         | 行为                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 未设置开学日 | 默认展示第 **1** 周；表头**不显示**月/日；页头可轻提示设置开学日                                                               |
| 已设置开学日 | `currentWeek = computeCurrentWeek(start)`（周一为第 1 周起点）；表头显示各列 `M/D`；打开课表定位到 `min(currentWeek, maxWeek)` |

持久化 key 建议：`course:semester_start_ms`（MMKV 存 epoch ms 字符串）。  
高亮列 key：`course:highlight_today_column`（`"1"` / `"0"`，Phase 2；默认开）。

实现文件：`model/semesterWeek.ts` 用 dayjs 复刻旧语义，单测优先（纯函数）。

### 2.4 数据层

```ts
// courseRepository.ts
export async function listCourses(): Promise<CourseEntry[]>;
```

本期：`mockCourses.ts` 同步返回；`listCourses` 可 `async` 以便日后换教务/Query。  
**禁止**在 `WeekGrid` 内直接 import 教务 HTML 解析。

`maxWeek`：`max(课程 weeks.end / weeksList, 1)`，至少 1 页。

### 2.5 状态（T3）

`courseUiStore`（Zustand）：

| 字段                                                                | 持久化          | 说明                        |
| ------------------------------------------------------------------- | --------------- | --------------------------- |
| `semesterStartMs: number \| null`                                   | MMKV            | 开学日                      |
| `highlightTodayColumn: boolean`                                     | MMKV（Phase 2） | 当日列高亮                  |
| `viewWeekIndex: number`                                             | 否              | 当前 FlatList 页（0-based） |
| `setSemesterStart` / `setHighlightTodayColumn` / `setViewWeekIndex` | —               | —                           |

hydration：Store 初始化时从 MMKV 读开学日/高亮。

### 2.6 UI 结构

**CourseScreen**

- SafeArea + 底 padding（`tabBar.heightMax + bottomGapMax`）避免被悬浮栏遮挡。
- 顶栏：标题「农屿课程表」或「第 N 周」；图标按钮打开开学日选择；Phase 2 可加高亮开关（简洁，如长按表头或顶栏小开关）。
- 主体：`WeekPager`。

**WeekPager**

- `FlatList` horizontal、`pagingEnabled`、`getItemLayout`、初始 `scrollToIndex` 到当前周。
- `onMomentumScrollEnd` 同步 `viewWeekIndex`。
- 非本周且已设开学日：显示 `BackToCurrentWeekFab` → `scrollToIndex` + 更新 store。

**WeekGrid**

- 固定表头行 + 纵向 `ScrollView` 五行。
- 时间列：各大课区间展示两小节的起止（`courseTimes`）。
- 有 `primary` 则渲染 `CourseCard`（Phase 2 高度 = `rowHeight * spanRows`）；`occupied` 空渲染。

**CourseCard**

- Phase 1：旧色板哈希；文案可多行宽松。
- Phase 2：仅 name / teacher / room；Reanimated 或 Pressable 按压缩放/透明度。

**CourseDetailSheet**

- `@gorhom/bottom-sheet`，snap ~50–70% 屏高。
- 内容：课名、教师、教室、星期、节次时间、周次文案。
- 无考勤/待办/删除。

**SemesterStartPicker**

- 触发后调起 `DateTimePicker`（Android dialog / iOS 可内嵌或再包一层确认）。

### 2.7 颜色

从旧 `COURSE_COLORS` 迁入 `model/colors.ts`；`hash(name) % palette.length`。Phase 2 可微调用 Token 语义色，但保持「多色区分」。

### 2.8 与 App Shell 关系

- 不改 Tab 配置；仅替换 `course.tsx` 内容。
- 不引入 Paper Theme；颜色走 `lightTokens` / 课表局部色板。
- Gesture Handler：根布局已有则直接用 BottomSheet；若缺 Provider 在根补齐（实现时核对 `_layout`）。

## 3. 实现步骤

### Phase 1 — 迁移基线

1. 落地 `model/`（types、semesterWeek、weekMatrix 可先 `spanRows=1`、colors、courseTimes）+ 纯函数单测（若工程已有 vitest/jest 策略则跟；无则先手工验收，不强制新测框架）。
2. `mockCourses` + `courseRepository`。
3. `courseUiStore` + MMKV 开学日。
4. `WeekGrid` + `CourseCard` + `WeekPager` + `CourseScreen`；接 `course.tsx`。
5. `CourseDetailSheet`（基础字段）+ `SemesterStartPicker`。
6. 对照 Spec §6.1 验收；底栏遮挡、无开学日表头行为按 T2。

### Phase 2 — PRD 基础升级

1. `weekMatrix` 启用真实 `spanRows`；卡片高度合并。
2. 卡片三字段；按压动效；详情进出动画调优。
3. 「回本周」FAB；打开定位当前周（已有则加固）。
4. 表头当日强调 + `highlightTodayColumn` 开关持久化。
5. 按 design-system / Token 收拢间距字号圆角（信息架构不变）。
6. Spec §6.2 验收。

### 测试与部署

- 手工：真机/模拟器切周、设开学日、详情、空格、底栏。
- 纯函数：`semesterWeek`、`weekMatrix`、`weekMatches` 优先补单测（若 RN 包内无测试脚本，可放 `src/modules/course/model/*.test.ts` 并评估是否接入现有 monorepo 测试；**不阻塞** Phase 1 UI）。
- 无服务端变更、无 EAS/原生模块新增 → 无需重打 Dev Client。

## 4. 注意事项

| 项       | 说明                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 性能     | 周页 `React.memo`；避免每帧重建 styles；动画 `useNativeDriver` / Reanimated UI 线程 |
| 嵌套滚动 | 横向 FlatList + 纵向 ScrollView：沿用旧版 `nestedScrollEnabled`；注意同时拖拽冲突   |
| 初始定位 | `scrollToIndex` 需 `onLayout` / `initialScrollIndex` 防闪烁到第 0 周                |
| 安全区   | 顶/底 padding 对齐首页；FAB 避开 TabBar                                             |
| 登出     | 开学日/高亮属偏好，**默认保留**（非敏感）；若产品日后要求清偏好再改                 |
| 安全     | mock 无密钥；勿把教务 Cookie 写入课表模块                                           |
| 范围蠕变 | 自定义课、分享、背景图、教务抓取一律不进本实现                                      |
