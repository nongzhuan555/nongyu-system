# Spec：农屿 Agent 接入广场帖子只读查询（Generative UI）

| 项       | 内容                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                                         |
| 需求类型 | **业务**                                                                     |
| 上游     | `docs/nongyu-rn-app/tech/Agent生成UI渲染能力-技术方案.md`（Controlled 模式） |
| 关联     | 广场 API `GET /api/app/posts`、`GET /api/app/posts/:id`；`PostCard`          |
| 状态     | 已确认（grill 全按推荐）                                                     |

---

## 1. 背景

农屿 Agent 已支持二课/教务/课表等工具的内联卡片。广场帖子（公告 / 反馈墙 / 大院）目前仅在 Tab 内浏览，用户希望用自然语言「查广场帖」并在对话里用与广场一致的帖子卡片看结果。

## 2. 目标

1. Agent 可只读查询广场帖子列表与单帖详情。
2. 查询结果以 **帖子卡片**（复用/对齐 `PostCard`）内联展示（AI 生成 UI / Controlled）。
3. 点击卡片进入 App 帖子详情页；列表超过展示上限时提供「去广场」入口。

## 3. 边界（非目标）

- **不支持写**：发帖、删帖、改帖。
- 不做「我的帖子」「最新公告」独立工具（本期不做 C/D）。
- 不改 Node 契约；不把工具放进 `nongyu-agent-sdk` ExternalTools（需 App JWT，放 RN 侧）。
- 不破坏用户间匿名：卡片不展示作者名。

## 4. 详细需求

### 4.1 工具

| 工具名              | 作用                     | 入参要点                                         | 渲染组件              |
| ------------------- | ------------------------ | ------------------------------------------------ | --------------------- |
| `plaza_posts_list`  | 按分区查列表（可关键词） | `postType` 必填；`keyword?`；`subtype?`；`page?` | `PlazaPostListCard`   |
| `plaza_post_detail` | 按 id 查详情（会计阅读） | `id` 必填                                        | `PlazaPostDetailCard` |

- 列表默认 `pageSize=5`（与对话展示上限一致）。
- `execute` 调用现有 `fetchPosts` / `fetchPostDetail`。

### 4.2 渲染

- **列表**：纵向堆叠最多 **5** 条，字段与广场 `PostCard` 一致（标题、摘要、时间、类型标签；无署名）。
- **详情**：单卡展示标题、类型、时间、正文（可截断）；加载/错误/空态齐全。
- **点击卡片**：`router.push('/center/post/{id}')`。
- **更多**：列表 `total > 展示数` 时显示「去广场查看更多」→ `router.push('/(tabs)/center')`。

### 4.3 Agent 接入

- `plazaTools` 并入 `getOrCreateNongyuAgent` 的 `tools`。
- `systemPrompt` 补充：查广场帖调用上述工具，结果以卡片展示；禁止引导发帖/删帖。
- `registerToolUI` 注册两个工具名。

## 5. 验收

| #   | 场景                  | 期望                                         |
| --- | --------------------- | -------------------------------------------- |
| 1   | 「看看最近公告」      | 调 `plaza_posts_list`，对话内出现帖子卡片    |
| 2   | 「反馈墙搜一下登录」  | 带 `keyword` 列表卡片                        |
| 3   | 点某张卡片            | 进入帖子详情路由                             |
| 4   | 超过 5 条             | 有「去广场查看更多」可进广场 Tab             |
| 5   | 「打开 id=xx 的帖子」 | `plaza_post_detail` + 详情卡                 |
| 6   | 未登录 / 401          | 错误态可读，不崩溃                           |
| 7   | 要求发帖              | Agent 不调用写工具（本期无写工具）并口头说明 |
