# Spec：全局确认框

| 项       | 内容                 |
| -------- | -------------------- |
| 应用     | `apps/nongyu-rn-app` |
| 需求类型 | **基建**             |
| 状态     | **已实现**           |

---

## 1. 背景

系统 `Alert.alert` 确认框观感差且各端不一致；需全局统一、可复用的自定义确认层，对齐农屿高级简约气质。

---

## 2. 目标

1. 提供 `confirm(...)` Promise API，业务侧一行调用。
2. Host 挂在 `AppProviders`，与 Toast 同级。
3. 支持普通确认与危险操作（destructive）两种主按钮样式。
4. 替换现有退出登录、删除帖子处的系统 Alert。

---

## 3. 边界

- 不替代 Toast；不做多按钮（仅取消 / 确认）。
- 不做队列叠多个确认框（同时只开一个；新开覆盖旧 Promise 为 false）。

---

## 4. API

```ts
confirm({
  title: string;
  message?: string;
  confirmText?: string; // 默认「确定」
  cancelText?: string;  // 默认「取消」
  destructive?: boolean;
}): Promise<boolean>
```

- `true`：点确认；`false`：点取消 / 蒙层 / 系统返回。

### 视觉

- 墨绿半透明蒙层；居中浅色卡片，大圆角、细描边、轻阴影。
- 顶缘品牌色细条为签名。
- 取消：浅底弱按钮；确认：品牌实心；destructive 用 danger。

---

## 5. 验收

- [ ] 退出登录、删帖使用自定义确认框，不再调用系统 Alert。
- [ ] 取消 / 确认 / 点蒙层行为正确。
