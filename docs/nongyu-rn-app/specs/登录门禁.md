# Spec：未登录仅登录页

| 项       | 内容                                                      |
| -------- | --------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                      |
| 需求类型 | **基建**（会话门禁）                                      |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/User/登录登出PRD.md` |
| 状态     | **已实现**                                                |

---

## 1. 背景

完整登录链路（教务 → 档案 → Node）已可真机联调。此前开发态会伪造已登录，且 `/login` 只是可关掉的 modal，未登录仍能进 Tab。PRD 要求：未登录只能停在登录页；登出或杀进程再开仍停在登录页。

## 2. 目标

1. `hydrated === false`：不展示 Tab / 子页（沿用原生启动屏，避免闪首页）。
2. `hydrated && !isAuthenticated`：全屏只渲染登录页，无底栏、不可返回主界面。
3. 登录成功：进入 `/(tabs)/home`。
4. 登出：清会话后自动回到登录页。
5. 禁止开发态伪造已登录绕过门禁。

## 3. 边界

- 不改登录表单 UI、不改 `performJiaowuLogin` 校验顺序。
- 不在本次做单设备互踢弹回登录页（PRD §4.4，另开）。
- 不强制 Node Token：本地教务会话建立即 `isAuthenticated`（与现会话模型一致）。
- 跳过独立技术方案 / 实施计划。

## 4. 详细需求

### 4.1 判定

- 冷启动：`useJiaowuBootstrap` 读完 SecureStore / MMKV 后 `hydrated = true`。
- 有本地凭据并恢复档案 → `isAuthenticated`；否则未登录。
- **删除** `DEV_FORCE_AUTHENTICATED` 及假档案。

### 4.2 导航

- 根布局在 Provider + bootstrap 之后用门禁：未登录只挂 `LoginScreen`，已登录才挂主 `Stack`。
- `/login` 不再 `presentation: "modal"`；已登录若进入该路由则 `replace` 到首页。
- 登录成功：`replace` 到启动页偏好（默认 `/(tabs)/home`）；**若本次打开来自课表桌面小组件**（`nongyu://course?from=widget`），则落到 `/(tabs)/course`。
- 登出只清会话；门禁因 `isAuthenticated === false` 切回登录页，不必在「我的」里再 `push('/login')`。

### 4.3 与既有页的关系

- 「我的」未登录 `GuestPrompt`、教务首页 compact 登录：主路径走不到；保留作防御，不作为未登录入口。
- 教务「通知/竞赛无需登录」仅适用于**已进入 App 之后**的教务子页；未登录 App 级仍只见登录页。

## 5. 流程

```text
冷启动
  → 启动屏，hydrated=false
  → bootstrap
       · 有凭据：setSession → 主界面（默认首页）
       · 无凭据：登录页
登录成功 → setSession → 启动页偏好（小组件来源则课表 Tab）
登出 → clearSession → 登录页
```

## 6. 验收

- [ ] 无本地凭据冷启动：只见登录页，不见底栏与首页。
- [ ] 登录成功进首页；可见姓名/学号（档案有则显示）。
- [ ] 退出登录后立刻回到登录页；杀进程再开仍是登录页。
- [ ] 登录页不能下滑关掉回到 Tab。
- [ ] 开发态不再出现「预览同学」假会话。
