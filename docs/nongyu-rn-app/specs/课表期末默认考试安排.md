# Spec：课表期末默认考试安排

| 项       | 内容                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                                    |
| 需求类型 | **业务**                                                                |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/Course/课表期末默认考试安排PRD.md` |
| 关联     | `课表周视图.md`、`课表共享与Diff.md`、教务 `ExamScreen`                 |
| 状态     | **已实现**（用户确认后编码 2026-08-16）                                 |

---

## 1. 背景

**Why**：学期课结束后用户再进课表，周视图已无新课信息，考试安排更有用；仍需能回看课表/日程。

**What**：本人课表模式下，若判定「本学期教务课已上完」，进入课表 Tab 默认展示考试安排面板；可一键切回周视图，并可再切回考试。不影响 peer/Diff；不支持他人考试。

---

## 2. 目标

| #   | 目标                 | 验收要点                                                              |
| --- | -------------------- | --------------------------------------------------------------------- |
| G1  | 正确判定「课已上完」 | 见 §4.1；未设开学日或无教务课不进入考试默认态                         |
| G2  | 默认考试面板         | 满足 G1 且本人模式时，进入课表 Tab 默认见考试列表（加载/空/错态可用） |
| G3  | 可恢复周视图         | 「查看课表」切回周视图；「考试安排」可再切回；本会话内保持用户选择    |
| G4  | peer/Diff 不受影响   | 查看他人 / Diff 始终周视图，无考试默认、无他人考试                    |
| G5  | 教务考试独立页不变   | `/home/jiaowu/exam` 行为与视觉不因本需求破坏性变更                    |

---

## 3. 边界（非目标）

- **不做** 查看他人考试 / 共享考试
- **不做** 将「用户选周视图」持久化到 MMKV（离开课表 Tab 再进入仍按默认考试）
- **不做** 改教务考试数据源或缓存策略（复用现有 `useJiaowuQuery` + `getExamInfo`）
- **不做** 技术方案文档（已确认跳过）
- **不做** 用自定义日程周次参与「课已上完」判定

---

## 4. 详细需求

### 4.1 判定：本学期教务课已上完

同时满足：

1. 当前为 **本人课表**（`viewMode === "self"`，非 peer/diff）；
2. 已设置开学日 `semesterStart`；
3. 教务课程列表非空（至少一门可落格课程）；
4. `computeCurrentWeek(semesterStart) > maxWeekFromCourses(courses)`。

说明：

- `maxWeekFromCourses` **仅统计教务课**，不含自定义日程。
- 未设开学日、课表加载中、课程为空、或当前周 ≤ 最大教学周 → **不**自动进入考试态。

### 4.2 视图模式（课表 Tab 内）

本人且满足 §4.1 时，存在两种展示：

| 模式   | 内容                                 |
| ------ | ------------------------------------ |
| `exam` | 本人考试安排列表（见 §4.3）          |
| `week` | 现有课表周视图（含日程、页头操作等） |

- **默认**：每次「进入课表 Tab」时，若 §4.1 成立，设为 `exam`；否则 `week`。
- **进入定义**：课表 Tab 获得焦点（`focus`）。底部 Tab 常驻不卸载时，以 focus/blur 为准，而非仅 mount。
- **会话覆盖**：用户点「查看课表」→ `week`；点「考试安排」→ `exam`。在仍 focus 于课表 Tab 期间保持选择。
- **重置**：课表 Tab **失焦（blur）** 后，下次 focus 若仍满足 §4.1，再次默认 `exam`（清除会话覆盖）。
- peer / Diff：强制 `week`，隐藏考试切换入口。

### 4.3 考试面板内容

- 数据与交互对齐现有教务考试页：`getExamInfo` + 本地搜索 + 下拉刷新 + 加载/错误/空态。
- **实现约束**：抽出可复用的考试列表内容组件（如 `ExamSchedulePanel`），供：
  - 课表 Tab 内嵌；
  - 既有 `ExamScreen` 继续使用（或薄包装），避免两套列表逻辑。
- 课表内嵌时：
  - 不套完整教务子页返回栈；使用课表页自有顶栏区域展示标题「考试安排」及切换按钮；
  - 不展示「查看他人考试」类能力。

### 4.4 切换按钮

当 §4.1 成立且本人模式：

| 当前模式 | 按钮文案     | 行为        |
| -------- | ------------ | ----------- |
| `exam`   | **查看课表** | 切到 `week` |
| `week`   | **考试安排** | 切到 `exam` |

- 按钮放在课表页顶栏操作区（与现有刷新 / 查看他人等同级可触达区域），样式与现有顶栏文字/图标按钮一致即可。
- 不满足 §4.1 或 peer/diff：**不显示**上述切换按钮。

### 4.5 与现有课表能力并存

- `week` 模式下：刷新课表、查看他人、开学日、日程、考勤等行为不变。
- `exam` 模式下：周网格/日程表单等可挂起不展示；从 `exam` 切回 `week` 后状态应可用（不必销毁周视图状态，允许保留）。

---

## 5. 业务流程

### 5.1 期末进入课表

1. 用户 focus 课表 Tab；
2. 课表与开学日已就绪，且 §4.1 为真；
3. 默认渲染考试面板；顶栏有「查看课表」。

### 5.2 恢复周视图再切回

1. 点「查看课表」→ 周视图；顶栏出现「考试安排」；
2. 点「考试安排」→ 考试面板；
3. 切到其他 Tab 再回来 → 若仍 §4.1，再次默认考试面板。

### 5.3 学期未结束 / 看他人

1. 当前周 ≤ 最大教学周 → 始终周视图，无切换按钮；
2. 进入查看他人 / Diff → 周视图，无考试默认与切换。

## 6. 验收标准与测试方案

| #   | 场景                                          | 期望                                |
| --- | --------------------------------------------- | ----------------------------------- |
| A1  | 开学日已设，今天教学周 > 课表最大周，本人模式 | 进课表 Tab 默认考试列表             |
| A2  | A1 下点「查看课表」                           | 周视图可用；顶栏有「考试安排」      |
| A3  | A2 后切走 Tab 再进课表                        | 再次默认考试列表                    |
| A4  | 今天教学周 ≤ 最大周                           | 周视图；无「考试安排/查看课表」切换 |
| A5  | 未设开学日                                    | 周视图；无自动考试                  |
| A6  | 查看他人 / Diff                               | 始终周视图；无考试切换；无他人考试  |
| A7  | 教务独立考试页                                | 仍可打开，列表正常                  |
| A8  | 考试无数据 / 加载失败                         | 空态 / 错误+重试，与教务页语义一致  |
