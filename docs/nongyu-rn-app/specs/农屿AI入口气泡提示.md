# Spec：农屿 AI 入口气泡提示

| 项       | 内容                                                                       |
| -------- | -------------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                                       |
| 需求类型 | **基建**                                                                   |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/Shell/农屿AI入口气泡提示PRD.md`       |
| 关联     | 底栏 `FloatingTabBar`（`docs/nongyu-rn-app/specs/底部导航与App-Shell.md`） |
| 状态     | **已落地**                                                                 |

---

## 1. 背景

农屿 AI 入口位于悬浮底栏左侧圆钮，用户可能忽略。需要在入口旁用聊天气泡做轻量引导，文案固定提示「点击此处使用农屿AI功能」。

---

## 2. 目标

1. 气泡从农屿 AI 圆钮附近冒出，文案固定：**点击此处使用农屿AI功能**。
2. **每次进入 App** 在满足展示条件时提示一次（见 §4.1）。
3. App **前台**期间每隔 **3 分钟**再提示一次（见 §4.2）。
4. 视觉为聊天气泡（尖角指向 AI 圆钮），带轻微弹出动效；可自动消失或点击关闭。

---

## 3. 边界（非目标）

- 「不再提醒」写入本地 MMKV；登出 / Token 失效清会话时清除，之后可再提示。
- 不接后台配置文案；文案写死在客户端。
- 不编写 tech / plan；仅本 Spec。
- 不改 AI 页业务能力、不改登录鉴权。
- 不做与系统通知 / Push 相关能力。

---

## 4. 详细需求

### 4.1 「进入 App」触发（均要触发）

在**当前展示自定义底栏**（主壳 Tab：home / course / center / mine）时，下列场景各触发一次展示：

| 场景                         | 说明                                |
| ---------------------------- | ----------------------------------- |
| 冷启动进入主壳               | App 进程启动后首次进入带底栏界面    |
| 从后台回到前台               | `AppState` active，且当前路由有底栏 |
| 进入主壳（含登录后落地主壳） | 路由进入带底栏的 Tab 容器           |

**抑制：** 当前路由为 `/ai` 或其它**不展示底栏**的页面时，**不展示**气泡。

### 4.2 周期提示（3 分钟）

| 项         | 要求                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------- |
| 间隔       | **3 分钟**（180s）                                                                           |
| 计时       | **仅 App 处于前台（active）时累计**；进入后台暂停，回前台继续或按进入规则立即提示（见下）    |
| 展示条件   | 与 §4.1 相同：必须当前有底栏；在 AI / 无底栏页不弹、不计满后的弹出                           |
| 重置       | 每次成功展示气泡后，重新开始下一轮 3 分钟计时                                                |
| 与进入重叠 | 因「进入」刚展示过时，3 分钟计时从该次展示结束（或开始展示）起重新计；避免同一时刻叠两个气泡 |

回前台时：若满足底栏条件，按 §4.1 **立即提示一次**，并重置 3 分钟计时。

### 4.3 展示与关闭

| 项           | 要求                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------ |
| 文案         | 固定：`点击此处使用农屿AI功能`；**打字机逐字出现**；打字中末字略大（+2），打完字号统一           |
| 位置         | 位于 AI 圆钮**上方**；气泡本体**水平展开**（与底栏 Tab 平行）；尖角朝下指向圆钮                  |
| 动效         | 出现：轻微缩放 + 淡入；消失：淡出；文案另有打字机（体感轻快即可）                                |
| 自动关闭     | 默认展示 **1 分钟**后自动消失；点「不再提醒」或「我知道了」可提前关闭                            |
| 点击文案     | 关闭气泡，并等同点击 AI 入口（进入 `/ai`）                                                       |
| 「不再提醒」 | 关闭气泡并写入 MMKV；之后不再按进入/回前台/3 分钟规则弹出；**主动登出或 Token 失效清会话时清除** |
| 「我知道了」 | 仅关闭本次气泡，不持久化，之后仍可再提示                                                         |
| 点击 AI 钮   | 若气泡可见则先关闭，再进入 `/ai`                                                                 |
| 叠层         | 气泡在底栏之上、不挡住四个 Tab 的主要点击区；不得穿透到错误页面层级                              |
| 单例         | 同一时刻最多一个引导气泡                                                                         |

### 4.4 视觉

- 聊天气泡形态（圆角矩形 + 指向 AI 钮的小三角/尖角）。
- 浅色表面（可用白/霜白或轻品牌浅色），文案清晰可读，字号偏小、单行或最多两行不截断关键句。
- 不做成系统 Toast；须视觉锚定在 AI 入口旁。

### 4.5 工程约束

- 实现挂在底栏壳层（如 `FloatingTabBar` 旁）或同等壳层组件，保证有底栏时才能看到。
- 使用已有 `react-native-reanimated` 做进出场即可；不新增重型依赖。
- 跳过 tech / plan；用户确认本 Spec 后直接编码。
- `type-check` / 仓库 lint·format 约定通过。

---

## 5. 业务流程

```text
进入带底栏主壳（冷启动 / 登录落地 / 回前台）
  → 展示 AI 引导气泡（若当前有底栏）
  → 启动/重置前台 3 分钟计时
  → 默认展示 1 分钟后自动关闭，或点「不再提醒」/「我知道了」关闭；点提示文案/AI 钮则进 /ai
  → 「不再提醒」写入本地后本会话期内（至登出）不再弹出；「我知道了」仅关本次

前台满 3 分钟且仍有底栏
  → 再次展示气泡 → 重置计时

进入 /ai 或无底栏页
  → 不展示；周期计时暂停或不触发弹出

返回带底栏页
  → 可按「进入」或周期规则在适当时机再提示
```

## 6. 验收标准与测试方案

### 6.1 UI

- [ ] 气泡在 AI 圆钮**上方**、水平展开并与 Tab 平行，尖角朝下指向圆钮，文案为「点击此处使用农屿AI功能」。
- [ ] 出现/消失有轻微动效，不突兀。
- [ ] 同时最多一个气泡。

### 6.2 功能

- [ ] 冷启动进主壳会提示一次。
- [ ] App 进后台再回前台（当前有底栏）会再提示一次。
- [ ] 登录后进入主壳会提示一次。
- [ ] 在 `/ai`（无底栏）时不提示。
- [ ] 前台停留约 3 分钟后再提示；后台期间不计时。
- [ ] 默认展示约 1 分钟后自动消失；「我知道了」仅关本次；「不再提醒」持久化后杀进程/回前台/满 3 分钟均不再弹；登出后再登录可再弹。
- [ ] 点提示文案或 AI 钮进入 AI。

### 6.3 工程

- [ ] `pnpm --filter nongyu-rn-app type-check` 通过。
- [ ] 仓库约定 lint / format 通过。
- [ ] 仅 Spec + PRD，无独立 tech/plan。
