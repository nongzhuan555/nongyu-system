## 1. 背景

回复 / 留言能力与 toast 轮询已落地，「我的」仅有「我的帖子」入口。用户缺少固定路径回看：**收到的回复**（他人留言 + 管理员回复）与 **我对他人的留言**。本期补齐入口与双 Tab 列表页。

## 2. 目标

1. 「我的 → 更多服务」增加「留言与回复」入口（紧挨「我的帖子」之后）。
2. 新路由页：双 Tab「收到的 / 我发出的」，默认「收到的」；分页列表；点进帖子详情。
3. 「我发出的」支持列表内删除（二次确认，复用既有 `deleteComment`）。
4. 复用 `appFetch` / TanStack Query / toast / confirm / 主题 token / 列表空态与加载模式（对齐「我的帖子」/`PostFeedList` 习惯）。
5. 遵守大院匿名与「管理员回复」文案约定。

## 3. 边界（非目标）

- 不做入口未读角标 / 红点。
- 不做「收到的」列表内删除。
- 不做推送；不改 `PostRepliesPollerHost` 行为。
- 不做楼中楼、编辑留言、富文本。
- 不改广场详情页既有留言 UI（仅跳转复用）。
- 跳过独立 tech 文档（本 Spec 确认后写 plan 再编码）。

## 5. API 封装

在 `src/modules/center/api/postReplies.ts`（或并列新建 list 类型同文件）扩展：

```ts
export type MyPostReplyListItem = {
  replyId: number;
  postId: number;
  postType: "feedback" | "courtyard";
  postTitle: string;
  kind: "admin_reply" | "comment";
  content: string;
  publishedAt: string;
};

export type PageResult<T> = {
  list: T[];
  total: number;
  page: number;
  pageSize: number;
};

/** GET /api/app/users/me/post-replies/received */
export function fetchReceivedPostReplies(params?: {
  page?: number;
  pageSize?: number;
}): Promise<PageResult<MyPostReplyListItem>>;

/** GET /api/app/users/me/post-replies/sent */
export function fetchSentPostReplies(params?: {
  page?: number;
  pageSize?: number;
}): Promise<PageResult<MyPostReplyListItem>>;
```

删除：复用既有 `deleteComment(postId, commentId)`（即当前 `deleteComment` / `DELETE .../comments/:id`）。

## 6. UI / 交互详细需求

### 6.1 页面骨架

- 顶栏：使用 `SettingsPageShell`（返回 + 居中标题「留言与回复」+ `TabScreenBackground`）；须在 `app/_layout.tsx` 注册 `mine/replies` 且 `headerShown: false`，避免系统顶栏露出路由名。
- 顶栏下 Segment / Tab：**收到的** | **我发出的**（品牌色实心选中 + 图标）；默认选中「收到的」。
- 列表项视觉对齐 `PostCard`（surface 圆角卡片 + 类型 chip +「查看原帖」）。
- 切换 Tab 保留各自列表缓存（TanStack Query 分 key）；下拉刷新当前 Tab。
- 空态：图标 + 主文案 + 一句说明。
  - 收到的：「还没有收到回复」/「别人回复你的帖子后会显示在这里」
  - 我发出的：「你还没有留言」/「你在大院给他人留言后会出现在这里」
- 加载失败：列表内错误态 + 可重试（与「我的帖子」一致优先）。

### 6.2 列表项

共用弱分隔列表（非卡片堆叠；对齐 `CommentList` / 我的页列表气质）：

| 区域     | 收到的                                               | 我发出的                   |
| -------- | ---------------------------------------------------- | -------------------------- |
| 主标题   | 帖标题（单行省略）                                   | 同左                       |
| 标签     | `kind==='admin_reply'` →「管理员回复」；否则「留言」 | 可不展示或固定「我的留言」 |
| 摘要     | `content` 去 HTML 后截断约 80 字                     | 同左                       |
| 时间     | `formatPublishedAt(publishedAt)`                     | 同左                       |
| 右侧操作 | 无                                                   | 「删除」文字按钮（危险色） |

- 整行可点（删除按钮除外）→ 跳转帖详情（与 `PostCard` / toast 跳转同一详情路由）。
- 摘要截断在客户端做；服务端返回全文。

### 6.3 删除（仅我发出的）

1. 点「删除」→ `confirm`：「确定删除这条留言？」
2. 确认后调用 `deleteComment(postId, replyId)`。
3. 成功：toast「已删除」；乐观移除该项或 invalidate `sent` query。
4. 失败：toast 错误信息；回滚乐观更新（若做了乐观）。

### 6.4 匿名与文案

- 列表与跳转后详情均不展示留言者身份（详情页已有约定）。
- 收到的管理员回复标签文案固定「管理员回复」。

### 6.5 工程落点建议

| 路径                                                                  | 职责                                |
| --------------------------------------------------------------------- | ----------------------------------- |
| `app/mine/replies.tsx`                                                | 路由薄封装                          |
| `src/modules/center/screens/MyRepliesScreen.tsx`（或 `mine/screens`） | 双 Tab 页                           |
| `src/modules/center/components/MyReplyListItem.tsx`                   | 列表行                              |
| `src/modules/center/api/postReplies.ts`                               | API                                 |
| `src/modules/mine/constants/services.ts`                              | 入口                                |
| `MineScreen`                                                          | 埋点 key `replies`（若按 key 分支） |

模块归属：业务数据属 center；入口属 mine。Screen 放 `center/screens` 更贴数据域（与 `MyPostsScreen` 一致）。

## 7. 业务流程

```
我的 → 留言与回复 → 默认「收到的」
  → fetchReceivedPostReplies
  → 点击项 → 帖详情

切「我发出的」
  → fetchSentPostReplies
  → 删除 → confirm → DELETE comment → 列表更新
```

## 8. 验收标准（理想 UI / 操作）

| #   | 操作                     | 期望                                                             |
| --- | ------------------------ | ---------------------------------------------------------------- |
| 1   | 已登录打开「我的」       | 「更多服务」见「留言与回复」，位于「我的帖子」下、「分享农屿」上 |
| 2   | 进入页面                 | 标题「留言与回复」；默认 Tab「收到的」                           |
| 3   | 有管理员回复 / 他人留言  | 「收到的」按时间倒序出现；标签正确；无作者名                     |
| 4   | 点列表项                 | 进入对应帖详情，可见完整回复 / 留言区                            |
| 5   | 「我发出的」有对他人留言 | 列表展示；可删                                                   |
| 6   | 删除成功                 | 该项消失；详情中该留言亦无（刷新后）                             |
| 7   | 空数据                   | 见对应空态文案                                                   |
| 8   | 未读角标                 | **无**                                                           |
| 9   | toast 轮询               | 行为与上线前一致                                                 |

视觉：川农绿 / 主题 token；列表弱分隔、无卡片堆叠；危险色仅用于删除。
