# Spec：设置页壳与课表偏好

| 项       | 内容                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                                                                 |
| 需求类型 | **基建**                                                                                             |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/MyPage/设置页面PRD.md`（壳）+ `Course/课表模块PRD.md`（背景图） |
| 入口     | 「我的」顶栏右上角设置 → `/mine/settings`                                                            |
| 状态     | **已实现（待人工回归）**                                                                             |

---

## 1. 背景

课表周视图已落地，但背景图、卡片尺寸、字号仍写死；设置页仍为占位。用户需要在统一设置体系中配置课表观感，并为后续「网页跳转 / 主题 / Agent」等分区预留入口。

**Why**：偏好与课表主路径解耦，避免课表页堆设置；设置 PRD 要求分区扩展。  
**What**：设置首页（分区列表）+「课表设置」子页（背景图 / 卡片大小 / 字体大小），并驱动周视图实时生效。

---

## 2. 目标

1. 替换 `/mine/settings` 占位为**设置首页**：多分区分组入口。
2. 实现可进入的「课表设置」子页；其余分区入口可见但标记「即将开放」（不可进或进占位说明）。
3. 课表偏好三项：周视图背景图（相册选图 + 清除）、卡片大小（小/中/大）、字体大小（小/中/大）；默认均为「中」、无背景图。
4. 偏好持久化；课表 Tab 读取后立即反映（含背景遮罩保证可读性）。
5. 目录：设置壳落 `src/modules/settings/`（或 `mine/settings` 下清晰子目录）；课表偏好状态与课表模块共享契约。

---

## 3. 边界（非目标）

- 主题切换、首屏是否课表、用户反馈渠道的**真实功能**（本轮仅灰显入口；网页打开见独立 Spec）
- Agent / API Key（见独立 Spec）
- 课程卡片「统一配色」开关
- 在课表页内再做一套完整设置 UI（开学日 / 当日列高亮可保留课表页快捷入口）
- 云端同步偏好
- iCloud/相册权限文案的法务长文（系统权限对话框即可；失败 Toast）

---

## 4. 详细需求

### 4.0 Grill 共识

| 决策   | 结论                                              |
| ------ | ------------------------------------------------- |
| 范围   | 设置壳 + 课表设置三项；其它分区即将开放           |
| 导航   | 设置首页列表 → 子页（非单页堆满）                 |
| 背景   | 相册选图 + 清除；半透明遮罩                       |
| 档位   | 卡片/字号均为 小/中/大，默认中                    |
| 作用域 | 卡片大小→行高；字号→卡片内三字段；表头/时间列不变 |
| 文档   | 本 Spec + 修订课表 Spec                           |

### 4.1 路由

| 界面     | 路由                                    | 说明                                    |
| -------- | --------------------------------------- | --------------------------------------- |
| 设置首页 | `/mine/settings`                        | 分区列表                                |
| 课表设置 | `/mine/settings/course`（或等价 Stack） | 本轮唯一可进业务子页                    |
| 其它分区 | 可选 `/mine/settings/*` 占位            | 或首页项 `disabled` + Toast「即将开放」 |

「我的」齿轮已指向 `/mine/settings`，保持不变。

### 4.2 设置首页

分区建议（可微调文案，结构需保留）：

| 分区       | 状态                                           |
| ---------- | ---------------------------------------------- |
| 课表设置   | **可进入**                                     |
| 网页跳转   | **可进入**（见 `specs/网页跳转设置.md`）       |
| 主题与外观 | `/mine/settings/theme`                         |
| 农屿 Agent | 即将开放                                       |
| 关于与反馈 | 即将开放（或「关于」仍走现有外链，本轮不强制） |

列表项：标题 + 可选一行说明；可进项有 chevron；不可进项次要样式 +「即将开放」。

### 4.3 课表设置子页

1. **背景图**
   - 「选择图片」：系统相册（`expo-image-picker`）
   - 「清除背景」：无图时禁用或隐藏
   - 可选缩略图预览当前背景
2. **卡片大小**：分段控件 小 / 中 / 大（默认中）
3. **字体大小**：分段控件 小 / 中 / 大（默认中）
4. 变更即时写入本地；返回课表 Tab 无需额外「保存」按钮（改即生效）

### 4.4 周视图消费偏好

| 偏好            | 效果                                                |
| --------------- | --------------------------------------------------- |
| 背景图 URI 有值 | 课表内容区底层铺图 + **半透明浅色遮罩**，其上为网格 |
| 无 URI          | 保持现有渐变/纯色底（与今一致）                     |
| 卡片大小        | 大课区间行高：小 &lt; 中(≈当前 88) &lt; 大          |
| 字体大小        | 卡片内课名/教师/教室字号三档；表头与左侧时间列不变  |

### 4.5 持久化（契约级）

至少持久化：

- `courseBackgroundUri: string \| null`
- `courseCardSize: "sm" \| "md" \| "lg"`
- `courseFontSize: "sm" \| "md" \| "lg"`

登出时：**课表背景图**须清除（文件 + URI，与 `课表扩展-自定义日程备注待办` G5 对齐）；卡片大小 / 字号等非敏感观感偏好仍默认保留。

---

## 5. 业务流程

```text
我的 → 设置齿轮 → 设置首页
  → 点「课表设置」→ 子页
       → 选图 / 清除 / 改档位 → 本地持久化
课表 Tab 订阅偏好 → 重算行高/字号/背景层
点「即将开放」分区 → Toast 或占位说明，不崩溃
```

---

## 6. 验收标准

- [ ] `/mine/settings` 不再是笼统占位文案，可见分区列表且「课表设置」可进。
- [ ] 其它列出的分区不可完成真实配置，并标明即将开放。
- [ ] 可选背景图；课表周视图可见该图 + 遮罩下文字仍可读。
- [ ] 可清除背景，恢复无自定义图。
- [ ] 卡片小/中/大改变行高；字号小/中/大改变卡片文字；默认中。
- [ ] 杀进程重开后偏好仍在。
- [ ] 表头与时间列不随字号档位明显变大。
- [ ] 未授权相册时有失败提示，不白屏。

### 理想 UI

- 设置首页干净列表，分区标题清晰，无仪表盘卡片墙。
- 课表设置子页：背景一块、尺寸两行分段，留白克制。
