# Spec：登录页 UI 对齐旧版

| 项       | 内容                                                                |
| -------- | ------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                                |
| 需求类型 | **业务**（视觉对齐）                                                |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/User/登录登出PRD.md`           |
| 参照     | `old-code/nongyu/src/modules/Profile` 未登录壳 + `JiaowuLoginProbe` |
| 状态     | **已实现（高级简约优化）**                                          |

---

## 1. 背景

新版 `/login` 仅为简洁表单；需暂时对齐旧版「我的」内嵌登录观感，后续再单独做 UI 优化。

---

## 2. 目标

1. 全局登录页视觉对齐旧版：顶渐变、Logo、时段问候、「欢迎来到农屿」、副文案 + 表单区。
2. 表单对齐旧版：描边圆角输入、密码显隐、「进入农屿」胶囊按钮、登录中状态文案、本地密码承诺提示。
3. 登录成功/失败仍走现有 `performJiaowuLogin` + toast；成功后进入首页（不可 `back` 回未登录主界面）。

---

## 3. 边界

- 不迁移旧版顶部长时 Banner、课表清空 Dialog、调试 logs。
- 不改教务页内 `JiaowuLoginForm compact` 的职责（仍紧凑嵌入）。
- 本次不做视觉「升级」，仅对齐旧版结构与层次。

---

## 4. 详细需求

### 4.1 页面壳（`LoginScreen`）

- 背景：柔和三色渐变（`primaryContainer` → 近底色 → `background`）。
- **无 App 图标、无顶部「农屿」字标**。
- 顶区文案：时段问候 +「用教务身份进入」+ 一句隐私说明。
- 下接全宽表单（非 compact）。

### 4.2 表单（非 compact）

- 学号 / 密码：**下划线输入**（无描边圆角块）；密码可显隐。
- 学号须为 9 位数字：**仅在提交时校验**；输入过程不实时标红、不因未满 9 位禁用主按钮（有密码且未提交中即可点）。
- 主按钮文案「进入」，圆角约 14、克制字重。
- 仅提交中展示状态文案。
- 底部一行隐私提示（无盾牌图标）。

### 4.3 路由

- `app/login.tsx` 引用 `LoginScreen`；**全屏**，非 modal。已登录访问则重定向首页。
- 未登录由根门禁直接渲染登录页，见 `specs/登录门禁.md`。

---

## 5. 验收

- [ ] 登录页无 App 图标；字标「农屿」可见。
- [ ] 观感高级简约（少装饰、下划线输入）。
- [ ] 教务页 compact 登录仍可用。
- [ ] 登录成功/失败行为与改前一致。
