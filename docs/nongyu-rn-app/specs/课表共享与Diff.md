# Spec：课表共享与 Diff

| 项       | 内容                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------ |
| 应用     | `apps/nongyu-rn-app` + `apps/nongyu-node-server`                                                                   |
| 需求类型 | **业务**                                                                                                           |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/Course/课表共享与Diff.md`                                                     |
| 关联     | `specs/课表周视图.md`、`specs/课表与用户数据存储约定.md`、`specs/设置页壳与课表偏好.md`、`specs/AI教务卡片渲染.md` |
| 状态     | **已实现（含 Agent 对比 Tool，待人工回归）**                                                                       |

---

## 1. 背景

**Why**：同学间约活动需要知道彼此课表与空档；截图传递成本高、难 Diff。  
**What**：用户 opt-in 后远端存一份原始课表快照；他人凭学号只读查看；可在周视图上与自己课表叠色对比。

现有约定「课表 JSON 不上云」将修订为：**默认仅本地；用户显式开启共享时可上传原始课表快照**（见 §4.8）。

---

## 2. 目标

1. 课表设置中可开关「允许课表共享」；开启需隐私确认；无本地课表时不可开启。
2. 开启后远端持久化当前 `CourseEntry[]`；关闭后不可查且删除远端 JSON。
3. 课表页可进入「查看他人课表」：输入 9 位学号拉取对方原始课表，只读周视图展示。
4. 查看他人模式下可切换 Diff：默认「冲突叠色」，可切「空闲交集」；周次与对方课表周控件同步。
5. 查找仅登录用户可用；错误文案统一；查询限流（具体数值在技术方案定）。
6. Agent 可通过只读 Tool `course_share_diff` 按学号对比课表；对话内卡片展示空档/冲突；可跳转课表打开 Diff。不开/关共享。

---

## 3. 边界（非目标）

- 二维码 / 海报分享
- 历史学期多份快照、学期切换存储
- 昵称 / 真实姓名对外展示
- 共享或查看备注、待办、自定义日程
- 通过 Agent 开启 / 关闭课表共享（仍走设置页隐私确认）
- 单独的「只查看他人课表、不做 Diff」Agent Tool（查对方即走对比 Tool）
- 他人课表写入 MMKV / 长期缓存
- 未登录公开查询
- 推送「有人查看了你的课表」

---

## 4. 详细需求

### 4.0 Grill 共识

| 决策      | 结论                                                                                           |
| --------- | ---------------------------------------------------------------------------------------------- |
| 类型      | 业务                                                                                           |
| 文档      | 新短 PRD + 本 Spec + 技术方案                                                                  |
| 共享内容  | 仅 `CourseEntry[]`                                                                             |
| 存储      | MySQL 每用户一行 JSON 快照；关共享删 JSON                                                      |
| 开关位置  | 课表设置；二次确认；无本地课表不可开                                                           |
| 查找      | 已登录 + `student_no`（9 位）；顶栏只显示学号                                                  |
| 查自己    | 允许（便于自测）                                                                               |
| 查看模式  | 只读周视图；隐藏编辑/加日程/备注/待办等                                                        |
| 开学日    | 查看他人 / Diff 一律用**当前用户**本地开学日，不读对方                                         |
| 他人详情  | 仅课程基本信息；不渲染备注 / 待办 / 考勤等扩展区                                               |
| Diff 退出 | 顶栏「退出对比」（原「对比课表」槽位）；不与「回到本周」半圆抢右缘                             |
| Diff      | 同网格叠色；冲突（默认）+ 空闲；跟周切换                                                       |
| 枚举防护  | 统一「未找到可查看的课表」+ 限流                                                               |
| 存储约定  | 修订为 opt-in 可上传快照                                                                       |
| Agent     | 只读 `course_share_diff`；错开=空档；只说对比则两种摘要都返回；卡片可跳课表 Diff；不自动切 Tab |

### 4.1 数据契约

**共享载荷**：与本地课表相同的 `CourseEntry[]`（见课表周视图 Spec）。

**不含**：`ScheduleEntry` / `CourseNote` / `CourseTodo`。

**远端逻辑模型（规格层，不绑表名）**：

| 字段         | 含义                                   |
| ------------ | -------------------------------------- |
| ownerUserId  | 所属用户                               |
| studentNo    | 学号（查找键）                         |
| shareEnabled | 是否允许被查                           |
| courses      | `CourseEntry[]` 或空（关闭后应无载荷） |
| updatedAt    | 快照更新时间（展示新鲜度）             |

每用户**仅一份**当前学期快照；强制刷新教务且仍开启共享时覆盖写。

### 4.2 共享开关（设置）

| 项               | 约定                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| 入口             | `/mine/settings/course`（课表设置）                                                              |
| 控件             | 「允许课表共享」开关                                                                             |
| 开启             | 先隐私确认（说明：仅原始课表、可被学号查找、可随时关闭）；确认后上传当前本地课表；成功后开关为开 |
| 无本地课表       | 不允许开启；提示先到课表页获取/刷新课表                                                          |
| 关闭             | 远端 `shareEnabled=false` 并删除 `courses`；本地开关为关                                         |
| 课表强制刷新成功 | 若当前仍开启共享，自动覆盖远端快照                                                               |

### 4.3 查找与拉取

| 项   | 约定                                                                    |
| ---- | ----------------------------------------------------------------------- |
| 入口 | 课表 Tab 内「查看他人课表」（具体控件形态技术方案/UI 实现定，须可发现） |
| 输入 | 9 位数字学号；格式错误本地拦截                                          |
| 鉴权 | 必须已登录 App                                                          |
| 成功 | 返回对方 `studentNo`、`courses`、`updatedAt`；进入只读周视图            |
| 失败 | 统一文案：**「未找到可查看的课表」**（不区分无用户 / 未开启 / 无快照）  |
| 限流 | 按查询用户限流；超限提示稍后再试（阈值技术方案定）                      |

### 4.4 只读周视图（查看他人）

| 项       | 约定                                                                                                                                                                                                                                  |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 网格     | 复用现有周视图；数据源为对方 `courses`，**不合并**本人扩展数据                                                                                                                                                                        |
| 顶栏     | 标明正在查看 `{studentNo}`；展示快照 `updatedAt`（相对或绝对时间均可）                                                                                                                                                                |
| 开学日   | **仅**使用当前登录用户本地开学日（与本人课表同一份设置）。共享载荷不含对方开学日，也不拉取对方偏好。未设置时与本人课表相同：默认第 1 周、表头不显示月日。查看他人时**不提供**开学日修改入口                                           |
| 周切换   | 与本人课表相同交互；已设开学日则默认当前教学周（按上一行开学日计算）；「回到本周」半圆位置、形状与本人课表一致                                                                                                                        |
| 课程详情 | 可点课程卡片；弹层**只渲染基本信息**（课名、教室、教师、节次时间、周次）。**整段不渲染**备注、待办（含标题、空状态、输入框）。后续考勤等扩展区块默认不出现（详情为基本信息白名单，除非单独改契约）。不得把本人备注/待办挂到对方课程上 |
| 禁用     | 添加/编辑/删除课程与日程、备注、待办、背景设置入口等写操作                                                                                                                                                                            |
| 退出     | 明确「返回我的课表」；退出后恢复本人数据与完整交互                                                                                                                                                                                    |
| 缓存     | 仅会话内存；不写 `course:entries:*`                                                                                                                                                                                                   |

### 4.5 Diff

| 项                     | 约定                                                                                                                                                                   |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 入口                   | 查看他人时，顶栏「对比课表」（与「返回我的课表」同在工具区）                                                                                                           |
| 基线                   | 本人本地 `CourseEntry[]` vs 对方快照                                                                                                                                   |
| 形态                   | 同一周网格叠色（非左右分屏）                                                                                                                                           |
| 模式 A（默认）冲突叠色 | 图例：仅自己 / 仅对方 / 双方都有课（冲突）                                                                                                                             |
| 模式 B 空闲交集        | 高亮双方该格均无课的时段（便于约时间）                                                                                                                                 |
| 图例条                 | 仅模式切换（冲突 / 空闲）+ 色点说明；**不放**「退出对比」                                                                                                              |
| 周次                   | 与当前只读周视图周次同步；开学日规则同 §4.4                                                                                                                            |
| 课程详情               | 与 §4.4 相同：仅基本信息，不渲染扩展区                                                                                                                                 |
| 退出 Diff              | 顶栏「退出对比」，占用原「对比课表」槽位，回到「仅看对方」只读视图。另可「返回我的课表」直接退出查看他人。禁止把「退出对比」放在图例条右缘，以免与「回到本周」半圆重叠 |

单元格「有课」判定：与现有 `weekMatches` / 周矩阵构建规则一致（含单双周、weeks / weeksList）。

### 4.9 Agent 对比 Tool

**工具名**：`course_share_diff`（只读，无需用户审批）。

**何时调用**（写入 Agent system prompt）：

| 用户说法               | `mode`                        |
| ---------------------- | ----------------------------- |
| 错开 / 空档 / 一起有空 | `free`                        |
| 撞课 / 冲突            | `conflict`                    |
| 只说「对比」未指明     | `both`（冲突摘要 + 空档摘要） |

不把「仅自己有课 / 仅对方有课」称为错开。

**入参**：

| 字段        | 约束                                                                                             |
| ----------- | ------------------------------------------------------------------------------------------------ |
| `studentNo` | 必填，9 位数字；非法则工具失败，提示输入 9 位学号                                                |
| `week`      | 可选，1-based 教学周。省略则用**当前用户开学日**算当前周；未设开学日则第 1 周（与课表页一致）    |
| `weeks`     | 可选。`all` 表示整学期：按周汇总冲突/空档格数，不把全部格子塞进对话；与 `week` 互斥时 `all` 优先 |
| `mode`      | 可选：`conflict` / `free` / `both`。省略视为 `both`                                              |

**执行**：

1. 须已登录；须有本人本地 `CourseEntry[]`，否则提示先到课表页获取课表。
2. 调用现有按学号拉取（与课表页同一 API / 同一限流 / 同一失败文案 **「未找到可查看的课表」**）。
3. 开学日只用当前用户本地设置（同 §4.4）。
4. 占用判定与 `buildDiffOverlay` 相同（含单双周）。
5. 不返回对方姓名、备注、待办、自定义日程、完整 `CourseEntry[]`（对话里给可读时段即可）。

**成功输出（规格层）**：

| 字段                         | 含义                                                     |
| ---------------------------- | -------------------------------------------------------- |
| studentNo / updatedAt / week | 对方学号、快照新鲜度、本次计算周（`all` 时 week 可省略） |
| mode                         | 实际使用的模式                                           |
| conflictSlots                | `mode` 含 conflict 时：双方都有课的格（星期、节次）      |
| freeSlots                    | `mode` 含 free 时：双方都空的格                          |
| counts                       | 冲突格数、空档格数（`all` 时按周数组）                   |

单周列表在卡片内最多展示前 **8** 条 + 「在课表中打开对比」；Agent 文本可概括，不复述全部格子。

**卡片**：

- 加载 / 失败 / 空数据（该周无冲突也无空档）均有态。
- 标题含学号与周次；分块列出冲突 / 空档（视 mode）。
- 「在课表中打开对比」：`router.push` 课表 Tab，写入 peer 快照并进入 Diff（`free` 则 Diff 模式为空闲，否则冲突），定位到对应周。**不**因 Tool 成功而自动切 Tab。
- 点击不回流 Agent 写操作。

**system prompt**：对比 / 错开 / 撞课某学号课表时必须调用 `course_share_diff`，不要用纯文本编造对方课表。

### 4.6 API 行为（规格）

须支持至少：

1. **设置自己的共享状态**
   - 开：上传当前 `courses`，`shareEnabled=true`
   - 关：`shareEnabled=false` 且删除载荷
2. **查询自己的共享状态**（设置页回显）
3. **按学号拉取可查看课表**（仅当对方开启且有载荷）

鉴权：App JWT。禁止返回对方真实姓名、备注/待办/自定义日程。

### 4.7 前端模块落点（规格）

| 区域  | 约定                                                                         |
| ----- | ---------------------------------------------------------------------------- |
| 设置  | 课表设置页增加共享开关与状态                                                 |
| 课表  | 查看他人入口、只读模式、Diff 模式状态机                                      |
| 数据  | 共享 API 客户端；与 `courseLocalStore` 分离（他人数据不写本地课表 key）      |
| Agent | 只读 Tool `course_share_diff` + 对话卡片；复用 `lookupPeer` 与 Diff 占用矩阵 |
| 同步  | 本地课表强制刷新成功且共享开启 → 触发快照覆盖                                |

### 4.8 文档修订

同步修订 `specs/课表与用户数据存储约定.md`：

- 默认：课表本体仍只存本地
- 例外：用户 opt-in「课表共享」时可上传**原始课表快照**至远端；关闭则删除
- 扩展数据（备注/待办/日程）的共享不在本需求范围

## 5. 业务流程

### 5.1 开启共享

```
用户打开课表设置 → 开「允许课表共享」
  → 无本地课表？→ 提示去课表页获取 → 结束
  → 隐私确认取消？→ 结束
  → 上传 CourseEntry[] → 成功则开关开 / 失败则保持关并 Toast
```

### 5.2 查看他人

```
课表页 → 查看他人 → 输入学号 → 请求
  → 失败/限流 → Toast 统一或限流文案
  → 成功 → 只读周视图（对方 courses）
       → 可切周 / Diff / 返回我的课表
```

### 5.3 Diff

```
只读查看中 → 对比课表
  → 默认冲突叠色（本人本地 + 对方快照，当前周）
  → 可切空闲交集
  → 切周同步重算
  → 退出 Diff / 返回我的课表
```

### 5.4 关闭共享

```
设置关开关 → API 关闭并删远端 JSON → 本地开关关
（他人再查得到统一失败文案）
```

### 5.5 Agent 对比

```
用户在 AI 对话说「对比 {学号} / 找出错开的课」
  → 调用 course_share_diff
  → 学号非法 / 未登录 / 无本地课表 → 工具错误，Agent 转述
  → 对方不可查 / 限流 → 「未找到可查看的课表」或稍后再试
  → 成功 → 对话内对比卡片 + 自然语言摘要
       → 用户可点卡片进入课表 Diff（不自动跳转）
```

## 6. 验收标准与测试方案

### 6.1 设置与同步

- [ ] 无本地课表时无法开启，有明确提示
- [ ] 开启需确认；确认后远端可被查到本人学号对应课表
- [ ] 关闭后他人立刻不可查；库侧无残留 courses（技术方案用测试/查询验证）
- [ ] 开启状态下强制刷新课表成功后，他人看到的是新快照（`updatedAt` 更新）

### 6.2 查找与隐私

- [ ] 未登录不能查
- [ ] 未开共享 / 错误学号 / 无用户：同一失败文案
- [ ] 成功响应不含姓名、不含扩展实体
- [ ] 顶栏仅学号 + 新鲜度
- [ ] 触发限流后有提示且不再返回课表

### 6.3 只读周视图

- [ ] 对方课程按周正确落格（与本人周视图规则一致）
- [ ] 第 N 周表头月日、「当前周」「回到本周」与本人课表使用同一开学日
- [ ] 看不见也不出现本人/对方的备注、待办、自定义日程
- [ ] 点课程卡片：详情只有基本信息；无备注/待办/考勤区块（含空状态与输入框）
- [ ] 无法进行写操作；可返回我的课表并恢复写能力
- [ ] 查自己学号可进入只读副本（若已开共享）

### 6.4 Diff

- [ ] 默认冲突叠色；图例可理解
- [ ] 空闲模式高亮双方皆空格
- [ ] 切周后 Diff 结果随周变化
- [ ] 单双周课程判定与周视图一致
- [ ] 「退出对比」在顶栏原「对比课表」位置；图例条无退出按钮
- [ ] 非本周时「回到本周」半圆与「退出对比」不重叠、均可点
- [ ] Diff 下点课程卡片同样仅基本信息

### 6.5 UI 理想描述

- 课表设置：一行开关 + 简短说明（谁能看、看什么、可关闭）
- 课表页：可发现的「查看他人」入口 → 学号输入 → 进入后顶栏强提示「正在查看 xxx」
- 只读详情：大半屏弹层仅课名 + 教室/教师/节次/周次标签，无下方扩展列表
- Diff：顶栏进出对比（对比课表 ⇄ 退出对比）+ 标题下方模式切换与色点；「回到本周」半圆仍贴右缘、位置与本人课表相同；避免左右分屏
- Agent 卡片：学号 + 周次 + 冲突/空档时段（最多 8 条）+ 底部「在课表中打开对比」；失败文案与课表页查找失败口径一致

### 6.6 Agent 对比 Tool

- [ ] 「帮我对比一下 {9位学号} 的课表，找出我们错开的课」会调用 `course_share_diff`（`mode=free`），对话出现卡片而非编造课表
- [ ] 「看看和某某有没有撞课」走 `conflict`；只说对比则 `both`，卡片含冲突与空档两块
- [ ] 非法学号本地失败；未开共享等与 App 同一文案
- [ ] 卡片不含姓名 / 备注 / 待办；不因成功自动打开课表 Tab
- [ ] 点「在课表中打开对比」进入对该学号的 Diff，周次与 Tool 一致
- [ ] 整学期查询按周汇总，对话不被格子清单撑爆
- [ ] 开/关共享不能通过 Agent 完成
