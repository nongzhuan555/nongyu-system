# Spec：分享农屿

| 项       | 内容                                                           |
| -------- | -------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                           |
| 需求类型 | **业务**（面板）+ **基建**（微信原生模块 / scheme / 启动注册） |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/MyPage/分享农屿PRD.md`    |
| 参照     | `old-code/nongyu/src/components/ShareSheet`（裁剪能力）        |
| 状态     | **已实现**                                                     |

---

## 1. 背景

新版「我的」中「分享农屿」仅 Toast 占位。旧版已有微信网页分享 + 复制链接，需迁入新版以便用户向同学推荐 App / 官网。

---

## 2. 目标

1. 点击「分享农屿」弹出底部分享面板（替代 Toast 占位）。
2. 支持三项操作：**微信好友**、**朋友圈**、**复制链接**。
3. 网页分享目标 URL 为农屿官网：`http://nongyu.site/`。
4. 接入微信原生 SDK（`expo-native-wechat` 或与 Expo 57 兼容的等价方案），启动时 `registerApp`；无原生模块 / 未装微信时有明确降级提示。
5. 关键作可走现有 Telemetry（`trackClick`），不阻塞主流程。

---

## 3. 边界（非目标）

- 不做海报、截屏、保存相册、系统分享。
- 不改课表「分享」入口语义（仍为查同学课表）。
- 不做微信登录 / 支付 / 小程序分享。
- 本期不以 iOS Universal Link 完整联调为硬门禁（Android 真机优先）；但配置项与 scheme 须预留，避免二次大改。
- 不编写独立 tech 文档。
- 不在本需求内完成微信开放平台后台操作（签名更新由人类在控制台完成）。

---

## 4. 详细需求

### 4.1 入口

| 位置                           | 行为                                     |
| ------------------------------ | ---------------------------------------- |
| 「我的」→ 更多服务「分享农屿」 | 打开分享面板；**不再** Toast「即将上线」 |

未登录态：当前「我的」主路径已登录才展示服务列表；不单独为访客增加分享入口。

### 4.2 分享面板 UI

- 底部弹出 Sheet（可用 `@gorhom/bottom-sheet` 或与现有课程 Sheet 一致的 Modal Sheet 模式）。
- 标题：「分享给好友」。
- 三个操作入口（图标 + 文案）：
  1. 微信好友
  2. 朋友圈
  3. 复制链接
- 提供「取消」关闭面板。
- 点击遮罩关闭。
- 视觉：使用现有 `ThemeTokens` / `createThemedStyles`，对齐「我的」页简洁风格；避免默认紫色/卡片堆砌。

### 4.3 复制链接

- 将 `http://nongyu.site/` 写入剪贴板（`expo-clipboard`）。
- Toast 成功：「链接已复制」。
- 完成后关闭面板。

### 4.4 微信网页分享

常量（沿用旧版）：

| 字段           | 值                                                          |
| -------------- | ----------------------------------------------------------- |
| AppID          | `wx174b5a4d92447b73`（可配置化，禁止散落魔法字符串多处）    |
| Universal Link | `https://nongyu.app/`（register 用；iOS 后续联调）          |
| webpageUrl     | `http://nongyu.site/`                                       |
| title          | `农屿 - 专属川农er的校园助手`                               |
| description    | `无广告课表、教务二课数据集成、智能AI助手，在农屿都能得到~` |
| thumb          | App icon（可压缩后作缩略图；失败则尽力用原图 URI）          |
| scene          | 好友 `0`；朋友圈 `1`                                        |

行为：

1. **iOS**：本期**不支持**微信好友 / 朋友圈。面板展示提示「iOS 暂仅支持复制链接分享」；点击微信入口 Toast「暂不支持」+「iOS 暂不支持分享到微信和朋友圈，请使用「复制链接」」；底层 `shareNongyuWebpage` 亦拒绝 iOS 调用。仅「复制链接」可用。
2. **Android**：若原生微信模块不可用：Toast / Alert 提示需使用 Dev Client 或正式包；**不**假装成功。
3. 若微信未安装：Toast「未检测到微信客户端，请先安装」。
4. 分享成功或由微信返回后关闭面板；失败 Toast 简要错误信息。
5. 操作进行中防重复点击。

### 4.5 基建：工程配置

1. 依赖：接入 `expo-native-wechat`（若与 New Arch / Expo 57 不兼容，在 Spec 实施时选官方文档推荐的等价 Expo 模块，并在本 Spec「变更记录」注明）。
2. `app.json`：
   - plugins 增加微信插件；
   - **在保留现有 `nongyu` scheme 的同时**，增加微信回跳 scheme：`wx174b5a4d92447b73`（多 scheme）。
3. App 启动路径（如根 layout / bootstrap）调用一次 `registerApp({ appid, universalLink })`；失败仅 `console.warn`，不阻断启动。
4. 封装 `src/` 下微信桥接模块（类似旧 `utils/wechat.ts`）：模块缺失时安全降级，禁止裸 `require` 拖垮 JS bundle。

### 4.6 埋点

| 时机         | 建议 eventName（或 props） |
| ------------ | -------------------------- |
| 打开分享面板 | `share_open`               |
| 点微信好友   | `share_wechat`             |
| 点朋友圈     | `share_moments`            |
| 点复制链接   | `share_copy_link`          |

埋点失败不得影响分享主流程。

### 4.7 工程结构建议

```text
src/modules/mine/
  components/ShareSheet.tsx      # 面板 UI
  constants/share.ts             # 官网 URL、文案常量
src/lib/wechat/                  # 或 modules/wechat/
  index.ts                       # register / isInstalled / shareWebpage
app.json / 启动注册
MineScreen.tsx                   # 挂载面板，去掉 Toast 占位
```

常量 `ABOUT_URL` 若已与官网相同，可复用，避免两处 URL 漂移。

---

## 5. 业务流程

```text
用户点「分享农屿」
  → trackClick(share_open)
  → 打开 ShareSheet
  → 分支：
      复制链接 → Clipboard → Toast 成功 → 关闭
      微信好友 / 朋友圈
        → 检查原生模块 / 是否安装微信
        → 失败：提示并保持或关闭（失败关闭面板亦可）
        → 成功：shareWebpage(scene) → 关闭面板
  → 取消 / 遮罩 → 关闭
```

## 6. 验收标准

### 6.1 UI / 操作（Android Dev Client 或正式包）

1. 「分享农屿」打开面板，三项入口可见，无「即将上线」Toast。
2. 复制链接后可粘贴出官网 URL，并有成功 Toast。
3. 已装微信时：好友 / 朋友圈能拉起微信分享页，标题/描述/链接正确。
4. 未装微信：有明确提示，不崩溃。
5. Expo Go（若仍可启动）：点微信分享有「需原生构建」类提示，不白屏。

### 6.2 配置

1. `app.json` 同时存在业务 scheme `nongyu` 与微信 scheme `wx174b5a4d92447b73`。
2. 冷启动会尝试 `registerApp`。

### 6.3 回归

1. 「关于农屿」仍可打开官网。
2. 课表查同学分享入口行为不变。
