# Spec：专业排名页 UI 优化

| 项       | 内容                                                                 |
| -------- | -------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                                 |
| 需求类型 | **业务**（轻量 UI，仅 Spec，无 PRD / tech / 实施计划）               |
| 参照     | `RankScreen`、`JiaowuPageShell`、`lightTokens`、frontend-design 定调 |
| 状态     | **已实现（待人工点验）**                                             |

---

## 1. 背景

专业排名现为白底卡片 + 三等分 `brandMuted` 统计块，信息平铺、偏通用仪表盘，与「高级简约」及农屿川农绿气质不符。需在不改数据契约的前提下重做内容区视觉。

---

## 2. 目标

1. 以**专业排名数字**为页面唯一记忆点（展签式）。
2. 身份与辅指标安静可读，层级清晰。
3. 进入页时排名数字有克制动效；尊重系统「减少动态效果」。

---

## 3. 边界（非目标）

- 不改 `getRankInfo` / 缓存 / 鉴权。
- 不加搜索、分享、历史对比、院系榜单列表。
- 不重做 `JiaowuPageShell`；不引入新依赖（动效用 RN `Animated` 即可）。
- 不单独写 tech / 实施计划 / PRD（本需求仅以本 Spec 为记录）。
- 不改其他教务子页。

---

## 4. 详细需求

### 4.1 信息架构（自上而下）

1. **身份区**
   - 主行：`name` · `studentId`（缺省用「-」或省略空段）
   - 次行：`campus` / `college` / `major` / `className` / `grade` 中非空项以 `·` 连接，小号次要色
2. **排名主角区**
   - 超大号展示 `majorRank`（无数据时 `-`）
   - 其下极小标注：如「专业排名」或「名 · 专业」（文案简洁，不堆营销词）
3. **辅指标区**（横向，细线分隔，**非**三等分色块卡）
   - 加权成绩：`weightedScore`
   - 学籍：`status`
4. 整体置于浅色 surface 面板或直接铺在渐变底上（实现任选其一，优先：**无重边框堆叠**，可用极细 outline 或仅留白分区）；禁止再出现三个并列 `brandMuted` 小卡。

### 4.2 视觉约束

- 颜色仅用 `lightTokens.color.*`（川农绿体系）。
- 大留白；字重对比：排名数字 ≫ 姓名 ≫ caption。
- 禁止：奖杯/emoji、多层阴影、霓虹 glow、紫渐变、奶油衬线展板风。

### 4.3 动效

- 排名数字（可含其标注）挂载后：opacity 0→1 + translateY 约 8–12 → 0，时长约 **300ms**，缓动 ease-out。
- 读取 `AccessibilityInfo.isReduceMotionEnabled`（或等价）；若开启则跳过动画、直接定态。
- 下拉刷新后数据更新：可不重复动画（避免烦扰）；**仅首次有数据呈现时播一次**即可。

### 4.4 壳与状态

- 仍用 `JiaowuPageShell`：标题「专业排名」、加载/错误/空/刷新行为与现网一致。
- 空态文案保持「暂无排名数据」。

---

## 5. 业务流程

```
进入页 → 既有拉数
  → 成功有数据 → 渲染展签布局；首次呈现播排名淡入上移（若未开减少动态）
  → 空 / 错 / 加载 → 壳层既有态
```

---

## 6. 验收标准

- [ ] 第一眼是大号专业排名，而非三列统计卡。
- [ ] 姓名学号、院系班级、加权、学籍均可读且层级正确。
- [ ] 无搜索条；壳层渐变与他页一致。
- [ ] 减少动态效果开启时无位移/淡入动画。
- [ ] 刷新、错误重试回归正常。
