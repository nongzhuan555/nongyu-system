# Spec：专业排名页 UI 优化

| 项       | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 应用     | `apps/nongyu-rn-app`                                         |
| 需求类型 | **业务**（轻量 UI，仅 Spec，无 PRD / tech / 实施计划）       |
| 参照     | `RankScreen`、`JiaowuPageShell`、主题 token、frontend-design |
| 状态     | **已实现（待人工点验）**                                     |

---

## 1. 背景

首版「展签式巨型数字 + 细线分割」在真机上偏空、像未完成设计稿。需迭代为更紧凑、可读的成绩册裁切页风格。

---

## 2. 目标

1. 一张 surface 卡片收纳全部信息，层次清楚。
2. 排名以中文读法 **「第 · N · 名」** 为主角（数字略大，非 72px 孤立数字）。
3. 加权 / 学籍为左标签右数值行列表；去掉入场动效。

---

## 3. 边界（非目标）

- 不改 `getRankInfo` / 缓存 / 鉴权。
- 不加搜索、分享、榜单列表。
- 不重做 `JiaowuPageShell`；不写 tech / 实施计划 / PRD。
- 不改其他教务子页。

---

## 4. 详细需求

### 4.1 布局（自上而下，单卡内）

1. **身份**：`name · studentId`；次行院系/专业/班级/年级等非空项 `·` 连接。
2. **排名**：居中「第」+ 较大 `majorRank` +「名」；下标注「专业内排名」。无数据时数字位为 `-`。
3. **分隔**：极细线。
4. **明细行**：
   - 加权平均 → `weightedScore`
   - 学籍状态 → `status`
   - 左标签次要色，右值主色加粗；非等分色块卡。

### 4.2 视觉

- 仅用主题 token（`createThemedStyles` / 当前色板）。
- 卡片：`surface` + hairline `border` + 中等圆角；适度内边距，避免大片留白空洞。
- 禁止：72px 悬空数字、奖杯/emoji、多层阴影、紫渐变、三等分 brandMuted 小卡、入场动画。

### 4.3 壳与状态

- 仍用 `JiaowuPageShell`；空态「暂无排名数据」；加载/错误/刷新不变。

---

## 5. 验收

- [ ] 一眼是「第 N 名」读法，不是孤立超大数字。
- [ ] 身份与加权、学籍在同一张卡内，行列表对齐。
- [ ] 无入场动效；壳层渐变与他页一致。
- [ ] 刷新 / 错误重试正常。
