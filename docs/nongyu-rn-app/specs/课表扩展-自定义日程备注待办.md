## 1. 背景

课表周视图主路径已迁移完成。本次接入 PRD 中的「扩展功能」：自定义日程、课程备注、课程待办事项。

**Why**：课表不止是展示教务课，还需承载用户自建日程与课程级笔记/任务，是学生端核心基建；同时这些能力需暴露为 Agent tool，供农屿 Agent 后续接入。

**What**：

1. 用户可在周视图空格子添加「自定义日程」（区别于教务课程，独立实体）；
2. 用户可为任一课程（教务课或自定义日程）添加备注、待办；
3. 自定义日程 / 备注 / 待办**同时存本地（MMKV）与远程（Node）**；
4. 登出时清空本地所有课表相关数据，远程保留；
5. 增删改查功能同步实现为 Agent 可调用的 tool（位于 RN App 内部）。

## 3. 边界（非目标）

- **不做** 考勤记录（PRD §扩展功能第 1 条，后续单独 Spec）
  - **修订（2026-08-15）**：考勤与「日程可与课程冲突叠卡」见 `specs/课表交互UI功能系列优化.md`，本 Spec 原「有课格子拒绝添加日程」条款已被覆盖。
- **不做** 上课提醒（PRD 已标暂不实现）
- **不做** 课表海报 / 分享
- **不做** 教务课程的「编辑」（PRD §自定义课程提到可编辑教务课，本次不改教务 CourseEntry，仅自定义日程可编辑）
- **不做** 教务课程删除/屏蔽（suppression），本次只做自定义日程的增删
- **不做** 跨设备实时同步/推送，仅请求级 pull/push
- **不做** 冲突复杂解决；远程为权威，本地 pull 覆盖；写操作先本地后远程，远程失败保留本地并下次重试
- **不做** Agent tool 的 Generative UI 渲染（纯数据 tool）

## 4. 详细需求

### 4.1 数据模型

#### 4.1.1 自定义日程 `ScheduleEntry`（独立类型，不复用 CourseEntry）

```ts
export type ScheduleEntry = {
  id: string; // uuid
  studentId: string; // 学号（远程按 uid 关联，本地按 key 隔离）
  title: string; // 日程名字
  content: string; // 日程内容
  location: string; // 日程地点
  day: 1 | 2 | 3 | 4 | 5 | 6 | 7;
  startPeriod: number; // 1–10
  endPeriod: number; // 1–10
  weeksList: number[]; // 出现在哪些周
  /** 色板下标 0–7；null / 缺省 = 旧版浅底默认样式（见 `课表卡片尺寸与日程颜色.md`） */
  colorIndex?: number | null;
  createdAt: string; // ISO
  updatedAt: string; // ISO
};
```

#### 4.1.2 课程备注 `CourseNote`

```ts
export type CourseNote = {
  id: string;
  studentId: string;
  courseId: string; // 绑定 CourseEntry.id 或 ScheduleEntry.id
  content: string; // 备注正文
  createdAt: string;
  updatedAt: string;
};
```

#### 4.1.3 课程待办 `CourseTodo`

```ts
export type CourseTodo = {
  id: string;
  studentId: string;
  courseId: string; // 绑定 CourseEntry.id 或 ScheduleEntry.id
  content: string; // 待办内容
  status: "pending" | "done";
  dueDate?: string; // ISO date，可选
  createdAt: string;
  completedAt: string | null;
  updatedAt: string;
};
```

> **绑定维度**：按 `CourseEntry.id`（教务课 id 由 `mapJiaowuCourseItems` 生成，需保证稳定；自定义日程用自身 id）。教务课表强制刷新后 id 若变化，备注/待办将失联 —— 见 §4.5 风险。

### 4.2 本地存储（MMKV）

沿用 `courseLocalStore` 模式，按学号分 key：

| 实体             | MMKV key                       |
| ---------------- | ------------------------------ |
| 自定义日程       | `course:schedules:{studentId}` |
| 课程备注         | `course:notes:{studentId}`     |
| 课程待办         | `course:todos:{studentId}`     |
| 教务课表（已有） | `course:entries:{studentId}`   |

- 每个实体一个 JSON 数组，整体读写（量小，无需分条 key）。
- 需扩 `apps/nongyu-rn-app/src/storage/mmkv.ts`：新增按 prefix 批量删除能力（登出清理用）。

### 4.3 远程存储（Node server）

新建三张表（`apps/nongyu-node-server`）：

```sql
-- custom_schedules
CREATE TABLE custom_schedules (
  id TEXT PRIMARY KEY,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  content TEXT NOT NULL DEFAULT '',
  location TEXT NOT NULL DEFAULT '',
  day INTEGER NOT NULL,
  start_period INTEGER NOT NULL,
  end_period INTEGER NOT NULL,
  weeks_list TEXT NOT NULL DEFAULT '[]',  -- JSON array
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

-- course_notes
CREATE TABLE course_notes (
  id TEXT PRIMARY KEY,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  course_id TEXT NOT NULL,
  content TEXT NOT NULL,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

-- course_todos
CREATE TABLE course_todos (
  id TEXT PRIMARY KEY,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  course_id TEXT NOT NULL,
  content TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'pending',
  due_date TEXT,
  created_at TEXT NOT NULL,
  completed_at TEXT,
  updated_at TEXT NOT NULL
);

CREATE INDEX idx_schedules_user ON custom_schedules(user_id);
CREATE INDEX idx_notes_user_course ON course_notes(user_id, course_id);
CREATE INDEX idx_todos_user_course ON course_todos(user_id, course_id);
```

### 4.4 接口契约

#### 4.4.1 REST API（Node，`/api/app/course-ext`，`requireAppAuth`）

| 方法   | 路径             | 说明                              |
| ------ | ---------------- | --------------------------------- |
| GET    | `/schedules`     | 拉取当前用户全部自定义日程        |
| POST   | `/schedules`     | 新建                              |
| PATCH  | `/schedules/:id` | 更新                              |
| DELETE | `/schedules/:id` | 删除                              |
| GET    | `/notes`         | 拉取全部备注（可选 `?courseId=`） |
| POST   | `/notes`         | 新建                              |
| PATCH  | `/notes/:id`     | 更新                              |
| DELETE | `/notes/:id`     | 删除                              |
| GET    | `/todos`         | 拉取全部待办（可选 `?courseId=`） |
| POST   | `/todos`         | 新建                              |
| PATCH  | `/todos/:id`     | 更新（含 status / completedAt）   |
| DELETE | `/todos/:id`     | 删除                              |

- 所有接口鉴权 `requireAppAuth`，按 `uid` 隔离，不可访问他人数据。
- 请求/响应 JSON；`weeksList` 远程存 JSON 字符串，接口层互转。
- 单条 CRUD；不提供批量。

#### 4.4.2 RN App 数据层 `courseExtRepository`

镜像 `courseRepository`：本地优先 + 远程同步。

```ts
// 伪代码
loadSchedules(studentId): 本地读 → 若联网且远程有更新则 pull 覆盖本地
addSchedule(entry): 写本地 → POST 远程（失败记 pending，下次重试）
updateSchedule(entry): 写本地 → PATCH 远程
deleteSchedule(id): 删本地 → DELETE 远程
// notes / todos 同构
```

- 进入课表页时触发一次 pull（GET 三类），覆盖本地。
- 写操作：先写本地（UI 立即响应），异步 push 远程；push 失败不回滚本地，下次 pull/push 时由 `updatedAt` 决定保留最新。

#### 4.4.3 Agent tools（位于 `apps/nongyu-rn-app/src/modules/course/agent/course-tools.ts`）

镜像 `jiaowu-tools.ts` 的 `tool()` 模式，调用 `courseExtRepository`（经 Node API）。每个 tool 返回 JSON 字符串。

| tool name                | 说明                          |
| ------------------------ | ----------------------------- |
| `course_schedule_create` | 新建自定义日程                |
| `course_schedule_update` | 更新自定义日程                |
| `course_schedule_delete` | 删除自定义日程                |
| `course_schedule_list`   | 列出自定义日程（可选按周）    |
| `course_note_create`     | 新建备注                      |
| `course_note_update`     | 更新备注                      |
| `course_note_delete`     | 删除备注                      |
| `course_note_list`       | 列出某课程备注                |
| `course_todo_create`     | 新建待办                      |
| `course_todo_update`     | 更新待办（含完成态）          |
| `course_todo_delete`     | 删除待办                      |
| `course_todo_list`       | 列出某课程待办                |
| `course_todo_complete`   | 标记完成                      |
| `course_ext_query`       | 按课程 id 一次性查备注 + 待办 |

- 注册到 RN App 的 Agent（`agent/agent.ts`）。
- tool 执行时需当前学号/鉴权，从 `useSessionStore` 取。

### 4.5 业务规则

1. **空格子校验**：添加自定义日程时，若目标 `(week, day, startPeriod-endPeriod)` 已有教务课或自定义日程，拒绝并提示「该时段已有课程/日程」。
2. **连堂日程**：`startPeriod` 与 `endPeriod` 可跨多个大课区间，渲染同连堂课程（`spanRows`）。
3. **周次匹配**：`weeksList` 为空数组视为全周；非空则仅出现在列出的周。
4. **远程权威**：pull 时远程数据覆盖本地（远程为用户跨设备真实来源）。
5. **id 稳定性风险**：教务 `CourseEntry.id` 若在强制刷新后变化，备注/待办失联。**本期约定**：`mapJiaowuCourseItems` 生成的 id 必须基于 `(name, day, startPeriod, endPeriod)` 哈希，保证同课同 id；若仍失联，备注/待办按 `courseId` 孤儿展示在「未关联课程」分组（后续优化）。

### 4.6 校验

- 自定义日程：`title` 非空；`day ∈ 1..7`；`startPeriod ≤ endPeriod`；`weeksList` 元素 ≥ 1。
- 备注：`courseId` 非空；`content` 非空。
- 待办：`courseId` 非空；`content` 非空；`status ∈ {pending, done}`。

### 4.7 登出清理

登出时（`performJiaowuLogout`）追加清理：

| 项                             | 清理方式                                               |
| ------------------------------ | ------------------------------------------------------ |
| `course:entries:{studentId}`   | MMKV delete                                            |
| `course:schedules:{studentId}` | MMKV delete                                            |
| `course:notes:{studentId}`     | MMKV delete                                            |
| `course:todos:{studentId}`     | MMKV delete                                            |
| 背景图文件                     | `expo-file-system` 删 `documentDirectory/course-bg/`   |
| React Query                    | `removeQueries(["jiaowu","course"])`、`["course-ext"]` |

远程数据**不清**。

## 5. 流程

### 5.1 添加自定义日程

```
用户点空格子 → 打开「添加日程」表单 → 填写 → 提交
  → 校验空格子 → 写本地 MMKV → UI 立即渲染
  → 异步 POST /api/app/course-ext/schedules
    → 成功：更新本地 entry 的 id（若远程生成）+ updatedAt
    → 失败：保留本地，记 pending，下次进课表 pull 时重试
```

### 5.2 进入课表页同步

```
进课表页 → loadCourses（本地）+ 并行 GET schedules/notes/todos
  → 远程返回 → 覆盖本地（远程权威）→ UI 刷新
  → 远程失败 → 用本地数据，不打断
```

### 5.3 登出

```
performJiaowuLogout → 清会话 + 清课表相关 MMKV + 删背景图 + 清 React Query
  → 远程不动
```
