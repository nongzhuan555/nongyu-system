# Spec：主题与外观设置

| 项       | 内容                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                                    |
| 需求类型 | **业务**                                                                |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/MyPage/设置页面PRD.md`（主题切换） |
| 色板     | 已迁入 `src/theme/`（见 `主题配色Token迁移.md`）                        |
| 入口     | 「我的」→ 设置 →「主题与外观」→ `/mine/settings/theme`                  |
| 状态     | **已实现**                                                              |

---

## 1. 背景

色板数据（川农新绿 / 樱花 / 暗色表面）已入库，设置首页「主题与外观」仍灰显。业务组件大量静态消费 `lightTokens`，切换须同时落地**运行时主题**与设置 UI，使全 App 跟色。

**Why**：设置 PRD 四项主题能力；避免「只存偏好、界面不变」。  
**What**：设置子页 + 本地偏好 + Theme 运行时，切换后全 App 立刻变色。

---

## 2. 目标

1. 「主题与外观」可进；可选 **川农新绿 / 樱花浅粉**，以及 **浅色 / 暗色 / 跟随系统**。
2. 偏好 MMKV 持久化；默认 **绿 + 浅色**；登出**不**清除（设备级）。
3. 提供 Theme 运行时：`resolveColorPalette` 驱动完整 `ThemeTokens`；`StyleSheet` 经 `createThemedStyles` / `useThemeTokens` 随主题重算。
4. 切换后全 App（含底栏玻璃强调色、页面背景、StatusBar）立即跟色，无需杀进程。
5. 跳过 tech；本 Spec 确认后编码。

---

## 3. 边界（非目标）

- 不同步 Node `user_settings.theme`（后置）。
- 不引入 Paper / 新 UI Kit。
- 不改课表卡片课程色池业务含义（可仍用固定 COURSE_COLORS；壳层跟主题）。
- 不做「关于与反馈」等其它灰显项。

---

## 4. 详细需求

### 4.1 路由

| 界面     | 路由                   | 说明     |
| -------- | ---------------------- | -------- |
| 设置首页 | `/mine/settings`       | 主题可进 |
| 主题外观 | `/mine/settings/theme` | 本轮新增 |

### 4.2 设置子页 UI

- 壳：`SettingsPageShell`。
- **品牌色**：川农新绿 / 樱花浅粉（单选，可色点预览）；**仅浅色界面生效**。
- **外观**：浅色 / 暗色 / 跟随系统。
- 外观为「暗色」时：品牌色选项禁用，并提示当前使用统一深色配色。
- 切换立即持久化并生效；无需保存按钮。

### 4.3 数据

| 项         | 约定                                                  |
| ---------- | ----------------------------------------------------- |
| brand      | `green` \| `sakura`；MMKV `app:theme_brand`           |
| appearance | `light` \| `dark` \| `system`；`app:theme_appearance` |
| 默认       | `green` + `light`                                     |
| 有效暗色   | `dark` 或（`system` 且系统为 dark）                   |

### 4.4 运行时

- `ThemeProvider` 挂在根 Provider 内；监听 `Appearance`（仅 `system` 时）。
- `buildThemeTokens(brand, isDark)`：`color` 来自 `resolveColorPalette`；**`isDark === true` 时忽略 brand，固定使用 `darkPalette`**（表面取旧版 `darkExtras`，强调色为统一冷灰蓝，不区分绿/粉）。
- `tabBar` 中与品牌相关的玻璃填充/描边随当前 `brandMuted` / `brand` 派生（暗色下即深色色板）。
- 业务取色：`useThemeTokens()` 或 `createThemedStyles((t) => …)`；禁止再在模块顶层把 `lightTokens.color.*` 写进一次性 `StyleSheet.create`（布局常量 `space`/`radius` 可静态）。
- `StatusBar`：浅色界面 `dark` 字色，暗色界面 `light` 字色。

### 4.5 设置首页

- 「主题与外观」`available: true` → `/mine/settings/theme`。

---

## 5. 业务流程

```text
设置 → 主题与外观 → 改 brand / appearance → MMKV + 运行时更新 → 全 App 重绘跟色
冷启动 → 读 MMKV → 解析有效明暗 → 应用 token
appearance=system → 系统外观变化 → 重算 isDark → 跟色
```

## 6. 验收标准

- [x] 设置项可进；四选项均可选且立即生效。

- [x] 暗色下切换绿/粉不改变界面强调色（统一深色色板）。
- [x] 杀进程重进偏好保持；登出不丢主题。
- [x] 底栏选中强调色、页面背景/文字随主题变。
- [x] `type-check` 通过（与主题无关的既有错误除外）。
- [x] 「想要其他主题」进入反馈墙发帖：预选「建议」、标题「App主题建议」、内容空。
