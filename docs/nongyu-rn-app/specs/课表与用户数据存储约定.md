## Grill 锁定

| 项           | 结论                                                                                                             |
| ------------ | ---------------------------------------------------------------------------------------------------------------- |
| 课表本体默认 | 仅本地 MMKV JSON（按学号）                                                                                       |
| 扩展实体     | 备注/待办/自定义日程：本地 + 远端同步（见课表扩展 Spec）；**不**纳入课表共享                                     |
| 用户配置类   | 可存远程（主题、网页、首屏等）                                                                                   |
| 刷新         | 有本地只读本地；无本地才抓教务；仅用户强制刷新覆盖                                                               |
| **共享例外** | 用户 **opt-in「允许课表共享」** 时，可将**原始** `CourseEntry[]` 上传远端快照；关闭共享则删除远端 JSON，不可被查 |

## 原则

1. **课表本体**：默认只存**本地**（可离线；可再从教务抓）。
2. **用户配置**：可存**远程**（跨设备）。
3. **课表刷新**：有本地则只读本地；无本地才自动抓教务；仅用户强制刷新才覆盖本地。
4. **课表共享（业务）**：仅在用户显式开启时，远端存一份原始课表快照供学号查找；**不含**备注/待办/自定义日程；详见 `specs/课表共享与Diff.md` 与 `tech/课表共享与Diff.md`。

## 已实现键

| 数据            | 位置                                                 |
| --------------- | ---------------------------------------------------- |
| `CourseEntry[]` | MMKV `course:entries:{studentId}`                    |
| 共享开关缓存    | MMKV `course:shareEnabled:{studentId}`（业务落地后） |
| 共享快照        | MySQL `course_share_snapshots`（仅开启时有 JSON）    |
