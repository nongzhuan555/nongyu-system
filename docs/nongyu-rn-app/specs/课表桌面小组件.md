## 1. 背景

**Why**：用户需要在不打开 App 时看到下一节课或下一场考试；旧版小组件已验证该路径，但刷新靠点击、点击不进 App，且没有「正在上课/正在考试」标记。

**What**：在新版 RN App 落地 Android 主屏课表小组件：课表态展示当前/下一节课；学期教务课结束后展示考试；约 10 分钟刷新；点击进入课表 Tab。

---

## 2. 目标

| #   | 目标           | 验收要点                                                              |
| --- | -------------- | --------------------------------------------------------------------- |
| G1  | 课表态实时     | 正确显示即将上课 / 正在上课 / 今日课已上完                            |
| G2  | 考试态         | 学期教务课结束后展示即将考试 / 正在考试 / 下一场 / 学期结束文案       |
| G3  | 刷新           | 目标每 10 分钟更新展示；课表或考试数据写入后立即刷新一次              |
| G4  | 点击进课表 Tab | 点击打开 App 并选中课表 Tab（`/(tabs)/course`），含冷启动与从后台恢复 |
| G5  | 视觉           | 课表态布局对齐旧版卡片；考试态同结构、字号更小以保证字段完整          |

---

## 3. 边界（非目标）

- **不做** iOS Widget
- **不做** 多种尺寸、多个 Widget 种类、Widget 独立设置页
- **不做** 深色主题跟随、用户自定义小组件配色
- **不做** 点击仅刷新、不打开 App
- **不做** 查看他人课表 / Diff 数据进入小组件（仅本人）
- **不做** 将自定义日程计入「本学期课已上完」判定
- **不做** 跳转教务考试独立页 `/home/jiaowu/exam`
- **不做** 独立技术方案文档（Grill 确认跳过）
- **不承诺** 国产 ROM 强杀后台后仍准时 10 分钟刷新（尽力而为）

## 4. 详细需求

### 4.0 Grill 共识

| 决策         | 结论                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------- |
| 平台         | 仅 Android                                                                                     |
| 课展示范围   | 教务课 + 自定义日程                                                                            |
| 学期结束判定 | 与 `课表期末默认考试安排.md` §4.1 一致：已设开学日、教务课非空、当前教学周 > 教务课最大周      |
| 课时间窗     | `COURSE_TIMES`；连堂按 startPeriod 开始～endPeriod 结束；重叠时优先正在上课                    |
| 考试时间窗   | 能解析起止则用闭区间；仅开始无结束则开始后 2 小时内视为正在考                                  |
| 考试字段     | 课程名、时间原文、地点、座位、考核方式；标签即将考试 / 正在考试                                |
| 空态         | 无数据同步提示；未设开学日提示；课完但无考试「暂无考试安排」；未登录点击走登录门禁后进课表 Tab |
| 点击         | 一律 `/(tabs)/course`                                                                          |
| 刷新         | 尽力 10 分钟 + 数据变更立即刷新                                                                |
| 边界         | 见 §3                                                                                          |

### 4.1 平台与入口

- 系统桌面可添加的 Android App Widget，名称：**农屿今日课表**。
- 一种默认尺寸（对齐旧版约 320×120dp，允许系统缩放）。
- 仅 `home_screen`。

### 4.2 数据与同步

小组件只读一份由 App 写入的本地快照（本人课表 + 开学日 + 考试列表）。快照须能支撑 §4.4–§4.5 的判定，至少包含：

- 开学日
- 教务课程列表（含周次 / 单双周 / weeksList / 星期 / 节次 / 名称 / 教师 / 教室）
- 自定义日程列表（星期 / 节次 / 周次 / 标题 / 地点；教师可空）
- 考试列表（课程名、examTime 原文、教室、座位、考核方式）及是否已成功拉到考试数据的标记

**写入时机**（立即刷新）：

1. 本人课表条目或自定义日程变化
2. 开学日变化
3. 教务考试列表刷新成功或清空
4. 登出：清空快照，小组件回到无数据态

**读取**：原生侧在刷新时读快照，按当前设备时间计算展示态；不在原生侧请求网络。

作息时刻与 App 一致，使用 `COURSE_TIMES`（川农 10 小节）。

### 4.3 两种主模式

| 模式   | 进入条件                             | 展示主题 |
| ------ | ------------------------------------ | -------- |
| 课表态 | 不满足考试态条件                     | 课       |
| 考试态 | 满足「本学期教务课已上完」（§4.3.1） | 考试     |

#### 4.3.1 本学期教务课已上完

与 `课表期末默认考试安排.md` §4.1 **同一判定**（仅教务课、不含自定义日程）：

1. 已设置开学日
2. 教务课程列表非空
3. `computeCurrentWeek(semesterStart) > maxWeekFromCourses(教务课)`

未设开学日、教务课为空、当前周 ≤ 最大教学周 → **课表态**。

### 4.4 课表态展示规则

候选课次 = 当日、当前教学周命中的 **教务课 ∪ 自定义日程**（周次规则与课表周视图一致：weeksList 优先，否则 weeks 范围 + 单双周；日程 weeksList 空视为全周，与课表模块现约定一致）。

对每个候选课次：

- 开始时刻 = `COURSE_TIMES[startPeriod-1].start`
- 结束时刻 = `COURSE_TIMES[endPeriod-1].end`
- **正在上课**：`开始 ≤ now < 结束`（结束时刻起不算正在上）
- **即将上课**：`now < 开始`
- **已结束**：`now ≥ 结束`

优先级：

1. 存在正在上课 → 展示该课，标签 **正在上课**（多门同时进行时取开始时刻最早的一门，再按名称稳定排序）
2. 否则存在即将上课 → 展示开始时刻最早的一门，标签 **即将上课**
3. 否则今日曾有课次且全部已结束 → 文案 **今天的课已经上完**（不展示下一教学日的课，不展示考试）
4. 否则今日无课次 → **今日无课** / **自由安排**（对齐旧版空闲文案）

课信息 UI（对齐旧版结构）：

- 顶栏：状态标签 + 时段 `HH:mm-HH:mm`
- 主标题：课程名（日程用 title）
- 次行：教师（有则「教师：…」；日程无教师则省略）
- 次行：地点（有则「地点：…」）
- 底栏：日期（如 `8月16日 周日`）+ 本次刷新时刻

「今天的课已经上完 / 今日无课」可不填时段、教师、地点。

### 4.5 考试态展示规则

仅在考试态计算。考试列表来自教务考试安排（与 `ExamScreen` / 课表内嵌考试面板同一数据源语义）。

解析 `examTime`：

- 能解析出开始与结束 → 闭区间 `[开始, 结束]`：`now` 在区间内为 **正在考试**；`now ≥ 结束` 为该场已结束；`now < 开始` 为未开始
- 仅能解析开始、不能解析结束 → 开始后 **120 分钟内** 视为正在考试；超过视为已结束
- 完全无法解析时间的条目 **不参与** 即将/正在/已结束排序（不把学期误判为结束）

优先级：

1. 存在正在考试 → 展示该场，标签 **正在考试**（多场同时则开始时刻最早）
2. 否则存在未开始的考试 → 展示开始时刻最早的一场（**可以不是今天**），标签 **即将考试**
3. 若已成功拉到考试数据，且所有**可解析时间**的考试均已结束 → 主文案 **本学期结束，下学期再见**
4. 若已进入考试态但考试列表为空，或没有任何可解析时间的考试 → **暂无考试安排**（**禁止**因此显示学期结束）
5. 尚未成功拉到考试数据 → **请打开 App 同步考试安排**

考试信息 UI（同卡片结构，**字号小于课表态**，允许课程名最多 2 行、时间/地点等最多 2 行，避免无意义截断）：

- 标签：即将考试 / 正在考试
- 主标题：课程名
- 时间：examTime 原文
- 考试性质 / 考核方式（有则显示）
- 地点、座位（有则显示）
- 底栏：日期 + 刷新时刻

学期结束 / 暂无考试：不填考试明细行。

### 4.6 其它空态与异常（课表态优先于考试态之前的兜底）

| 条件                   | 展示                                   |
| ---------------------- | -------------------------------------- |
| 无快照或课表与考试都空 | 请打开 App 同步课表 / 未检测到课表数据 |
| 有课表但未设开学日     | 请设置开学日期 / 前往课表页设置        |
| 快照损坏无法解析       | 数据加载异常                           |

登出后必须回到「无快照」类空态，不得继续展示上一账号的课或考试。

### 4.7 刷新

- **周期**：目标间隔 **10 分钟** 重算并重绘（即使快照未变，状态也可能从即将上课变为正在上课）。
- **立即**：§4.2 写入成功后触发一次 Widget 更新（纠正旧版「只写文件不通知」）。
- **允许**：厂商限制导致间隔变长；不得把系统 `updatePeriodMillis` 当作唯一手段（其下限常为 30 分钟）。
- 刷新时刻展示在卡片右下角，便于用户感知是否在更新。

### 4.8 点击交互

点击小组件任意可点区域：

1. 启动或回到农屿 App
2. 导航到课表 Tab：`/(tabs)/course`
3. **不要**停在首页或其它 Tab
4. **不要**打开 `/home/jiaowu/exam`

与登录门禁：

- 未登录：先全屏登录页；登录成功后 **落到课表 Tab**（本需求覆盖登录成功默认首页：仅当启动来源为小组件时改落到课表）
- 已登录：直接课表 Tab；若课表 Tab 因期末 Spec 默认考试面板，保持该行为即可

### 4.9 视觉

- 课表态：旧版浅绿到白渐变圆角卡片、信息层级（标签 / 课名 / 教师地点 / 底栏日期）
- 考试态：同一卡片骨架，正文字号下调（标签与课表态可同级或略小），保证 §4.5 字段在默认尺寸内可读
- 不随 App 主题色切换（本轮固定旧版绿系）

## 5. 业务流程

### 5.1 学期中看课

1. App 写入快照并通知刷新
2. 小组件按当前时间选择正在上 / 即将上 / 今日已上完 / 今日无课
3. 约 10 分钟后同一快照重新计算（例如课中途变成「正在上课」）

### 5.2 进入考试态

1. 当前教学周超过教务课最大周
2. 小组件不再展示课，改走 §4.5
3. 用户点击进入课表 Tab（期末默认考试面板由既有 Spec 负责）

### 5.3 学期彻底结束

所有可解析考试均已结束 → 固定文案「本学期结束，下学期再见」，直到新学期课表快照写入。

## 6. 验收标准与测试方案

| #   | 场景                                 | 期望                                   |
| --- | ------------------------------------ | -------------------------------------- |
| A1  | 今日有未开始的课，当前不在任何课次内 | 即将上课 + 下一节名称/时段/教师/地点   |
| A2  | 当前时刻落在某课次 [开始, 结束)      | 正在上课 + 该课信息                    |
| A3  | 今日课全部结束，学期未结束           | 「今天的课已经上完」，不出现考试       |
| A4  | 今日无课，学期未结束                 | 今日无课 / 自由安排                    |
| A5  | 自定义日程在今日且时间未到           | 可作为即将上课展示                     |
| A6  | 当前周 > 教务最大周                  | 考试态；不因自定义日程残留而留在课表态 |
| A7  | 考试态，下一场在未来（含非当天）     | 即将考试 + 小字完整字段                |
| A8  | 考试态，当前在考试时段内             | 正在考试                               |
| A9  | 当天考试已结束但仍有后续场次         | 展示下一场（可跨天）                   |
| A10 | 可解析考试全部结束                   | 「本学期结束，下学期再见」             |
| A11 | 考试态但列表空                       | 「暂无考试安排」，不是学期结束         |
| A12 | 写入课表后不等 10 分钟               | 小组件很快变为新数据                   |
| A13 | 点击小组件（已登录）                 | 进入 App 且底栏课表 Tab 选中           |
| A14 | 点击小组件（未登录）                 | 登录成功后课表 Tab                     |
| A15 | 登出                                 | 小组件不再展示该账号课表               |
| A16 | 未设开学日且有课                     | 请设置开学日期                         |

理想 UI：课表态一眼能读标签与课名；考试态字段不因字号过大被裁成无意义省略。
