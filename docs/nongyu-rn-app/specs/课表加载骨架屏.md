# Spec：课表加载骨架屏

| 项       | 内容                                                                            |
| -------- | ------------------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                                            |
| 需求类型 | **业务**（课表 UX）                                                             |
| 关联     | `specs/课表周视图.md`、`specs/课表扩展-自定义日程备注待办.md`、弹层打开性能优化 |
| 状态     | **已确认**（2026-08-15 Q1–Q4）                                                  |

---

## 1. 背景

课表详情 / 日程 BottomSheet 为保上滑流畅，会延后挂载重内容，打开后下方曾出现空白；课表 Tab 首屏仍用转圈。需用与全 App 一致的 `SkeletonBox` 脉冲骨架填等待态。

## 2. 目标

| #   | 目标                                               | 验收                                       |
| --- | -------------------------------------------------- | ------------------------------------------ |
| G1  | 本人课程详情：扩展区未就绪时显示骨架               | 标题/标签先出，下方骨架 → 再出考勤备注待办 |
| G2  | 只读（他人/Diff）详情：无扩展区、无骨架            | 仅基本信息                                 |
| G3  | 日程弹层：内容未就绪时整页骨架；保存仍用按钮文案态 | 打开过渡见骨架；保存中不整页骨架           |
| G4  | 课表 Tab 首屏加载用周视图骨架替代转圈              | 无 `ActivityIndicator` 全屏转圈            |

## 3. 边界（非目标）

- 不改教务 / 广场 / 二课等其它模块骨架（已有实现）
- 查找他人课表按钮内转圈、刷新按钮内转圈：保持现状
- 不引入新依赖

## 4. 详细需求

1. **复用** `@/components/skeleton/SkeletonBox`，课表侧封装 `CourseDetailExtensionsSkeleton` / `ScheduleFormSkeleton` / `CourseWeekSkeleton`。
2. **CourseDetailSheet**：`!readOnly && !extensionsReady` 时在标签行下渲染扩展区骨架。
3. **ScheduleFormSheet**：`onChange` 到位前渲染表单骨架；`onDismiss` 重置；`saving` 仍改按钮文案。
4. **CourseScreen**：`loading === true` 时渲染 `CourseWeekSkeleton`（表头 + 网格占位）。

## 5. 验收

- 点课程卡：弹层上滑过程/到位瞬间下方为骨架，随后出现考勤备注待办，无大块空白
- 点日程卡 / 空格新增：打开过渡为骨架，再出现表单
- 他人课表点课：无扩展骨架
- 进课表 Tab 拉取中：见周视图骨架而非转圈
