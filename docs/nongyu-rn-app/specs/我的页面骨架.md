# Spec：我的页面骨架

| 项       | 内容                                                        |
| -------- | ----------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                        |
| 需求类型 | **业务**                                                    |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/MyPage/我的页面PRD.md` |
| 参照     | `old-code/nongyu/src/modules/Profile`（已登录主路径 UI）    |
| 状态     | **已实现（骨架 UI + 占位跳转）**                            |

---

## 1. 背景

在新 RN App 落地「我的」Tab 主界面：视觉与信息架构对齐旧版 Profile（已登录态），登录入口走现有全局 `/login`。本版本不提供帖子评论/回复入口。

---

## 2. 目标

1. 实现「我的」主界面：顶栏、基本信息网格、「更多服务」列表、退出登录。
2. 组件落在 `src/modules/mine/`，路由薄封装在 `app/(tabs)/mine.tsx`。
3. 未登录：全局门禁只展示登录页（见 `specs/登录门禁.md`）；本页 `GuestPrompt` 仅作防御，主路径走不到。
4. 设置入口可进；「我的帖子」复用已有 `/mine/posts`。本版本不提供评论/回复入口与占位。
5. 登出接入现有 `performJiaowuLogout`（确认弹窗 + Toast）。
6. 「关于农屿」系统浏览器打开官网；「分享农屿」打开分享面板（见 `specs/分享农屿.md`）。

---

## 3. 边界（非目标）

- 不实现设置页功能（主题/网页打开方式/首屏课表等）。
- 不实现资料编辑（含 QQ）。
- 分享面板见独立 Spec `分享农屿.md`（本骨架不再占位）。
- 不实现评论、回复列表业务。
- 不迁移旧版页内登录动画双层切换（`JiaowuLoginProbe` 叠层）。
- 不编写 tech 文档；Spec 确认后直接编码。

---

## 4. 详细需求

### 4.1 路由

| 界面         | 路由             | 说明                          |
| ------------ | ---------------- | ----------------------------- |
| 我的主界面   | `/(tabs)/mine`   | 本 Spec 主体                  |
| 个人信息详情 | `/mine/profile`  | 教务档案全字段；基本信息入口  |
| 我的帖子     | `/mine/posts`    | **已有**，入口直达            |
| 设置         | `/mine/settings` | 设置首页与子页                |
| 登录         | `/login`         | 全屏门禁页（见登录门禁 Spec） |

### 4.2 未登录态

- 展示简短欢迎文案（可含时段问候）+「去登录」按钮 → `router.push('/login')`。
- 不展示档案详情网格与退出登录。
- 可选：仍显示「关于农屿」入口（外开官网）；不强制。

### 4.3 已登录态 UI（对齐旧版结构）

自上而下：

1. **顶栏**：标题「我的」+ 右上设置齿轮 → `/mine/settings`。
2. **基本信息**：带 icon 的六格卡片——姓名 / 学号 / 学院 / 专业 / 班级 / 年级；区块标题带右箭头，点击进入 `/mine/profile`；值单行省略，空则「未知」。不展示校区 / 生源地。
3. **个人信息详情**（`/mine/profile`）：只读本地会话教务档案字段（**不含校区**）；登录时 `getPersonalInfo` 写入 MMKV/会话，登出清空；详情页不提供刷新。
4. **更多服务**（列表，带 chevron）：
   - 我的帖子 → `/mine/posts`
   - 分享农屿 → 打开 ShareSheet（微信好友 / 朋友圈 / 复制链接；见 `specs/分享农屿.md`）
   - 关于农屿 → `Linking.openURL('https://nongyu-app.github.io/index.html')`（失败 Toast）
   - **不含**「我的评论 / 我的回复」（本版本不支持帖子评论回复）
5. **退出登录**：确认框 → `performJiaowuLogout(queryClient)` → Toast「已退出登录」→ 根门禁切到登录页。

视觉：用 `lightTokens`（川农新绿）；档案表 + 列表分组；底部留足 TabBar 滚动 padding。页背景与首页 / 广场共用 `TabScreenBackground`。

### 4.4 数据

- 只读 `useSessionStore` 的 `isAuthenticated` / `profile`。
- 本次不发新网络请求；无区块级骨架屏。

### 4.5 工程结构建议

```text
src/modules/mine/
  screens/MineScreen.tsx
  components/
    ProfileHeader.tsx
    InfoGrid.tsx
    ServiceList.tsx
    GuestPrompt.tsx
  constants/
app/(tabs)/mine.tsx
app/mine/posts.tsx
app/mine/profile.tsx
app/mine/settings/...
```

根 `app/_layout.tsx` 注册相关 Stack.Screen（`headerShown: false`）。

---

## 5. 业务流程

```text
进入「我的」
  → hydrated 后读会话
  → 未登录：GuestPrompt → 去登录
  → 已登录：Header / InfoGrid / ServiceList / 退出
点设置 → 设置页
点我的帖子 → 已有列表页
点关于 → 系统浏览器 / 应用内网页
点分享 → Toast 占位
点退出 → 确认框 → performJiaowuLogout → 登录页
```

---

## 6. 验收标准

### 6.1 UI / 交互

- [ ] 已登录：顶栏、基本信息摘要、「更多服务」（帖子/分享/关于）、退出登录均可见；无评论/回复入口。
- [ ] 未登录：根门禁拦截，看不到「我的」；本页 GuestPrompt 不作为入口。
- [ ] 设置与帖子可进；无评论/回复路由入口。
- [ ] 关于外开/应用内网页；分享有 Toast。
- [ ] 退出确认后会话清空，回到登录页。

### 6.2 工程

- [ ] 实现位于 `src/modules/mine`。
- [ ] `pnpm --filter nongyu-rn-app type-check`、lint、format 通过。
