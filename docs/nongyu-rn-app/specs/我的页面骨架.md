# Spec：我的页面骨架

| 项       | 内容                                                        |
| -------- | ----------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                        |
| 需求类型 | **业务**                                                    |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/MyPage/我的页面PRD.md` |
| 参照     | `old-code/nongyu/src/modules/Profile`（已登录主路径 UI）    |
| 状态     | **已实现（骨架 UI + 占位跳转）**                            |

---

## 1. 背景

在新 RN App 落地「我的」Tab 主界面：视觉与信息架构对齐旧版 Profile（已登录态），登录入口走现有全局 `/login`，设置与评论/回复等子能力先做路由占位。用户后续再给 UI/功能优化方向。

---

## 2. 目标

1. 实现「我的」主界面：顶栏、身份卡、基本信息网格、「更多服务」列表、退出登录。
2. 组件落在 `src/modules/mine/`，路由薄封装在 `app/(tabs)/mine.tsx`。
3. 未登录：引导态 +「去登录」进入 `/login`（不在页内嵌教务表单）。
4. 设置入口、我的评论、我的回复 → 简单占位页；「我的帖子」复用已有 `/mine/posts`。
5. 登出接入现有 `performJiaowuLogout`（确认弹窗 + Toast）。
6. 「关于农屿」系统浏览器打开官网；「分享农屿」本次仅 Toast 占位。

---

## 3. 边界（非目标）

- 不实现设置页功能（主题/网页打开方式/首屏课表等）。
- 不实现资料编辑（含 QQ）。
- 不实现分享面板 / 埋点 SDK。
- 不实现评论、回复列表业务。
- 不迁移旧版页内登录动画双层切换（`JiaowuLoginProbe` 叠层）。
- 不编写 tech 文档；Spec 确认后直接编码。

---

## 4. 详细需求

### 4.1 路由

| 界面         | 路由             | 说明               |
| ------------ | ---------------- | ------------------ |
| 我的主界面   | `/(tabs)/mine`   | 本 Spec 主体       |
| 我的帖子     | `/mine/posts`    | **已有**，入口直达 |
| 设置占位     | `/mine/settings` | 标题 + 说明 + 返回 |
| 我的评论占位 | `/mine/comments` | 同上               |
| 我的回复占位 | `/mine/replies`  | 同上               |
| 登录         | `/login`         | 已有 modal         |

占位页：复用 `ModulePlaceholder`（或同等简版），无需业务逻辑。

### 4.2 未登录态

- 展示简短欢迎文案（可含时段问候）+「去登录」按钮 → `router.push('/login')`。
- 不展示身份卡详情网格与退出登录。
- 可选：仍显示「关于农屿」入口（外开官网）；不强制。

### 4.3 已登录态 UI（对齐旧版结构）

自上而下：

1. **顶栏**：标题「我的」+ 右上设置齿轮 → `/mine/settings`。
2. **身份卡**：渐变底；首字头像（学号/姓名 hash 选色板，对齐旧版思路）；Welcome + 姓名；学号标签。
3. **基本信息**：整块「档案表」纯文字六格（弱分割、无逐卡绿条/icon）；值单行省略；**长按**冒带尖角气泡看全文（点空白关闭）。
4. **更多服务**（列表，带 chevron）：
   - 我的帖子 → `/mine/posts`
   - 我的评论 → `/mine/comments`（占位）
   - 我的回复 → `/mine/replies`（占位）
   - 分享农屿 → Toast「分享功能即将上线」（不弹旧版 ShareSheet）
   - 关于农屿 → `Linking.openURL('https://nongyu-app.github.io/index.html')`（失败 Toast）
5. **退出登录**：确认 `Alert` → `performJiaowuLogout(queryClient)` → Toast「已退出登录」→ 主界面切回未登录引导。

视觉：用 `lightTokens`（川农新绿）；结构/层次对齐旧版，非像素级；为大圆角身份卡、信息小卡、列表分组容器。底部留足 TabBar 滚动 padding。页背景与首页 / 广场共用 `TabScreenBackground`（颜色与 stops 一致）。

### 4.4 数据

- 只读 `useSessionStore` 的 `isAuthenticated` / `profile`。
- 本次不发新网络请求；无区块级骨架屏。

### 4.5 工程结构建议

```text
src/modules/mine/
  screens/MineScreen.tsx
  components/
    ProfileHeader.tsx      # 标题 + 设置
    IdentityCard.tsx       # 身份卡
    InfoGrid.tsx           # 基本信息网格
    ServiceList.tsx        # 更多服务
    GuestPrompt.tsx        # 未登录引导
  constants/               # 官网 URL、服务入口配置等
app/(tabs)/mine.tsx        # export MineScreen
app/mine/settings.tsx      # 占位
app/mine/comments.tsx      # 占位
app/mine/replies.tsx       # 占位
```

根 `app/_layout.tsx` 注册上述 Stack.Screen（`headerShown: false`）。

---

## 5. 业务流程

```text
进入「我的」
  → hydrated 后读会话
  → 未登录：GuestPrompt → 去登录
  → 已登录：Header / IdentityCard / InfoGrid / ServiceList / 退出
点设置 / 评论 / 回复 → 占位页
点我的帖子 → 已有列表页
点关于 → 系统浏览器
点分享 → Toast 占位
点退出 → Alert 确认 → performJiaowuLogout → 未登录引导
```

## 6. 验收标准

### 6.1 UI / 交互

- [ ] 已登录：顶栏、身份卡、六格信息、「更多服务」五项、退出登录均可见；观感接近旧版主路径。
- [ ] 未登录：引导 + 去登录进 `/login`；无假身份数据。
- [ ] 设置 / 评论 / 回复进占位并可返回；帖子进已有页。
- [ ] 关于外开官网；分享有 Toast。
- [ ] 退出确认后会话清空，页面回到未登录态。

### 6.2 工程

- [ ] 实现位于 `src/modules/mine`。
- [ ] `pnpm --filter nongyu-rn-app type-check`、lint、format 通过。
