# Spec：课表卡片尺寸与日程颜色

| 项       | 内容                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app` + `apps/nongyu-node-server`（course-ext）                         |
| 需求类型 | **业务**                                                                               |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/Course/课表卡片尺寸与日程颜色PRD.md`              |
| 关联     | `课表交互UI功能系列优化.md`、`课表扩展-自定义日程备注待办.md`、`设置页壳与课表偏好.md` |
| 状态     | **已实现**（用户确认后编码 2026-08-16）                                                |

---

## 1. 背景

**Why**：中/大档卡片偏高，一屏可见信息偏少；日程卡目前统一浅底，用户无法按日程语义着色，辨识弱。

**What**：

1. 下调课表卡片中档、大档行高（小档与字号不变）；
2. 自定义日程支持预设色板选色，写入实体并本地 + 远程持久化；编辑可改色；兼容无色旧数据。

---

## 2. 目标

| #   | 目标              | 验收要点                                                                     |
| --- | ----------------- | ---------------------------------------------------------------------------- |
| G1  | 中/大档行高下调   | `md`/`lg` 行高按下方数值生效；`sm` 与名称/元信息字号不变                     |
| G2  | 日程表单可选色    | 新增/编辑表单有色板 +「默认/无色」；新建默认选中色板第 0 色                  |
| G3  | 周视图按色渲染    | 有 `colorIndex` 时用对应色板 `bg`/`text` + 细边 + 日历弱图标；无色保持旧样式 |
| G4  | 本地 + 远程持久化 | 增改后杀进程/换设备 pull 后颜色一致；旧日程无字段仍可展示                    |

---

## 3. 边界（非目标）

- **不做** 自由取色 / 自定义 hex / 渐变
- **不做** 本轮 Agent `course_schedule_create` / `update` 暴露 `colorIndex`（Agent 创建的日程 `colorIndex = null`）
- **不做** Agent 侧 `CourseScheduleCard` 着色展示（可后续对齐）
- **不做** 教务课程用户自定义颜色
- **不做** 技术方案文档（已确认跳过）
- **不做** 改动「小」档行高或任何字号档位数值

---

## 4. 详细需求

### 4.1 卡片行高

`COURSE_ROW_HEIGHT`（`coursePrefs.ts`）调整为：

| 档位 | 调整前 | 调整后          |
| ---- | ------ | --------------- |
| sm   | 100    | **100**（不变） |
| md   | 120    | **110**         |
| lg   | 140    | **130**         |

- `COURSE_NAME_FONT` / `COURSE_META_FONT`：**不变**。
- 周网格行高、课程卡、日程卡均继续读同一 `COURSE_ROW_HEIGHT[cardSize]`，无需另开日程专用高度表。

### 4.2 色板

- 复用现有课程色池（`colors.ts` 中 8 组 `{ bg, text }`），下标 `0…7`。
- 导出稳定只读色板数组（或等价 API），供表单色块与 `ScheduleCard` 解析；禁止在业务侧硬编码另一套 hex。

### 4.3 数据模型

`ScheduleEntry` 增加可选字段：

```ts
/** 色板下标 0–7；null / 缺省 = 旧版浅底默认样式 */
colorIndex?: number | null;
```

约束：

- 合法值：整数 `0…7`，或 `null` / `undefined`（视为无色）。
- 非法值（越界、非整数）：按 **无色** 渲染，写回时纠正为 `null`（客户端防御；服务端校验拒绝非法写入）。

### 4.4 表单行为（`ScheduleFormSheet`）

- 新增与编辑均展示「颜色」区：
  - 「默认/无色」选项 + 8 个色板色块；
  - 当前选中有可见反馈（描边/对勾）。
- **新建默认**：`colorIndex = 0`（色板第一色）。
- **编辑**：回填已有 `colorIndex`；缺省/null 时选中「默认/无色」。
- 用户可随时改为「默认/无色」（写入 `null`）或其他下标。
- 提交时把 `colorIndex` 写入 `ScheduleEntry`（无色为 `null`），走既有 `onSubmit` / Outbox 路径。

### 4.5 周视图渲染（`ScheduleCard`）

- `colorIndex` 为合法 `0…7`：
  - `backgroundColor = palette[i].bg`；
  - 标题/元信息文字色 = `palette[i].text`；
  - 边框色基于 `text` 的浅透明（保持细边 hairline）；
  - 日历弱图标颜色用 `text`（或同色系），保留左上角弱图标位置。
- `colorIndex` 为 `null` / 缺省 / 非法：保持现有主题浅底 + brand 细边样式（与 `课表交互UI功能系列优化` 一致）。
- **不得**改为与 `CourseCard` 完全相同的「无边框实心块」形态，以免与课程卡混淆。

### 4.6 远程与同步（Node course-ext）

- DB：`custom_schedules` 新增可空列，例如 `color_index TINYINT NULL`（仅允许 `NULL` 或 `0…7`）。
- API DTO / Zod：
  - create：`colorIndex: z.number().int().min(0).max(7).nullable().optional()`（缺省按 `null` 存）；
  - patch：同上，可选；
  - list 返回带 `colorIndex: number | null`。
- 客户端本地 MMKV、Outbox payload 随 `ScheduleEntry` 透传该字段；无需新实体类型。
- 旧客户端不传字段：服务端存 `NULL`；新客户端读到 `null` 按无色渲染。

### 4.7 Agent

- 本轮 **不** 改 `course_schedule_*` tool schema。
- Agent 创建/更新不携带 `colorIndex` → 持久化为无色。

---

## 5. 业务流程

### 5.1 新建带色日程

1. 用户在空格/冲突入口打开新增表单；
2. 颜色默认选中色板第 0 色；
3. 用户可改色或选「默认/无色」；
4. 保存 → 本地写入 → Outbox push → 周视图按色渲染。

### 5.2 编辑改色

1. 打开已有日程编辑；
2. 改色并保存；
3. 周视图与远程 list 一致反映新色。

### 5.3 旧数据兼容

1. 升级前已有日程无 `colorIndex`；
2. 展示为旧浅底样式；
3. 用户编辑保存时可选择上色或保持无色。

### 6.1 UI / 操作

| #   | 场景                       | 期望                                                        |
| --- | -------------------------- | ----------------------------------------------------------- |
| A1  | 设置卡片大小为「中」「大」 | 行高相对改版前明显略矮；「小」与改版前一致；字号观感不变    |
| A2  | 新增日程不改色直接保存     | 周视图为色板第 0 色的日程形态（浅底色系 + 细边 + 日历图标） |
| A3  | 新增选「默认/无色」保存    | 周视图为升级前默认浅底 brand 边样式                         |
| A4  | 编辑改选其他色块保存       | 卡片立即换色；杀进程重进仍为该色                            |
| A5  | 同格叠卡翻到有色日程       | 日程正面颜色正确；仍可与课程卡区分                          |
| A6  | 有色日程与无色日程并排     | 视觉差异清晰，且均保留日程图标/细边语义                     |
