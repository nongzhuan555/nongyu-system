---

## 1. 背景

**Why**：多轮上下文费 token，且历史可能干扰单次问答；用户需要可切换的「有记忆 / 无记忆」。  
**What**：Agent 设置增加上下文管理模式；发送 / 重新生成时按模式决定是否把历史与摘要交给模型。

---

## 2. 目标

1. 设置页可选「完整上下文」（默认）与「无记忆」，选项下有简短说明。
2. 切换立即写入本机并生效，无需点「保存并检测」。
3. 「无记忆」：`agent.stream` 的 `history` 为空，且不传 `llmSummary` / `llmCompactedUntilId`；系统提示词仍由 Agent 配置生效。
4. 聊天页气泡展示与会话落盘行为不变。
5. 清除 API Key / 登出 **不**重置该偏好。

---

## 5. 详细需求

### 5.1 模式定义

| 存储值      | 展示名     | 模型侧行为                                                                        |
| ----------- | ---------- | --------------------------------------------------------------------------------- |
| `full`      | 完整上下文 | 与现逻辑一致：带会话 history + 摘要压缩字段（若有）                               |
| `stateless` | 无记忆     | `history=[]`；不传 `llmSummary` / `llmCompactedUntilId`；仅当前 prompt + 系统提示 |

缺省 / 非法值 → `full`。

### 5.2 设置页 UI

在「农屿 Agent」页、「服务商」区块之前或 API Key 区块之后增加「上下文管理」区块（推荐：**服务商之前**，与凭据操作分离）：

- 单选两行（样式对齐主题设置：标题 + 说明 + radio）
- 文案：

| 模式       | 说明（可微调，语义不变）                                           |
| ---------- | ------------------------------------------------------------------ |
| 完整上下文 | 每次提问会带上本会话历史（含摘要），模型能记住前文，适合连续追问。 |
| 无记忆     | 每次只发送当前问题与系统提示，模型看不到历史，更省用量、互不干扰。 |

- 切换即时 `setContextMode`，无需确认框。

### 5.3 持久化

- MMKV key：`app:agent_context_mode`
- 值：`full` \| `stateless`
- 设备级；登出 / `clearAgentConfig` **不**删除

### 5.4 运行时

- `agentChatRunner` 在调用 `agent.stream` 前读取当前模式。
- **仅影响模型入参**；Runner 内 `messages` 仍按完整会话追加 / 落盘。
- `send` 与 `regenerate` 均遵守该模式。
- 「无记忆」下会话摘要字段仍可存在于本地会话元数据，但 **不得** 传入本次 stream。

---

## 6. 业务流程

```
用户切换模式 → MMKV + store 更新
用户发送 / 重试 / 重新生成
  → Runner 组装 UI messages（含历史）
  → 若 full：stream(history=…, llmSummary=…)
  → 若 stateless：stream(history=[], 无摘要字段)
```

---

## 7. 验收

| #   | 场景                 | 期望                                          |
| --- | -------------------- | --------------------------------------------- |
| 1   | 首次安装             | 默认为完整上下文                              |
| 2   | 切到无记忆后多轮提问 | UI 有多条气泡；模型侧无前文（行为上互不引用） |
| 3   | 切回完整上下文       | 后续提问能引用前文                            |
| 4   | 清除 API Key         | 上下文模式保持不变                            |
| 5   | 杀进程重开           | 模式保持                                      |
