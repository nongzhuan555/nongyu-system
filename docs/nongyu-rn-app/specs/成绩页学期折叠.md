# Spec：成绩查询页学期折叠

| 项       | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 应用     | `apps/nongyu-rn-app`                                         |
| 需求类型 | **业务**                                                     |
| 来源     | 2026-08-16 对话对齐（全部走推荐）                            |
| 参照     | `ScoreScreen`、`JiaowuPageShell`、既有学期分组 `groupByTerm` |
| 状态     | **已实现（待人工点验）**                                     |

---

## 1. 背景

成绩查询页已按学期分区展示全部成绩卡片，学期较多时列表过长，扫读成本高。需要在保持现有分组与搜索能力的前提下，为每个学期增加展开/收起，默认只展开列表最上方（通常为最近）学期。

---

## 2. 目标

1. 每个学期分区可独立展开/收起其成绩卡片列表。
2. 进入页面（或无搜索关键词）时：**仅列表第一个学期展开**，其余收起。
3. 收起态仍能通过学期头扫到「有几门课」；展开态交互清晰、有轻量反馈。
4. 与现有本地搜索兼容：有命中时自动展开相关学期；清空搜索后恢复默认展开策略。

---

## 3. 边界（非目标）

- 不改 `getScoreInfo` / 缓存 / 鉴权 / `JiaowuPageShell` 公共搜索壳。
- 不做手风琴（不强制同时仅展开一个学期）。
- 不持久化用户展开偏好（离开页面或重新进入后仍按默认策略）。
- 不做复杂高度动画库；不做「全部展开/全部收起」全局按钮。
- 不改其他教务子页；不单独编写技术方案文档。

---

## 4. 详细需求

### 4.1 学期头（可点击）

每个学期分区顶部为可点击的学期头，包含：

| 元素   | 说明                                                             |
| ------ | ---------------------------------------------------------------- |
| 学期名 | 沿用现有 `group.term` 文案与品牌色强调                           |
| 门数   | 展示该分组当前可见课程数，如「3 门」（搜索过滤后为过滤后的门数） |
| 指示器 | chevron（或等价箭头），展开/收起时轻量旋转，暗示可点击           |

- 点击学期头切换该学期展开态；**多个学期可同时展开**。
- 无障碍：学期头为 `button`，label 含学期名与当前展开/收起状态。

### 4.2 默认展开策略

在**无生效搜索关键词**（`query` 为空）时：

1. 对当前 `groups`（按学期降序，与现有 `groupByTerm` 一致）取**第一个**学期为展开。
2. 其余学期收起。
3. 下拉刷新、数据重载后：若仍无搜索关键词，重新应用上述默认（不保留用户临时展开态）。

### 4.3 搜索与展开态

| 场景                           | 行为                                                                       |
| ------------------------------ | -------------------------------------------------------------------------- |
| 有生效关键词且有命中           | **自动展开**所有「过滤后门数 > 0」的学期；无命中学期不展示（与现过滤一致） |
| 清空关键词 / 关键词变为空      | 恢复默认：**仅第一个学期展开**                                             |
| 用户在有关键词时手动收起某学期 | 允许；再次改关键词重新触发「命中学期自动展开」时以新一轮规则为准           |

说明：搜索过滤逻辑、字段、空态文案不变（见《教务子页交互与UI优化》Spec）。

### 4.4 内容显隐与动画

- 收起：不渲染（或不占布局）该学期下的成绩卡片列表。
- 展开：展示该学期全部（过滤后）成绩卡片，卡片样式与现网一致。
- 动画：chevron 旋转 + 内容显隐即可；**不要求**精确高度插值动画。

### 4.5 视觉约束

- 仅用主题 token（`createThemedStyles`）。
- 学期头可做成可点的一行（可带轻量 surface / 无边框均可），避免新增厚重卡片套卡片。
- 不引入新图标库；优先 `Ionicons`（与教务壳一致）。

---

## 5. 业务流程

```
进入成绩页 → 拉数成功 → groupByTerm → 默认仅展开 groups[0]
用户点学期头 → 切换该 term 展开态（可多开）
用户输入搜索 → 过滤 → 自动展开所有有命中的学期
用户清空搜索 → 恢复仅展开 groups[0]
下拉刷新且无关键词 → 恢复仅展开 groups[0]
```

---

## 6. 验收标准

- [ ] 进入页（多学期、无搜索）：仅最上方学期展开，其余只显示学期头 + 门数 + chevron。
- [ ] 点击收起学期头可展开/再收起；可同时展开多个学期。
- [ ] 收起态门数正确；搜索过滤后门数随过滤结果变化。
- [ ] 搜索有命中：相关学期自动展开；无结果仍为「未找到相关结果」。
- [ ] 清空搜索后恢复「仅顶部学期展开」。
- [ ] 下拉刷新、错误重试、加载骨架等壳层行为不变。
- [ ] chevron 有展开/收起方向变化（轻量）。
