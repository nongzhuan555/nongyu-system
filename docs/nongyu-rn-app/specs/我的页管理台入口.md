## 1. 背景

「我的 → 更多服务」需向管理员暴露 Web 管理后台入口。打开策略与全站外链一致（`openAppUrl`）；登录由 Node handoff + Web 自动兑换完成，App **不**存管理员密码、**不**弹密码确认框。

---

## 2. 目标

1. 仅当当前用户 `role === 1` 时，在「更多服务」展示「农屿管理台」。
2. 点击后申请 handoff ticket，再打开管理端 URL（带 `loginType=in_app` 与 `ticket`）。
3. 本地会话能拿到并持久化 `role`（来自 App 登录 / `me`），登出清除。
4. 失败有明确 Toast；无二次确认弹窗。

---

## 3. 边界（非目标）

| 非目标                   | 说明                     |
| ------------------------ | ------------------------ |
| 设置页配置管理员密码     | 不做                     |
| SecureStore 存管理员密码 | 不做                     |
| 强制内置 WebView         | 遵守用户「网页跳转」偏好 |
| 修改 Web / Node 实现细节 | 以各自 Spec 为准         |
| 游客展示入口             | 不展示                   |

---

## 4. 详细需求

### 4.1 角色来源

- App 登录成功（`POST /api/app/auth/login`）与冷启动 `GET /api/app/auth/me` 的 `user.role`（`0 | 1`）写入会话（内存 + 现有持久化策略中与 profile/token 同生命周期的位置）。
- 登出（`performJiaowuLogout`）清除 `role`。
- 展示条件：`isAuthenticated && role === 1`。

### 4.2 更多服务入口

| 字段        | 值                                             |
| ----------- | ---------------------------------------------- |
| key         | `admin`                                        |
| title       | 农屿管理台                                     |
| description | 打开 Web 管理后台（自动登录）                  |
| icon        | 与现列表风格一致（如 `desktop-outline`）       |
| 可见性      | 仅管理员；插入列表靠后（建议「关于农屿」之前） |

游客 / 普通用户：该行不渲染（不是灰显）。

### 4.3 点击流程

1. 展示短暂 loading（按钮态或全局均可，避免连点）。
2. `POST /api/admin/auth/app-handoff`（Bearer = App Token）。
3. 成功后构造 URL：

   `http://101.43.34.229/admin/login?loginType=in_app&ticket={ticket}`

   （管理端部署根为 `http://101.43.34.229/admin`；登录子路径 `/login`。）

4. `openAppUrl(url, { label: "农屿管理台" })`。
5. 失败：Toast；文案映射：

| 情况         | Toast                  |
| ------------ | ---------------------- |
| 网络失败     | 网络异常，请稍后重试   |
| 403 非管理员 | 需要管理员权限         |
| 403 禁用     | 账号已禁用             |
| 401          | 登录已失效，请重新登录 |
| 其它         | 打开管理台失败         |

无密码弹窗、无「确认进入」弹窗。

### 4.4 常量

- 管理端 base：`http://101.43.34.229/admin`（集中常量，便于改环境）。

---

## 5. 业务流程

```
用户点「农屿管理台」
  → app-handoff
  → openAppUrl(login?loginType=in_app&ticket=…)
  →（系统浏览器或内置 WebView）Web 自动登录
```

---

## 6. 验收标准

**UI**

- [ ] 普通用户「更多服务」无「农屿管理台」。
- [ ] 管理员可见；文案为「农屿管理台」。
- [ ] 点击无密码/确认弹窗。

**功能**

- [ ] 网页跳转=内置：进 WebView，最终落在已登录工作台（依赖 Web Spec）。
- [ ] 网页跳转=系统浏览器：系统浏览器打开带 ticket 的 URL，同样自动登录。
- [ ] handoff 失败有 Toast；成功不残留错误提示。
- [ ] 登出后再登录为普通用户：入口消失。
