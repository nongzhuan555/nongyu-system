# Spec：首页模块骨架

| 项       | 内容                                                      |
| -------- | --------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                      |
| 需求类型 | **业务**                                                  |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/Home/首页模块PRD.md` |
| 参照     | `old-code/nongyu/src/modules/Home`                        |
| 状态     | **已实现（骨架 + 视觉细化）**                             |

---

## 1. 背景

将旧版农屿首页迁移为新工程骨架：保留主路径信息架构与细粒度组件，暂缓真实后端与 AI；通知接口未就绪时写死数据，但仍走「加载 → 展示」并显示骨架屏。

---

## 2. 目标

1. 实现首页主界面（问候、通知栏、常用网站、教务/二课入口、社交复制）。
2. 组件按区块细拆，目录落在 `src/modules/home/`（与 modules 命名一致）。
3. **仅存在（或预留）网络请求的区块**展示骨架屏；本次通知栏模拟短延迟加载固定数据。
4. 问候语按时段本地生成，打字机效果；为文案预留稳定高度，避免布局跳动。
5. 常用网站完整迁移旧版列表与搜索；点击固定用系统浏览器打开。
6. 教务、二课、通知列表/详情等入口进入**简单占位页**。

---

## 3. 边界（非目标）

- 问候不接 AI、不含用户姓名、不拼天气。
- 不实现教务/二课业务页、登录锁定逻辑、课表导入等。
- 不做网站打开方式设置（内置 WebView / 外开切换）。
- 不接真实通知 API（固定文案即可）。
- 不迁移 `WeatherProbe`。
- 不编写 tech 文档；Spec 确认后可直接编码（用户已允许业务侧略过部分基建）。

---

## 4. 详细需求

### 4.1 路由

| 界面     | 路由约定                       | 说明                   |
| -------- | ------------------------------ | ---------------------- |
| 首页     | `/(tabs)/home`                 | 主界面                 |
| 通知占位 | `/home/notice`（或等价 Stack） | 通知栏点击             |
| 教务占位 | `/home/jiaowu`                 | 「教务系统」点击       |
| 二课占位 | `/home/second`                 | 「二课系统」点击       |
| 常用网站 | 无独立业务路由                 | `Linking.openURL` 外开 |

占位页：标题 + 一两句说明 + 返回即可。

### 4.2 问候语（Greeting）

- 按时段映射文案（至少覆盖：清晨/上午/中午/下午/傍晚/晚上/深夜，具体切分可对齐旧 `getTimeSlotLabel` 或等价简洁切分）。
- 文案示例方向：`你好，现在是上午，祝你学习顺利`（无姓名）。
- **打字机**：逐字展示；区域按约 **2 行**预留最小高度（当前文案长度），避免与通知栏间距过大。
- 与通知栏的垂直间距宜紧凑（问候底 padding 宜小）。
- 与页面顶（安全区下）外间距宜紧：内容区 `paddingTop ≈ safeArea + xs`，问候本身不再叠加额外 `paddingTop`，避免顶空过大显得突兀。
- **无网络请求 → 无骨架屏**。

### 4.3 通知栏（NoticeBar）

- 视觉与常用网站**搜索框对齐**：高度 40、圆角 12、共用 `HOME_FIELD_CHROME` 描边/霜面；左侧喇叭图标 + 单行标题 + chevron。
- **栏位 UI 必须始终存在**：优先展示最新公告；未登录 / 无数据 / 请求失败时回退显式占位文案（`FIXED_NOTICE`），**禁止**因无数据整栏隐藏。
- loading 期间显示同形态骨架屏；有真实公告 id 点击进广场详情，占位则进 `/home/notice`。

### 4.4 常用网站（WebNav）

- **完整迁移**旧版站点列表（list1–list4）与搜索过滤 UI。
- 栅格：一行 4 个；**可视区域固定为恰好 3 行**，超出部分在面板内纵向滚动。
- 图标：首字 + 渐变底（可用 `expo-linear-gradient`，若未安装则 `expo install`）。
- 点击：`Linking.openURL(url)`；失败可用 Toast 提示。
- 静态配置、无请求 → **无骨架屏**。
- 不做应用内 WebView Modal。

### 4.5 入口卡片

- **教务系统**、**二课系统**：样式对齐旧版 socialCard 行；点击进对应占位页。
- **公众号 / QQ 群**：展示固定文案与「点击复制」；复制成功 Toast（可用现有 toast 方案）。

### 4.6 骨架屏约定

| 区块        | 是否骨架 | 说明                      |
| ----------- | -------- | ------------------------- |
| 问候        | 否       | 本地计算                  |
| 通知栏      | 是       | 模拟请求；接真 API 后复用 |
| 常用网站    | 否       | 静态                      |
| 入口/复制行 | 否       | 静态                      |

骨架形态：与通知栏同尺寸的圆角条 + 闪光/脉冲块即可，细拆为可复用小组件（如 `SkeletonBox`）。

### 4.7 工程与结构建议

```text
src/modules/home/
  HomeScreen.tsx              # 组装
  components/
    HomeBackground.tsx
    HomeSurface.tsx           # 统一浅浮层卡片（阴影/圆角）
    Greeting/
    NoticeBar/
    WebNav/                   # 含站点常量、搜索、格子项
    EntryCard/                # 教务/二课
    SocialCopyCard/           # 公众号/QQ
  constants/                  # 时段文案、社交常量等
  hooks/                      # 如 useTypewriter、useNoticeBootstrap
src/components/skeleton/      # 通用骨架原子组件（可复用）
app/(tabs)/home.tsx           # 引用 HomeScreen
app/home/notice.tsx           # 占位
app/home/jiaowu.tsx           # 占位
app/home/second.tsx           # 占位
```

- 图标可用 Ionicons / MaterialCommunityIcons（与项目已有依赖一致即可）。
- 中文注释；改动后 `type-check` / lint / format。

### 4.8 视觉细化（frontend-design，大体不变）

在 **信息架构与区块顺序不变** 前提下做细节升级，方向：**林荫学园（Campus Canopy）** —— 依托川农新绿色板，清透、克制、有材质感。

| 项        | 约定                                                                                                                       |
| --------- | -------------------------------------------------------------------------------------------------------------------------- |
| Signature | 问候区：打字机主文案（无「今日 · 时段」eyebrow）；背景仅柔渐变，无装饰光斑图案；与广场 /「我的」共用 `TabScreenBackground` |
| 卡片      | 统一浅浮层（圆角偏大、极轻品牌色阴影、细描边），避免厚重投影与霓虹                                                         |
| 通知栏    | 与网站搜索框同形（高 40 / 圆角 12 / outline / 白霜）；喇叭+标题+chevron                                                    |
| 网站格    | 可视恰 3 行，超出面板内滚动；图标品牌向渐变；搜索内嵌浅底                                                                  |
| 入口/社交 | 行间细分割线；入口强调、复制行弱化但可点                                                                                   |
| 非目标    | 不改路由/数据/骨架逻辑；不加新业务区块；不引入第三方 UI Kit                                                                |

## 5. 业务流程

```text
进入首页
  → 渲染问候（立即按时段生成 → 打字机）
  → 通知栏进入 loading 骨架 → 延迟后展示固定通知
  → 渲染网站列表 / 入口 / 复制行
用户点通知 / 教务 / 二课 → 对应占位页
用户点网站 → 系统浏览器打开 URL
用户点公众号/QQ → 复制 + Toast
```

---

## 6. 验收标准

### 6.1 UI / 交互

- [ ] 首页区块齐全，观感接近旧版主路径（非像素级，结构与层次一致）。
- [ ] 问候按时段变化；打字机可见；区域高度稳定。
- [ ] 通知栏先骨架后固定文案；可进占位页。
- [ ] 网站搜索过滤正确；点击外开；列表与旧版条目一致。
- [ ] 教务/二课进占位；复制有反馈。

### 6.2 工程

- [ ] 组件细拆在 `src/modules/home`。
- [ ] `pnpm --filter nongyu-rn-app type-check` 通过；lint / format 通过。
