# Spec：二课功能（工具库 + Agent Tool + App 只读接入）

| 项       | 内容                                                                               |
| -------- | ---------------------------------------------------------------------------------- |
| 应用     | `packages/nongyu-tool-second`、`packages/nongyu-agent-sdk`、`apps/nongyu-rn-app`   |
| 需求类型 | **基建 + 业务**                                                                    |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/Home/二课功能PRD.md`（源自 all-prd 二课段落） |
| 参照     | `nongyu-tool-jiaowu`、`ExternalTools/jiaowu-tools.ts`、教务模块 `modules/jiaowu/*` |
| 状态     | **已实现（待联调验收）**                                                           |

---

## 1. 背景

农屿需聚合川农二课能力。当前：

- `packages/nongyu-tool-second` 仅为占位类，无法抓取 / 清洗二课数据；
- Agent 侧仅有教务 `jiaowuTools`，无二课 tool；
- RN 首页「二课系统」仍为 `/home/second` 占位页。

本需求对齐教务已验证模式：工具库负责登录与结构化查询 → Agent SDK 用 `tool()` 封装 → App 只做 UI 与会话桥接。**能力面全部做成 tool**；App 点击与仅 Agent 调用是使用分流，不是「做不做 tool」的边界。

---

## 2. 目标

1. **工具库完备**：`nongyu-tool-second` 提供登录/会话与个人二课信息、活动列表、活动详情等原子查询 API；包内有使用文档（`README.md`）与实现约定（`TECH.md`）。
2. **Agent Tool**：在 `nongyu-agent-sdk` 增加 `ExternalTools/second-tools.ts`（及统一导出），将上述能力全部封装为符合 SDK 规范的 `tool()`，供 `createAgent` 注册；活动推荐由 Agent **组合原子 tool** 完成，不单独做推荐策略硬编码工具（可后续加薄封装，本轮不做）。
3. **RN 只读接入**：依赖 `nongyu-tool-second`，落地二课入口 + 个人二课信息 + 活动列表 + 活动详情；交互与壳层对齐教务模块既有模式（登录门禁、加载/空/错态、Token 色）。
4. **真机验收**：本轮至少真机调通二课登录，并成功拉取至少一项核心查询（个人二课信息或活动列表）。

---

## 3. 边界（非目标）

- **代码不做**二课报名、取消报名、签到等任何写操作（不导出函数、不封装 Agent tool、App 无入口）。
- **文档保留**旧版报名接口契约（见 `docs/nongyu-rn-app/tech/二课接口清单-旧版农屿.md`），供后续版本启用，本轮仅文档不实现。
- **不做** App 内「活动推荐」独立页面；推荐仅 Agent 对话路径。
- **不把**推荐算法/策略冻进 `nongyu-tool-second`。
- 不改农屿 Node 主业务库以存二课快照（仍实时直连二课系统）。
- 不单独编写 RN 侧大型技术方案文档；工具库登录/抓取约定写包内 `TECH.md`，必要时补 `docs/nongyu-rn-app/tech/二课鉴权方案.md`（登录真机调通后回填，对齐教务鉴权文档风格）。
- 本轮不做 A2UI 组件复用落地（PRD 提及「设计时考虑」即可，不强制本轮实现 Agent 卡片复用）。
- 不改教务工具库与现有教务页面行为。

## 4. 详细需求

### 4.1 分层与职责

| 层         | 职责                              | 载体                                                 |
| ---------- | --------------------------------- | ---------------------------------------------------- |
| 二课会话   | 访问需登录的二课接口 / 页面       | `nongyu-tool-second`：登录、Cookie/Token、查询函数   |
| Agent Tool | Zod 入参 + `tool()` + JSON Schema | `nongyu-agent-sdk` → `ExternalTools/second-tools.ts` |
| App 会话桥 | 冷启动恢复、持久化备份、登出清理  | `modules/second/auth/*`（对齐 `jiaowuSession`）      |
| App UI     | 只读展示与筛选                    | `modules/second/screens/*` + `app/home/second*` 路由 |

登录凭据是否与教务共用、二课站点具体 URL/协议：**以逆向与真机结果为准**，写入 `TECH.md` / 鉴权文档；Spec 只要求「与教务同模式的分层会话，密码不上传 Node」。

### 4.2 `nongyu-tool-second` 导出能力（原子 API）

包对外至少提供（命名实现时可微调，但语义必须覆盖）：

| API（语义）                                                                            | 鉴权                                   | 说明                                                                                       |
| -------------------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------ |
| `setLoginData` / `secondLogin` / `clearLoginData`                                      | —                                      | 写入凭据、执行登录、清空会话                                                               |
| Cookie（或等价会话）`get` / `set`                                                      | —                                      | 冷启动恢复 / 持久化桥接                                                                    |
| `getPersonalSecondInfo`（或拆分为学分分布 / 附加分 / 累计分 / 综测 / 排名 的一组函数） | 需登录                                 | 覆盖 PRD 个人二课信息字段集合；可一个聚合接口或若干细粒度接口，**全部**需有对应 Agent tool |
| `listActivities`                                                                       | 视系统而定（列表若可匿名则允许无登录） | 支持关键词、部落、分类等筛选入参                                                           |
| `getActivityDetail`                                                                    | 视系统而定                             | 按活动 ID（或系统等价主键）取详情                                                          |

约定：

- 返回结构与教务包一致风格：`{ success, result?, message? }`（或包内统一 Result 类型），便于 RN / Agent 消费。
- 网络层：axios + 必要的编码处理；登录失效可自动重登并重放（对齐教务拦截器思路，细节进 `TECH.md`）。
- RN 消费 `dist/`；改源码后需 build。
- **禁止**写操作 API（报名等）进入本轮**代码**导出面；报名契约仅写入接口清单文档。

### 4.3 Agent Tool 封装

- 文件：`packages/nongyu-agent-sdk/src/core/tool/ExternalTools/second-tools.ts`
- 每个 4.2 业务查询函数对应至少一个 `tool()`（`name` 建议 `second_*` 前缀）。
- 登录 / `setLoginData` **不**封装为 Agent 可调 tool（与教务一致：由 App 全局会话保证）。
- 导出 `secondTools` 对象，供 Agent / GUI / CLI 注册；描述文案需说明何时调用、与 WebSearch 的优先级（校内二课优先走本工具）。
- **活动推荐**：本轮不新增 `second_recommend_*` 专用 tool；Agent 通过「个人二课信息 + 活动列表/详情」原子 tool 组合完成推荐并在回复中附理由。

### 4.4 使用文档

| 文档                        | 位置                                      | 内容                                                          |
| --------------------------- | ----------------------------------------- | ------------------------------------------------------------- |
| 使用说明                    | `packages/nongyu-tool-second/README.md`   | 安装/依赖、导出 API、登录用法、查询示例、与 Agent / RN 的关系 |
| 实现约定                    | `packages/nongyu-tool-second/TECH.md`     | 网络/编码、登录步骤、页面或接口映射、禁止冻死密钥等           |
| RN 接入（可选，登录调通后） | `docs/nongyu-rn-app/tech/二课鉴权方案.md` | 会话分层、冷启动、与教务凭据关系                              |

### 4.5 RN App 模块与路由

信息架构对齐教务「入口页 + 子页」：

| 路由（建议）                        | 页面                 | 使用 tool 能力      | 需二课登录               |
| ----------------------------------- | -------------------- | ------------------- | ------------------------ |
| `/home/second`                      | 二课入口（服务列表） | —                   | 入口可展示；需登录项门禁 |
| `/home/second/profile`（或 `info`） | 个人二课信息         | 个人二课信息 API    | 是                       |
| `/home/second/activities`           | 活动列表             | `listActivities`    | 按系统要求               |
| `/home/second/activities/[id]`      | 活动详情             | `getActivityDetail` | 按系统要求               |

行为要求：

- 替换现有 `ModulePlaceholder` 占位；首页 EntryCard 仍进 `/home/second`。
- 未登录时：入口页展示可公开服务 + 页内登录表单（或引导使用已有农屿/教务凭据完成二课会话——以鉴权方案为准）；需登录子页不可静默失败，需明确引导。
- 列表支持关键词搜索与部落/分类筛选（筛选控件形态实现时对齐教务子页搜索/壳层习惯）。
- 加载中 / 空数据 / 错误态齐全；文案区分「暂无数据」与「筛选无结果」。
- UI：语义 Token、`TabScreenBackground` / 与教务子页一致的壳（可复用或平行实现 `SecondPageShell`）；**不做报名按钮**。
- `package.json` 增加 `nongyu-tool-second: workspace:*`；Metro 若需 iconv/buffer 等与教务相同的 polyfill，按依赖实际补齐。

### 4.6 使用分流（同一 tool 面）

| 能力            | App 用户点击   | Agent 调用          |
| --------------- | -------------- | ------------------- |
| 个人二课信息    | ✅             | ✅                  |
| 活动列表 / 详情 | ✅             | ✅                  |
| 活动推荐编排    | ❌（无独立页） | ✅（组合原子 tool） |
| 报名等写操作    | ❌             | ❌                  |

## 5. 业务流程

### 5.1 App 只读查询

```text
用户打开二课入口
  →（若需）完成二课登录 / 恢复会话
  → 进入个人信息或活动列表
  → 调用 nongyu-tool-second 查询函数
  → 渲染列表/详情（只读）
```

### 5.2 Agent 推荐（编排示意）

```text
用户提出二课活动需求
  → Agent 调用个人二课信息 tool（了解缺口）
  → Agent 调用活动列表 tool（按关键词/部落/分类筛选）
  →（可选）拉取若干活动详情
  → Agent 生成推荐列表 + 理由（不落写操作）
```

### 5.3 冷启动（目标形态）

```text
本地恢复二课会话凭据/Cookie
  → setLoginData / setCookie（或等价）
  → 业务请求遇失效 → 自动重登并重放（工具层）
```

### 5.4 Token 过期无感刷新（对齐旧版 RN）

```text
业务请求返回「用户过期」/ HTTP 401·403 / 鉴权失败文案
  → 工具层用内存 LOGIN_DATA 调 secondLogin（并发只打一次；凭据来自首次登录写入的 SecureStore）
  → 成功：写新 x-access-token（内存 + App 钩子持久化 MMKV）并重放原请求
  → 失败（本地密码无效等）：清 token 与无效密码，Toast 提示，跳转二课登录页要求手动登录
```

约束：登录接口本身不参与自动重登；成功时用户无感（不跳登录页）；可选轻提示「正在自动重新登录」。首次登录成功必须持久化二课密码。

## 6. 验收标准与测试方案

### 6.1 工具库

- [ ] `pnpm --filter nongyu-tool-second build` 成功；导出类型完整。
- [ ] README 可独立指导 Node/脚本调用登录 + 至少一项查询。
- [ ] TECH.md 记录已验证登录步骤（真机/实网），禁止冻抓包死密钥作为唯一路径。
- [ ] 真机或实网：**登录成功** + **至少一项**个人二课信息或活动列表查询成功。
- [ ] 人为让 token 失效后发起业务请求：自动 `secondLogin` 一次并重放成功；并发多请求只登录一次。
- [ ] 无凭据或重登失败：不死循环；抛可读错误。

### 6.2 Agent Tool

- [ ] `secondTools` 可被 SDK 注册；`getToolSchemas()` 含全部 `second_*` 业务 tool。
- [ ] 无登录类 tool；无报名类 tool。
- [ ] CLI/GUI 或 debug 脚本能至少执行一个 second tool（环境具备会话时）。

### 6.3 RN App（理想 UI / 操作）

- [ ] 首页「二课系统」进入真实入口页（非占位文案）。
- [ ] 可进入个人二课信息页，看到学分分布/累计/综测/排名等结构化信息（字段以系统实际返回为准，空字段不崩溃）。
- [ ] 活动列表可搜索、可按部落/分类筛选；点进详情只读展示。
- [ ] 全程无报名/提交类操作入口。
- [ ] 未登录访问需登录能力时有明确引导；错误/超时有可读提示。
- [ ] Token 过期后继续浏览：轻提示自动重登，页面不跳登录页；新 token 写入 MMKV；重登失败有 Toast 并跳转二课登录页要求手动登录（同时清除无效本地密码）。
- [ ] 首次二课登录成功后，二课密码写入 SecureStore；冷启动可恢复到工具内存供自动重登。
- [ ] `pnpm --filter nongyu-rn-app` 相关 type-check / lint 通过。

### 6.4 非功能

- [ ] 二课密码（若有）不上传 Node。
- [ ] 与教务模块互不破坏；登出农屿时二课会话一并清理（若共享登出链路，在鉴权方案中写明）。

1. 二课系统基址、登录页/接口、会话 Cookie 名或 Token 形态；

3. 活动列表筛选参数的官方枚举（部落、分类）；
4. 二课登录是否可复用教务学号密码，或需独立密码 / SSO。
