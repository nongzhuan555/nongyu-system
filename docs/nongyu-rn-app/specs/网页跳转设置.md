# Spec：网页跳转设置

| 项       | 内容                                                                        |
| -------- | --------------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                                        |
| 需求类型 | **业务**                                                                    |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/MyPage/设置页面PRD.md`（网页打开设置） |
| 入口     | 「我的」→ 设置 →「网页跳转」→ `/mine/settings/web`                          |
| 状态     | **已实现**                                                                  |

---

## 1. 背景

设置首页「网页跳转」仍为「即将开放」。用户需要选择常用外链在 **App 内自建 WebView 页** 还是 **系统浏览器** 打开。

**Why**：设置 PRD「网页打开设置」；「应用内」须是农屿自有网页页，而非系统 Custom Tabs。  
**What**：设置子页开关 + 本地偏好 + 统一打开助手 + `/web-viewer` WebView 页。

---

## 2. 目标

1. 「网页跳转」可进；子页可切换「应用内打开 / 系统浏览器」。
2. 偏好本地 MMKV 持久化；默认 **应用内打开**（对齐服务端字段默认 `open_web_in_app=1`，本轮不同步远程）。
3. 提供统一 `openAppUrl`：应用内 → 路由进自建 WebView；否则 `Linking.openURL`；失败 Toast。
4. 接入范围（本轮）：首页 **常用网站**、我的页 **关于农屿**。
5. 跳过 tech；本 Spec 确认后直接编码。

---

## 3. 边界（非目标）

- 不做自定义全屏以外的第三方内嵌方案；**应用内 = `react-native-webview` 自建页**（非 `expo-web-browser`）。
- 不同步 Node `/api/app/settings` 的 `openWebInApp`（后置）。
- 不改教务通知/竞赛等已单独打开外链的入口（本轮不纳入开关）。
- 不做主题 / 首屏课表等其它设置项。

---

## 4. 详细需求

### 4.1 路由

| 界面       | 路由                 | 说明                                         |
| ---------- | -------------------- | -------------------------------------------- |
| 设置首页   | `/mine/settings`     | 「网页跳转」可进                             |
| 网页跳转   | `/mine/settings/web` | 开关偏好                                     |
| 应用内网页 | `/web-viewer`        | `url` + `title` 查询参数；顶栏返回 + WebView |

### 4.2 设置子页 UI

- 壳：复用 `SettingsPageShell`（与课表/Agent 一致）。
- 标题：「网页跳转」。
- 主控件：开关——**在应用内打开网页**（开 = 自建 WebView 页；关 = 系统浏览器）。
- 辅文案说明两种模式差异（一两句即可）。
- 切换立即持久化，无需单独「保存」按钮。

### 4.3 数据

| 项   | 约定                                          |
| ---- | --------------------------------------------- |
| 键   | MMKV，如 `app:open_web_in_app`（`"1"`/`"0"`） |
| 默认 | 未写入时视为 `true`（应用内）                 |
| 状态 | Zustand store（或同等）供 UI 与打开助手读     |

登出：**不**强制清除该偏好（属设备级 App 设置，非敏感账号数据）。

### 4.4 打开行为

| 偏好           | 行为                                                     |
| -------------- | -------------------------------------------------------- |
| `openWebInApp` | `router.push('/web-viewer?url=&title=')`，页内 `WebView` |
| 否则           | `Linking.openURL(url)`（可先 `canOpenURL`）              |

应用内页：顶栏标题（站点名或「网页」）+ 返回；加载中可有指示；无效 URL 有可读提示。

失败：Toast（如「打开失败」）；不崩溃。

### 4.5 接入点

| 入口            | 现状           | 目标            |
| --------------- | -------------- | --------------- |
| 首页常用网站    | 一律 `Linking` | 走 `openAppUrl` |
| 我的 · 关于农屿 | 一律 `Linking` | 走 `openAppUrl` |

---

## 5. 业务流程

```text
设置 → 网页跳转 → 切换开关 → MMKV
首页点常用网站 / 我的点关于农屿
  → 读偏好 → 内置 WebBrowser 或系统浏览器
```

---

## 6. 验收标准

- [ ] 设置首页「网页跳转」可进，不再「即将开放」。
- [ ] 切换后杀进程重进，偏好仍在；默认应用内。
- [ ] 开：常用网站 / 关于农屿进入农屿内 WebView 页（可见顶栏返回）；关：系统浏览器。
- [ ] 打开失败有 Toast。
- [ ] `type-check` / lint / format 通过。

### UI
