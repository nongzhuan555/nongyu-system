# Spec：列表回顶悬浮按钮（玻璃拟态）

| 项       | 内容                                                        |
| -------- | ----------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                        |
| 需求类型 | **基建**                                                    |
| 关联     | 广场 `PostFeedList`、教务 `JiaowuPageShell`、二课活动列表等 |
| 状态     | 已确认（grill 全按推荐）                                    |

---

## 1. 背景

长列表下滑后回到顶部需多次手势，且常要顺带刷新。需要统一的「回顶 + 刷新」入口，视觉与现有霜膜玻璃语言一致。

## 2. 目标

1. 提供可复用的回顶 FAB（霜膜拟态，非真 BlurView）。
2. 滚动超过阈值后显示，回顶后隐藏；显隐带淡入淡出。
3. 点击：动画滚到顶部，并触发与下拉刷新相同的列表刷新。
4. 本期接入：广场列表、教务壳列表、二课活动列表。

## 3. 边界（非目标）

- 不接：课表周横向分页、首页整页 ScrollView、AI 消息列表、详情页短文 ScrollView、登录表单 ScrollView。
- 不在内容区使用真 `BlurView` / `GlassPanel`（位于 `BlurTargetSurface` 内会 Android 闪退）。
- 本期不强制改管理端 Web。

## 4. 详细需求

### 4.1 显示规则

| 项   | 约定                                           |
| ---- | ---------------------------------------------- |
| 出现 | `contentOffset.y > 240`                        |
| 消失 | `y ≤ 240`（含回顶动画结束后）                  |
| 动效 | 淡入淡出（约 180–220ms）                       |
| 位置 | 右下角；有悬浮底栏时抬高避开底栏；否则贴安全区 |

### 4.2 交互

1. 点击 → `scrollTo` / `scrollToOffset` **animated: true** 至 `y=0`。
2. 同时触发当前列表的 refresh（与 `RefreshControl.onRefresh` 同源）。
3. 无 refresh 能力时仅回顶。
4. `accessibilityLabel`：`回到顶部并刷新`。

### 4.3 视觉

- 圆形约 48；半透明 surface/霜膜 + 细描边；图标 `chevron-up`，品牌色。
- 与分段 Tab 霜膜同套路，禁止实心不透明白块。

### 4.4 接入点

| 列表                     | 说明                           |
| ------------------------ | ------------------------------ |
| `PostFeedList`           | FlashList；广场 Tab 抬高避底栏 |
| `JiaowuPageShell`        | ScrollView + `onRefresh`       |
| `SecondActivitiesScreen` | FlatList + 现有 refresh        |

## 5. 验收

| #   | 场景         | 期望                                  |
