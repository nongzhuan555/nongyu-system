# Spec：全局下雨特效预览 MVP

## 背景

全局前景雨效由用户开关控制「是否启用」；启用后根据学院/校区映射到川农三校区拉取天气，仅雨天显示雨效。不使用设备定位。

## 目标

- 设置中可开关；开启且校区当前为雨类天气时显示雨丝 + 涟漪
- 学院 → 校区 → Open-Meteo（固定经纬度）
- 天气拉取时机：
  1. **进入 App**（档案就绪且处于前台 / 从后台回到前台）拉一次
  2. **前台期间每 5 分钟**拉一次；进入后台停止定时
  3. **切换下雨特效开关**时拉一次
- 零新原生依赖

## 边界（非目标）

- 设备定位 / GPS
- 雪/雾等其它天气粒子；Lottie / Skia
- 雨滴与 UI 真实碰撞
- 开关偏好远程同步

## 详细需求

1. 偏好 `rainEnabled`（MMKV）；开启表示「允许按天气显示雨效」；可通过设置页或 Agent `settings_get` / `settings_update`（字段 `rainEnabled`）读写
2. 校区解析优先级：`profile.campus` 文案匹配 → `profile.college` 映射表 → 默认雅安
3. 马克思主义学院固定雅安；学院名做别名兼容
4. Open-Meteo `weather_code` 属雨类则 `isRaining=true`
5. 并发请求去重（inFlight）；失败则 `isRaining=false`，不阻断后续按时机重试
6. 雨丝约 20–24 条 + 涟漪对象池；后台暂停雨丝动画

## 业务流程

登录档案就绪且前台 → 拉天气 → 写 store → `rainEnabled && isRaining` 显示；前台每 5 分钟刷新；后台停表；回前台立即再拉并重启 5 分钟定时；设置页拨动开关立即再拉。

## 验收

- 开关关：无雨效
- 开关开 + 雨天：有雨效；非雨天：无雨效
- 进 App / 回前台可见天气请求；前台停留 ≥5 分钟可见周期性请求；后台无定时请求
- 拨动开关立即出现天气请求
- 无学院/校区时回退雅安仍可请求
