# Spec：启动页（首屏 Tab）设置

| 项       | 内容                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                                          |
| 需求类型 | **业务**                                                                      |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/MyPage/设置页面PRD.md`（是否首屏为课表） |
| 入口     | 「我的」→ 设置 →「启动页」→ `/mine/settings/launch`                           |
| 状态     | **已实现**                                                                    |

---

## 1. 背景

PRD 要求「是否首屏为课表页」；当前登录成功与 `AuthRoot` 一律 `replace("/(tabs)/home")`，`(tabs)` 的 `initialRouteName` 也固定为 `home`。

**Why**：部分用户希望打开 App（已登录进入主栈）直接看到课表。  
**What**：本地偏好 + 设置子页 + 进入主 Tab 时按偏好跳转；并同步 Agent `settings_*` Tools。

---

## 2. 目标

1. 设置首页新增「启动页」可进；子页可选 **首页** / **课表**（单选）。
2. MMKV 持久化；默认 **首页**；登出**不**清除（设备级）。
3. 凡「进入主 Tab」均跟随偏好：登录成功、`AuthRoot` 已登录离开登录页、以及其它硬编码进 `/(tabs)/home` 的路径改为读偏好。
4. Agent：`settings_get` / `settings_update` 增加 `launchTab`。
5. 跳过 tech；本 Spec 确认后编码。

---

## 3. 边界（非目标）

- 不支持广场/我的作为启动 Tab（本轮仅 home|course）。
- 不改变未登录冷启动仍先到登录页。
- 不同步服务端 user_settings。
- 不改动 Tab 栏本身顺序。

---

## 4. 详细需求

### 4.1 路由

| 界面     | 路由                    | 说明       |
| -------- | ----------------------- | ---------- |
| 设置首页 | `/mine/settings`        | 启动页可进 |
| 启动页   | `/mine/settings/launch` | 本轮新增   |

根 Stack 注册 `mine/settings/launch`，`headerShown: false`，`title: "启动页"`。

### 4.2 数据

| 项   | 约定                                   |
| ---- | -------------------------------------- |
| 字段 | `launchTab`: `"home" \| "course"`      |
| MMKV | `app:launch_tab`；缺省 / 非法 → `home` |
| 登出 | 不清除                                 |

Store：如 `useAppLaunchPrefsStore`（与 `appWebPrefsStore` 同模式）。

### 4.3 设置 UI

- 壳：`SettingsPageShell`。
- 单选两行：首页 / 课表（说明文案简短）；立即持久化。
- 设置首页条目：`title: "启动页"`，`description: "打开 App 后进入首页或课表"`。

### 4.4 跳转逻辑

提供助手如 `resolveLaunchHref(): "/(tabs)/home" | "/(tabs)/course"`，至少替换：

- `AuthRoot` 已登录且在登录页时的 `replace`
- `LoginScreen` 登录成功后的 `replace`
- `app/login.tsx` 已登录 `Redirect`

说明：用户从底栏主动切 Tab 不受影响；仅「进入主栈」默认落点跟随偏好。

### 4.5 Agent

| Tool              | 变更                                        |
| ----------------- | ------------------------------------------- |
| `settings_get`    | 快照增加 `launch.tab`: `"home" \| "course"` |
| `settings_update` | 可写 `launchTab`                            |
| systemPrompt      | 补充「启动页 / 首屏课表」指引               |

---

## 5. 业务流程

```text
设置 → 启动页 → 选 home/course → MMKV
登录成功 / AuthRoot 进主栈 → resolveLaunchHref → replace 对应 Tab
Agent：「首屏设为课表」→ settings_update(launchTab=course)
```

---

## 6. 验收标准

- [x] 设为课表后：退出登录再登录（或杀进程已登录冷启动进主栈）落在课表 Tab。
- [x] 设为首页后：同上落在首页。
- [x] 默认未配置时行为与现网一致（首页）。
- [x] Agent 可查询/修改；与设置页一致。
- [x] `type-check` 通过。
