## 2. 意向（将来若做）

- 交互方向：长按开始录音 → 松手结束 → 转写结果写入输入框（可再编辑后发送）。
- 转写方案曾对比：云端文件转写、系统 ASR、端侧自带模型；选型需按当时机型覆盖与换壳成本再定。
- 预期改动面：RN 聊天输入 UI + 录音/识别依赖；**不必**改 `nongyu-agent-sdk` 对话协议（结果仍是普通文本 prompt）。
