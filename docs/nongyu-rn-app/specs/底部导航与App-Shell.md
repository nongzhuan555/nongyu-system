# Spec：底部导航与 App Shell（占位）

| 项       | 内容                                                       |
| -------- | ---------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app`                                       |
| 需求类型 | **基建**                                                   |
| PRD      | `docs/forhuman/rawprds/nongyu-rn-app/Shell/底部导航PRD.md` |
| 参考视觉 | 会话内悬浮底栏参考图（左圆形入口 + 右胶囊 Tab + 毛玻璃）   |
| 状态     | **已实现（占位壳）；选中指示器迭代已落地**                 |

---

## 1. 背景

农屿学生端需要可扩展的主导航壳：四个主 Tab（首页、课表、广场、我的）与独立「农屿 AI」入口。本次只搭架子与底部导航视觉/交互，页面内容占位，为后续业务模块提供稳定路由与壳层组件。

---

## 2. 目标

1. 提供自定义底部栏组件，结构与参考图一致：左侧圆形「农屿 AI」+ 右侧约 70% 宽胶囊 Tab 容器。
2. 四个 Tab 路由可切换；默认落地「首页」。
3. 选中态为**椭圆毛玻璃指示器**（比右侧大胶囊更糊）+ 图标/文案主题 `brand`；切换时指示器以「水滴」动感在 Tab 间移动（非瞬变）。
4. 底栏使用 `expo-blur` 实现双端毛玻璃（同一组件思路）。
5. 点击「农屿 AI」进入占位页，转场为淡入 + 轻微放大（约 320ms，ease-out）；AI 页不展示底栏。
6. 图标统一 Ionicons **filled** 实心风格。

---

## 3. 边界（非目标）

- 不实现首页 / 课表 / 广场 / 我的 / AI 的真实业务与数据。
- 不设计 AI 入口最终视觉以外的插画体系；圆形按钮内使用资源图 `assets/nongyuai.jpg`（含角色头像与「农屿AI」字标）。
- 不调整登录鉴权、会话、埋点策略。
- 不编写独立技术方案文档（本需求跳过 tech）；本次 UI 迭代仅更新本 Spec。
- 不在本次完成 `design-system/rn-app/MASTER.md` 全文定调（可随壳层落地补充 token 扩展）。
- 不做指示器过淡到不可辨；填充跟主题浅色（`brandMuted`），可随主题切换。

---

## 4. 详细需求

### 4.1 信息架构与路由

| 入口    | 路由（约定）      | 类型     | 底栏     |
| ------- | ----------------- | -------- | -------- |
| 首页    | `/(tabs)/home`    | Tab      | 显示     |
| 课表    | `/(tabs)/course`  | Tab      | 显示     |
| 广场    | `/(tabs)/center`  | Tab      | 显示     |
| 我的    | `/(tabs)/mine`    | Tab      | 显示     |
| 农屿 AI | `/ai`（根 Stack） | Stack 页 | **隐藏** |

- Tab 路由命名与 `src/modules` 对齐：`home` / `course` / `center` / `mine`。
- `/(tabs)/index` 仅作默认落地重定向到 `home`（Expo Router 需要 index，否则 `/` 会 Unmatched）。
- Tab 从左到右顺序：**首页 → 课表 → 广场 → 我的**。
- 冷启动默认选中：**首页**（`home`）。
- 「农屿 AI」为 Stack push；返回后回到进入前的 Tab，不重置 Tab 状态（在系统能力范围内）。

### 4.2 底部栏布局

- 整体**悬浮**：相对屏幕左右有外边距；**底部间距 = 安全区 inset + 额外悬浮间距**（避免贴底）。
- **左侧**：正圆形按钮；内部为 `assets/nongyuai.jpg` 封面图（`resizeMode: cover`，裁切适配圆钮）；无障碍标签仍为「农屿AI」。
- **右侧**：水平胶囊（两端全圆）；与左侧圆钮共用一行，**小间距紧邻**（避免视觉割裂）；胶囊 `flex:1` 占满剩余宽度。
- 右侧胶囊内四个 Tab **均分**宽度；每项为「图标在上 + 短文案在下」。
- **响应式**：底栏尺寸随屏宽缩放（以约 390 宽为基准，限制上下限）。

### 4.3 视觉与主题

| 元素            | 要求                                                                                                                                                                                                        |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 毛玻璃          | `expo-blur` 真模糊；**磨砂玻璃**：中高模糊 + **薄**霜白膜；看不清背后文字，但滚动时能明显感到底下色块/光影变化；**禁止**实心白块；Android 配合 `BlurTargetView`；`blurMethod` 为 `dimezisBlurViewSdk31Plus` |
| 胶囊 / 圆钮表面 | 轻描边 + 轻阴影 + 薄霜；不得过透（背后文字不可读），也不得过厚（观感不透明）                                                                                                                                |
| 未选中 Tab      | filled 图标 + 文案，颜色为主题次要文字色                                                                                                                                                                    |
| 选中 Tab        | 见 §4.3.1：椭圆毛玻璃指示器 + 图标/文案 `brand`                                                                                                                                                             |
| 图标集          | Ionicons filled：首页 `home`、课表 `calendar`、广场 `compass`、我的 `person`                                                                                                                                |

#### 4.3.1 选中椭圆指示器（毛玻璃 + 水滴动效）

| 项       | 要求                                                                                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 形态     | 包住当前 Tab「图标 + 文案」的**小胶囊/椭圆**：相对**整条右侧胶囊**上下等距内缩（`activeInsetV`，约 5px），左右相对 Tab 格略收（`activeInsetH`）；圆角接近全圆 |
| 材质     | 玻璃拟态 + **主题浅色底**（`brandMuted` × 约 **0.45** 透明）；比右侧大胶囊更糊；须可辨选中椭圆，同时能感到底下光影                                            |
| 模糊层级 | 指示器用**独立 Blur 层**叠在大胶囊内容区内滑动；**禁止**把 BlurView 嵌套在另一 BlurView 内部（Android 易闪退）；与大栏共用 `BlurTargetView` 即可              |
| 前景     | 选中 Tab 的图标与文案仍为主题 `brand`；未选中为次要文字色；指示器在图标/文案**下方**（z 序），不遮挡点击                                                      |
| 动效形态 | **水滴移动**：指示器在 Tab 间**水平滑动**；行程中略**横向拉伸再收回**；落地时轻微**垂直弹跳**；禁止瞬变切换                                                   |
| 动效时长 | 体感约 **380–450ms**；软弹簧（可略过冲再回落）；相邻与跨多格共用同一套弹簧参数（跨格因位移更大而自然更有动感）                                                |
| 实现约束 | 使用已有 `react-native-reanimated`；路由切换与指示器动画同步触发；快速连点时动画可打断并追向最新选中项                                                        |
| Token    | 填充跟主题 `brandMuted`；blur 等可扩展 `tokens.tabBar.activeBlur*`，与大栏参数区分                                                                            |

### 4.4 「农屿 AI」交互与转场

- 点击圆形入口 → 压入 `/ai` 占位页。
- 转场：**opacity 淡入 + scale 轻微放大**（建议初始 scale ≈ 0.92～0.96 → 1），时长约 **320ms**，缓动 **ease-out**。
- AI 页展示简单占位文案即可；**不渲染**自定义底栏。
- 返回：pop 回 Tab 容器；动效应可读、不突兀（可与进入对称或使用框架默认返回动画，优先保证进入侧高级感）。

### 4.5 占位页内容

四个 Tab 页与 AI 页均只展示标题级占位说明（标明模块名即可），不拉取业务数据、不展示假业务列表（除非仅为撑起毛玻璃演示所必需的极简背景）。

### 4.6 工程约束

- 依赖：已引入 `expo-blur@~57.0.2`；启用真模糊前需**重打 Dev Client / 原生壳**。
- 自定义底栏：隐藏 Expo Router 默认 `tabBar`，改用自研组件（或等价 `tabBar` 插槽），保证布局自由度。
- 代码含必要中文注释；类型完整；改动后通过本仓库 `lint` / `type-check` / `format` 约定。

### 4.7 内容与悬浮底栏重叠时的视觉让位（各 Tab 通用）

悬浮底栏会压在可滚动内容之上。**凡四个主 Tab（home / course / center / mine）内有纵向滚动内容**，当某块内容滚到与底栏视觉占用区重叠时，必须做类似「降透明 / 渐隐让位」处理，避免内容与毛玻璃底栏堆叠、主次不清、观感杂乱。

约定：

| 项       | 要求                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------ |
| 适用范围 | 所有主 Tab 可滚动页；不只首页。列表尾部、底栏附近的卡片/文案均适用                                     |
| 触发     | 内容底边（或显著视觉块）进入底栏保护区（安全区 + 悬浮间距 + 底栏高度附近）                             |
| 效果     | 透明度随重叠加深而降低（参考首页 `SocialCopyCard`：最低约 0.34，行程约数十 px 渐变）；离开保护区后恢复 |
| 交互     | 降透后仍可点击（除非产品明确要求禁用）；不得用实心遮罩挡住底栏毛玻璃                                   |
| 参考实现 | `HomeScreen` 滚动监听 + 社交卡 `opacity` 插值；后续 Tab 可抽公共 hook，但行为须一致                    |

## 5. 业务流程

```text
启动 App
  → 进入 Tab 容器，默认「首页」（选中椭圆指示器落在首页）
  → 用户点击右侧某一 Tab
       → 切换对应页；椭圆指示器以水滴动效滑向目标 Tab；图标/文案变为 brand
  → 用户点击左侧「农屿AI」
       → 隐藏底栏语境下 push /ai
       → 播放淡入 + 轻微放大（~320ms）
  → 用户返回
       → 回到原 Tab 页，底栏重新显示（指示器仍在原选中 Tab）
```

## 6. 验收标准与测试方案

### 6.1 UI（理想效果）

- [ ] 底栏为悬浮结构：左圆钮 + 右胶囊，比例与间隙接近参考图。
- [ ] 右侧胶囊 / AI 圆钮毛玻璃偏毛：背后内容不可清晰辨认，仅能感到色块/光影变化（新壳 + 支持机型）。
- [ ] 四 Tab 文案与顺序正确；图标为 filled。
- [ ] 选中项有椭圆毛玻璃指示器（包住图标+文案、上下有内边距）；指示器比大胶囊更糊；底色为主题浅色（`brandMuted`），选中态一眼可辨。
- [ ] 选中图标/文案为品牌色；未选中为次要文字色；切换主题色时强调色跟随。
- [ ] Tab 切换时指示器滑动 + 中途横向拉伸 + 落地轻弹，体感约 0.4s，非瞬变。
- [ ] AI 圆钮与右侧胶囊紧邻，不呈左右两端割裂。
- [ ] 底栏与屏幕底边有明显悬浮间距（安全区之外另有间距）。
- [ ] 毛玻璃不过透、也不做成实心白块；指示器与大栏均非实心白块。
- [ ] 不同屏宽下底栏尺寸比例协调（响应式缩放）。
- [ ] AI 圆钮内为 `nongyuai.jpg` 头像图（cover 铺满圆），无障碍名仍为「农屿AI」。
- [ ] 可滚动内容与底栏重叠时有降透/渐隐让位，不与底栏抢视觉（见 §4.7）。

### 6.2 功能操作

- [ ] 冷启动落在首页；指示器初始在首页位。
- [ ] 四个 Tab 可互相切换，状态与路由一致；快速连点时指示器追向最终选中项。
- [ ] 点击「农屿AI」进入 AI 占位页；该页无底栏。
- [ ] 进入 AI 页可见淡入 + 轻微放大，时长体感约 0.3s。
- [ ] 从 AI 返回后仍在进入前的 Tab（或至少回到 Tab 容器且选中合理）。

### 6.3 工程

- [ ] `pnpm --filter nongyu-rn-app type-check` 通过。
- [ ] 仓库约定的 lint / format 通过。
- [ ] 文档：本 Spec 已更新；跳过 tech / plan，用户确认 Spec 后直接编码。
- [ ] Android 上指示器毛玻璃不因嵌套 Blur 导致闪退。
