## SSH

| 项       | 填写                                            |
| -------- | ----------------------------------------------- |
| Host     | `<公网 IP>`                                     |
| User     | `root`（或专用部署用户）                        |
| 认证     | 优先私钥                                        |
| 口令     | （仅写在本机副本）                              |
| 私钥路径 | 如 `C:\Users\<you>\.ssh\id_ed25519_nongyu_node` |

## 远程路径（装机后填写）

| 项           | 建议默认                             |
| ------------ | ------------------------------------ |
| 应用目录     | `/opt/nongyu-node`                   |
| Node 监听    | `127.0.0.1:3000`                     |
| systemd unit | `nongyu-node.service`                |
| Nginx 站点   | `/etc/nginx/conf.d/nongyu-node.conf` |
| ACME webroot | `/var/www/acme`                      |
| 证书目录     | `/etc/letsencrypt/live/<公网IP>/`    |
| MySQL        | 本机已有；Node 用 `127.0.0.1:3306`   |

## HTTPS

| 项       | 填写                                     |
| -------- | ---------------------------------------- |
| 对外 URL | `https://<公网IP>`（无尾斜杠）           |
| 证书类型 | Let’s Encrypt IP + shortlived（约 6 天） |
