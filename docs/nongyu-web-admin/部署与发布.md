# 农屿 Web 管理端 · 同机静态部署（路径 /admin）

管理端与官网共用 WEB 机 Nginx，对外路径为 `/admin/`。

完整约定与日常发布见：

- [`docs/nongyu-web-site/部署与发布.md`](../nongyu-web-site/部署与发布.md)
- Nginx 样例：`docs/nongyu-web-site/deploy/nongyu-web.nginx.conf.example`
- 一键脚本：`scripts/deploy-nongyu-web.ps1` + `scripts/ops/web-deploy.env`

生产构建使用 Vite `base: /admin/`；本地 `vite` 开发仍为 `/`。
