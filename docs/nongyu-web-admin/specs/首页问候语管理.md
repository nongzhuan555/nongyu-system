---

## 1. 背景

首页第二句问候语已有 Admin API，需在 Web 管理端提供配置页，避免仅靠 API/SQL 运维。

---

## 2. 目标

1. 侧栏可进入「首页问候」页。
2. 列表：分页、按启用状态筛选；展示文案、启用态、时间。
3. 新建 / 编辑文案（≤48 字）/ 启停（全局最多一条启用）/ 删除（确认）。

---

## 3. 边界

- 不改 RN / Node 契约（已有）。
- 不做按时段多条文案、随机池 UI。

---

## 4. 详细需求

### 4.1 路由

| 路由              | 文案     |
| ----------------- | -------- |
| `/home-greetings` | 首页问候 |

### 4.2 列表与操作

- 筛选：全部 / 启用 / 禁用
- 列：文案、状态、更新时间、操作（编辑 / 启用或禁用 / 删除）
- 启用某条时：后端互斥关其它；列表刷新后仅一条为启用
- 删除前 Modal 确认

### 4.3 表单

- `message`：必填，1～48 字
- `enabled`：Switch；新建默认关或开均可（推荐默认关，避免误切线上）

---

## 5. 验收

1. 已登录管理员可从侧栏进入并 CRUD。
2. 启用 B 后 A 自动变禁用。
3. 空文案 / 超长前端校验拦截。
4. 未建档超管会话看到与其它业务页一致的无权限提示。
