---

## 1. 背景

平台 LLM 代理依赖后台 Key 池。管理员需要在 Web 管理端对参与调度的 Key 进行增删改查与启停，并查看脱敏信息与基础运行态（占用/冷却/成功失败计数）。

---

## 2. 目标

1. 新增路由页面「LLM Key 池」，侧栏可进入。
2. 列表：分页、按状态筛选；展示脱敏 Key、账号组、启停、计数与冷却态。
3. 新建 / 编辑（含可选轮换 Key）/ 启用禁用 / 硬删（删前确认）。
4. 全程不展示完整明文 Key（创建表单提交后即不可再见）。

---

## 3. 边界（非目标）

- 调用量图表、按用户用量查询、多厂商复杂配置向导。
- 一键连通性探测（可后置）。
- 修改全局环境变量（model 默认等仍走服务端 env）。

---

## 4. 详细需求

### 4.1 路由与入口

| 路由        | 行为         |
| ----------- | ------------ |
| `/llm-keys` | Key 池管理页 |

- 侧栏增加入口（文案：「LLM Key 池」或「模型密钥池」）。
- 需已登录且已建档管理员；鉴权守卫沿用壳层。

### 4.2 列表

**筛选**

| 控件 | 参数     | 说明               |
| ---- | -------- | ------------------ |
| 状态 | `status` | 全部 / 启用 / 禁用 |

**列**

| 列        | 来源                         |
| --------- | ---------------------------- |
| 名称      | `name`                       |
| 账号组    | `accountGroup`               |
| Key       | `****` + `apiKeySuffix`      |
| 模型      | `model` 或「默认」           |
| 并发      | `maxConcurrent`              |
| 权重      | `weight`                     |
| 状态      | `status`                     |
| 占用      | `inFlight`（无则 —）         |
| 冷却      | `cooling` / `cooldownUntil`  |
| 成功/失败 | `successCount` / `failCount` |
| 最近使用  | `lastUsedAt`                 |
| 操作      | 编辑 / 启停 / 删除           |

- 加载 Skeleton；失败可重试；空态「暂无密钥，请添加」。

### 4.3 新建

表单字段：名称、账号组、API Key（密码框）、Base URL（可选）、模型（可选）、最大并发（默认 1）、权重（默认 1）、启用开关（默认开）。

提交调用 `POST /api/admin/llm/keys`；成功 Toast 并刷新列表。

### 4.4 编辑

- 打开抽屉或弹窗，回填非敏感字段。
- API Key 输入框占位「留空则不修改」；填写则轮换。
- 提交 `PATCH /api/admin/llm/keys/:id`。

### 4.5 启停与删除

- 启停：`PATCH` 只改 `status`；或列表快捷开关。
- 删除：确认文案含名称与 suffix；确认后 `DELETE`。

### 4.6 视觉

遵循 `design-system/web-admin/MASTER.md` 与现有用户管理页交互密度（表格 + 抽屉/弹窗），不新造视觉语言。

---

## 5. 验收

1. 管理员可完成 Key 的增、改、启停、删，列表可见脱敏与账号组。
2. 网络面板中任何 Admin 响应体均无完整 apiKey 明文。
3. 禁用后该 Key 不再出现在「启用」筛选；代理侧不再选用（联调验证）。
4. bootstrap 未建档会话：与其它业务页一致，写操作失败有可行动提示。
