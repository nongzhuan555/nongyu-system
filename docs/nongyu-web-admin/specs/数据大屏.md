---

## 1. 背景

管理员需要用图表看清农屿运行状态与用户行为。`/dashboard` 目前是占位页。本库指标接口已存在；埋点类指标经 Node 代理 Track。交互上需要 **Bento 网格可拖拽改序、拖边角改尺寸**，布局与增长趋势时间范围记在 **浏览器 localStorage**（不跟账号）。图表库使用已引入的 **ECharts**（`echarts` + `echarts-for-react`）。

---

## 2. 目标

1. `/dashboard` 成为真实大屏：KPI + 分布/趋势图 + 页面使用 + 设置分布 + 性能 + 崩溃表。
2. 卡片可拖拽排序、可缩放占位；图表随容器 resize 重绘。
3. 布局与增长 `range` 持久化到 localStorage；损坏/版本不兼容时回默认；提供「恢复默认布局」。
4. 进入页面各拉一次数据；工具栏手动刷新；不自动轮询。
5. 本库指标与 Track 指标 **失败隔离**：一边挂了另一边仍展示。

---

## 3. 边界（非目标）

- 「用户使用时间分布」（无上游聚合）。页均停留见增量 Spec `数据大屏页面映射与停留时长.md`。
- 图表内部 dataZoom / 刷选时间轴。
- 隐藏/显示单卡、多套布局、按账号云同步。
- DAU 趋势、online_peak 趋势（BFF 的 `/track/trend` 本期页面不调用）。
- **月活（MAU）**：本期不做；见 `月活MAU查询-后续考虑.md`。
- 崩溃详情页、按人筛选、导出。
- 独立技术方案文档（已约定跳过）。
- 不改 RN / Track 上报口径。
- 工作台仍为入口卡片，不把大屏图表嵌进工作台。

---

## 4. 详细需求

### 4.1 路由与壳

| 项               | 行为                                                          |
| ---------------- | ------------------------------------------------------------- |
| `/dashboard`     | 替换 `DashboardPlaceholderPage`；需登录                       |
| 侧栏「数据大屏」 | 路径不变                                                      |
| 工作台卡片       | 仍链到 `/dashboard`，文案可改为「查看运行指标」类，不堆假数据 |

页头：标题「数据大屏」+ 一句说明（系统运行与用户行为）+ **刷新** + **恢复默认布局**。触摸热区 ≥44px。

### 4.2 卡片目录

网格内每张卡有稳定 `id`（localStorage 的 `i`）。缺 id 的旧存储丢弃。

| id                    | 标题         | 展示                                                        | 数据                                                               |
| --------------------- | ------------ | ----------------------------------------------------------- | ------------------------------------------------------------------ |
| `kpi-total-users`     | 总用户数     | 大数字总用户；辅文「其中管理员 N」                          | `GET /api/admin/dashboard/overview`                                |
| `kpi-dau`             | 今日日活     | 大数字 DAU；辅文「当日至少一次打开 App」                    | `GET /api/admin/track/overview` 的 `dau`                           |
| `kpi-online`          | 当前在线     | 大数字                                                      | overview `onlineUsers`                                             |
| `kpi-today-new`       | 今日新增     | 大数字                                                      | overview `todayNewUsers`                                           |
| `chart-user-growth`   | 用户增长趋势 | 平滑折线；卡内 range：7/30/90/180/365 天，默认 7 天         | `GET /api/admin/dashboard/user-growth?range=`                      |
| `chart-gender`        | 性别分布     | 饼/环                                                       | `user-distribution.gender`（male/female/unknown → 男/女/未知）     |
| `chart-college`       | 学院分布     | 横向柱（项可能多）                                          | `college`                                                          |
| `chart-grade`         | 年级分布     | 柱                                                          | `grade`                                                            |
| `chart-device`        | 设备品牌分布 | 饼或柱                                                      | `deviceBrand`（空 → 未知；苹果单独，安卓按品牌，与后端 key 一致）  |
| `chart-screen-views`  | 页面使用次数 | 横向柱 Top N                                                | `GET /api/admin/track/dims?metric=screen_views`                    |
| `chart-screen-dwell`  | 页均停留     | 横向柱（秒）                                                | `GET /api/admin/track/dims?metric=screen_dwell_avg`（见停留 Spec） |
| `chart-button-clicks` | 按钮点击分布 | 横向柱 Top N（`event_name`）                                | `GET /api/admin/track/dims?metric=button_clicks`                   |
| `chart-settings`      | 用户设置分布 | 同一卡内 2×2 小饼：主题、首屏课表、应用内打开网页、智慧助手 | `GET /api/admin/dashboard/settings-distribution`                   |
| `chart-perf`          | 关键性能     | 分组柱：各 `event_name` 的 p50 / p95（毫秒）                | 并行 `perf_p50` 与 `perf_p95` dims                                 |
| `table-crashes`       | 错误捕获     | 表格，非 ECharts                                            | `GET /api/admin/track/crashes`（默认当天，可分页）                 |

KPI **不用** ECharts。其余图用 ECharts，色板 `['#10B981', '#FBBF24', '#34D399', '#FCD34D']`，折线 `smooth: true`，tooltip 圆角。空数据：卡片内「暂无数据」，不画假点。

### 4.2.1 图表数值排序（2026-09-05）

| 项       | 行为                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 适用范围 | 所有 **分类/分布类** ECharts 卡：性别/学院/年级/设备、页面使用、页均停留、按钮点击、设置分布（各小饼）、App 性能、官网 Web Vitals |
| 不适用   | KPI；`chart-user-growth`（时间序列保持日期升序）；`table-crashes`（表格分页，不另做数值排序控件）                                 |
| 控件     | 卡头右侧「降序 / 升序」切换（Segmented），**默认降序**                                                                            |
| 口径     | 按展示用数值排序（`count` / `metricValue`；双系列性能图按 `p95`，缺则 `p50`）                                                     |
| 横向柱   | 数值更大（降序时）或更小（升序时）的类目靠近图表 **顶部**                                                                         |

`chart-perf`：`dimValue` 为事件名（如课表渲染、长列表）。无数据时说明「暂无性能样本」。不在前端写死事件名白名单（有什么展示什么，按 `metricValue` 降序，最多 20 条）。

崩溃表列：时间（`receivedAtMs` 格式化为上海可读时间）、事件名、学号、版本、平台、品牌、`props` 中 message/stack 截断（单行 + Tooltip 全文，stack 最多展示前 2KB）。分页：`page` / `pageSize=10`。

### 4.3 网格交互

- 使用可拖拽 + 可缩放的 **响应式网格**（推荐 `react-grid-layout`，12 列）。
- 拖卡片改 `x/y`；拖右下角改 `w/h`。最小尺寸：KPI `minW=2,minH=2`；图表 `minW=3,minH=3`；崩溃表 `minW=4,minH=4`。
- 松手后写 localStorage；拖拽中不写。
- 图表容器 `ResizeObserver` 或库回调里 `chart.resize()`。
- 断点：`lg≥1200` 12 列；`md≥768` 8 列；更窄 4 列且默认 `w` 拉满（堆叠）。
- **窄屏（网格 xs / 壳层 &lt; lg）**：禁用拖拽改序与缩放，仅纵向滚动（见增量 Spec `隐藏校区与移动端布局优化.md`）。桌面拖拽手柄仍在卡片标题条，避免和图表 tooltip 抢手势。
- **校区**：接口 `user-distribution.campus` **仍可返回（先获取）**；卡片 `chart-campus` **已移除、暂不展示**。读 prefs 时若遇 `chart-campus` 过滤丢弃并 compact。

**默认布局（lg，12 列）** 建议：

| 行  | 卡片                                  | w×h       |
| --- | ------------------------------------- | --------- |
| 0   | 四个 KPI 各 `3×2`                     | x=0,3,6,9 |
| 2   | 增长趋势 `12×4`                       |           |
| 6   | 性别/年级/设备 各约 `4×4`（三卡均分） |           |
| 10  | 学院 `6×5` + 页面使用 `6×5`           |           |
| 15  | 设置分布 `6×5` + 性能 `6×5`           |           |
| 20  | 崩溃表 `12×5`                         |           |

md/xs 由库 compact 推导；若存储里缺某断点，用默认生成。

### 4.4 localStorage

| 项   | 值                                                             |
| ---- | -------------------------------------------------------------- |
| Key  | `nongyu.admin.dashboard.layout.v1`                             |
| 范围 | 本浏览器本源；**不**跟登录账号；登出不清（布局是习惯不是会话） |

```ts
type DashboardPrefsV1 = {
  version: 1;
  growthRange: "7d" | "30d" | "90d" | "180d" | "365d";
  layouts: Record<string, Array<{ i: string; x: number; y: number; w: number; h: number }>>;
};
```

- 合法 `growthRange` 才会采用，否则 `7d`。
- `layouts` 每项必须 `i` 属于 §4.2 的 id 集合；未知 id 丢弃；**缺卡用默认几何补上**（避免发版新增卡片消失）。
- JSON 损坏、`version !== 1`、隐私模式/配额失败：内存用默认，不白屏。
- 「恢复默认布局」删除该 key（或写入默认）并立刻应用；**保留**当前 `growthRange` 不强制改回 7d（range 是看数习惯，与排版分开）。若希望一并重置 range，仅当用户点恢复时把 range 也设回 `7d`——**锁定：恢复默认同时把 range 设回 `7d`**，避免两套「默认」口径。
- 改 range：立刻请求 `user-growth` 并写入 prefs。

读写须 `try/catch`（与现有 `storage.ts` 同策略）。

### 4.5 数据加载

进入 `/dashboard`：

1. 并行请求：`dashboard/overview`、`user-distribution`、`settings-distribution`、`user-growth`（当前 range）、`track/overview`、`track/dims?metric=screen_views`、`screen_dwell_avg`、`button_clicks`、`perf_p50`、`perf_p95`、`track/crashes`（page=1）。
2. 本库一组失败 → 依赖这些卡显示错误与「重试」（只重试失败组）。
3. Track 一组失败（含 502/503）→ DAU / 页面 / 停留 / 按钮 / 性能 / 崩溃显示「埋点指标暂不可用」，本库 KPI 与分布图照常。
4. 顶栏「刷新」：按当前 range 与崩溃页码重拉全部。
5. 崩溃翻页：只请求 crashes。
6. 禁止假数据 fallback。

今日口径：前后端均按 Node `BUSINESS_TZ`（默认上海）；前端不另选时区、不提供日期选择器（本期固定「今天」的 Track 查询，增长图除外）。

### 4.6 权限与空态

- 未登录：现有守卫，先登录再回 `/dashboard`。
- bootstrap 超管若 403：与用户管理相同，提示先走 App 建档，不白屏。
- 全 0 合法数据：数字 0 + 图「暂无数据」，不算错误。

### 4.7 视觉

- Bento：白底卡片、`rounded-2xl`～`rounded-3xl`、软阴影、背景 `#F8FAFC`、主色 `#10B981`。
- 数字 KPI 字重 600+；辅文 `#64748B`。
- 禁止霓虹、直角、仅 hover 才能拖/缩放。
- 窄屏内容区可纵向滚动；卡片不要定死整屏高度导致裁切图表。

---

## 5. 业务流程

```text
进入 /dashboard
  → 读 localStorage prefs（失败则默认）
  → 按 layouts 渲染网格
  → 并行拉数 → 填入各卡
拖拽/缩放结束 → 写 layouts
切换增长 range → 写 growthRange + 拉 user-growth
刷新 → 重拉全部
恢复默认 → 清布局+range=7d → 重拉 growth
```

## 6. 验收标准与测试

### 6.1 UI（理想态）

- 登录后侧栏进数据大屏，不再出现「即将开放」。
- 首屏可见四枚 KPI；向下可见增长折线与若干分布图；底部崩溃表。
- 卡片圆角大、留白足，图表绿/琥珀配色，非默认 ECharts 大红大蓝。
- 拖标题条可换位；拖角可变大变小；松手刷新后布局仍在。
- 换浏览器或清站点数据后回到默认布局。

### 6.2 功能

- [ ] 增长默认 7 天；切换 30/90/180/365 后刷新页面仍是所选 range。
- [ ] 恢复默认：卡片回到默认位置尺寸，range 回到 7d。
- [ ] 手动改 localStorage 为非法 JSON：页面用默认，不崩。
- [ ] Node dashboard 正常、Track 停：总用户/在线/新增/分布/设置/增长仍在；DAU/页面/性能/崩溃为不可用提示。
- [ ] 全部接口成功且无埋点：DAU=0、页面/性能/崩溃空态，不是报错。
- [ ] 刷新按钮会更新在线人数（改库后点刷新可见）。
- [ ] 无自动重复请求（停留 1 分钟网络面板无定时 overview）。
- [ ] 学院很多时横向柱可滚动或截断 Top，不撑破卡片。

### 6.3 回归

- [ ] 侧栏其它页、登录登出、用户管理/内容管理不受影响。
- [ ] 登出再登录：大屏布局仍在（key 未清）。

### 6.4 工程

- 新增依赖仅网格库（及类型）；图表不另选 Highcharts 等。
- 直接从组件文件 import，禁止无必要 barrel。
- `pnpm lint` / `type-check` / `format` 通过。
