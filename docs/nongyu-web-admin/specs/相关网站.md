## 1. 背景

**Why**：运营需要云厂商、农屿官网、Pushy 发版控制台与 GitHub 仓库的快捷入口。  
**What**：侧栏「相关网站」：阿里云 / 腾讯云 / 农屿官网 / Pushy / **GitHub** 外链；农屿官网另嵌手机尺寸 iframe 预览（Pushy / GitHub **仅外链**，不嵌入）。

---

## 2. 目标

1. 侧栏文案「相关网站」，图标可用链接/全球类；路由 `/related-sites`。
2. 页内 **五个**便捷跳转（`target=_blank` + `rel=noopener noreferrer`）。
3. 农屿官网区域：手机外框（约宽 390、高 844）内 iframe 加载 `http://101.43.34.229/`。
4. 旧路径 `/versions` 重定向到 `/related-sites`。
5. **不**再以 iframe 嵌入 Pushy；Pushy / GitHub 仅作为快捷外链卡片。

---

## 3. 边界

- 不嵌阿里云 / 腾讯云 / Pushy / GitHub iframe。
- 不保证目标站允许被 iframe（`X-Frame-Options` 等）；空白时靠「新窗口打开」兜底。
- 管理台若以 HTTPS 部署，HTTP iframe 可能被浏览器混合内容拦截——仍提供外链。
- 不写独立 tech 文档。

## 5. 详细需求

### 5.1 链接

| 名称     | URL                                             |
| -------- | ----------------------------------------------- |
| 阿里云   | `https://www.aliyun.com`                        |
| 腾讯云   | `https://cloud.tencent.com`                     |
| 农屿官网 | `http://101.43.34.229/`                         |
| Pushy    | `https://pushy.reactnative.cn/`                 |
| GitHub   | `https://github.com/nongzhuan555/nongyu-system` |

### 5.2 UI

- `PageFrame` **bare**：标题「相关网站」+ 简述落在画布上，**禁止**再套一层默认白底。
- 五个入口：等权单层白卡（`shadow-panel`），落在 canvas 上，文案含「新窗口打开」。
- 农屿官网预览：手机壳直接落在画布；旁附「新窗口打开」。
- 窄屏：入口纵向堆叠；宽屏可用多列网格。

### 5.3 菜单与路由

- `AdminShell`：`相关网站` → `ROUTES.relatedSites`
- `AppRouter`：注册新路由；`/versions` `Navigate` 到新路径

---

## 6. 验收

1. 侧栏无「版本管理」，有「相关网站」。
2. 五外链均可新窗口打开正确站点；含 Pushy、GitHub 仓库。
3. 农屿官网手机框内尝试加载指定地址；若被拦，外链仍可用。
4. 访问 `/versions` 落到 `/related-sites`。
5. 代码中**无** Pushy iframe；仅有 Pushy / GitHub 外链常量。
