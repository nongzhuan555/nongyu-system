---

## 1. 背景

管理员需要快速查看「当前谁在线」。大屏只有人数；用户列表有 `isOnline` 但无服务端筛选。本刀在列表 API 与管理端筛选项补齐「仅当前在线」。

---

## 2. 目标

1. `GET /api/admin/users` 增加可选 query `isOnline=1`：只返回当前在线用户。
2. 在线口径与 `GET /api/admin/dashboard/overview` 的 `onlineUsers` **一致**。
3. 用户管理页增加筛选项：全部 / 仅当前在线；可与关键词、角色、状态组合。
4. 助手工具 `admin_users_list` 支持可选 `isOnline: 1`。
5. 跳过独立 tech。

---

## 3. 边界（非目标）

- `isOnline=0`（仅离线）本期不做。
- 大屏 KPI 点击跳转/弹窗名单。
- 改心跳超时窗口（仍为 10 分钟 / `ONLINE_FRESH_WINDOW_SEC`）。
- 改列表其它字段、校区展示策略。

---

## 4. 详细需求

### 4.1 后端：`GET /api/admin/users`

**新增 Query**

| 参数       | 类型         | 说明                                                                                                                   |
| ---------- | ------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `isOnline` | 可选，仅 `1` | 传 `1` 时只返回当前在线；省略则不过滤在线。非法值（如 `0`、其它）→ 400 或忽略： **锁定为仅允许省略或 `1`，其它 → 400** |

**在线定义（与大屏一致）**

1. 处理本列表请求时先调用 `clearStaleOnlineUsers`（与 overview 相同窗口）。
2. 筛选条件：`is_online = 1` **且** `last_active_at IS NOT NULL` **且** `last_active_at >= UTC_TIMESTAMP(3) - INTERVAL 600 SECOND`。
3. 未传 `isOnline` 时：仍建议每次列表请求执行 `clearStaleOnlineUsers`，使返回行的 `isOnline` 与大屏口径一致（避免僵尸在线显示为在线）。

可与现有 `keyword` / `role` / `status` / 分页组合；切换筛选时前端重置 page=1（现有行为）。

### 4.2 管理端 UI

| 控件 | 行为                                                 |
| ---- | ---------------------------------------------------- |
| 在线 | `全部`（默认，不传参）/ `仅当前在线`（`isOnline=1`） |

- 桌面与窄屏筛选区均展示；窄屏纵向堆叠样式沿用现页。
- 空列表文案仍为「暂无用户」。

### 4.3 助手

- `admin_users_list` 增加可选 `isOnline: z.literal(1)`；description 注明可查当前在线用户。
- 系统提示可不强制改；工具描述足够即可。

### 4.4 文档同步

- 更新 `用户管理.md` 筛选表、`接口文档概览.md` Query 说明。

---

## 5. 业务流程

```text
管理员打开 /users → 选「仅当前在线」
  → GET /api/admin/users?isOnline=1&page=1&…
  → Node clearStaleOnlineUsers → 按在线条件 + 其它筛选分页返回
```

---

## 6. 验收标准

- [ ] 选「仅当前在线」时列表人数与大屏「当前在线」在相近时刻一致（允许短暂心跳差）。
- [ ] 超时未心跳用户不会出现在「仅当前在线」结果中。
- [ ] 与角色/状态/关键词组合正确；切筛选重置到第 1 页。
- [ ] 不传 `isOnline` 行为与改前兼容。
- [ ] 助手可用 `isOnline: 1` 列出在线用户。
- [ ] 相关单测（Node 列表筛选 / 清超时）覆盖；`pnpm lint` / `type-check` / `format` 通过。
