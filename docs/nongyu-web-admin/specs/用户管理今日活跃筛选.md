# Spec：用户管理今日活跃筛选

| 项        | 内容                                                                |
| --------- | ------------------------------------------------------------------- |
| 应用      | `apps/nongyu-web-admin` + `apps/nongyu-node-server`                 |
| 需求类型  | **业务**                                                            |
| PRD       | `docs/forhuman/rawprds/nongyu-web-admin/用户管理今日活跃筛选PRD.md` |
| 前置 Spec | `用户管理.md`、`用户管理在线筛选.md`                                |
| 状态      | **已实现**                                                          |

---

## 1. 背景

「今日活跃」≠「当前在线」。方案 A 用业务库 `last_active_at` 按上海业务日过滤，无需改表、无需 Track 联表。

---

## 2. 目标

1. `GET /api/admin/users?activeToday=1` 只返回今日活跃用户。
2. 条件：`last_active_at >= 今日 00:00` 且 `< 明日 00:00`（`BUSINESS_TZ`，与 `businessDayUtcRange` 一致）。
3. 管理端筛选项：全部 / 仅今日活跃；可与 keyword/role/status/isOnline 组合。
4. 助手 `admin_users_list` 支持 `activeToday: 1`。
5. UI/文档注明：**近似今日活跃，不等同大屏 DAU（app_open 去重）**。

---

## 3. 边界

- 不等同 Track DAU 用户名单。
- 不做 `activeToday=0`。

---

## 4. 验收

- [ ] 选「仅今日活跃」只含 `last_active_at` 落在今日业务日的用户。
- [ ] 可与「仅当前在线」同时选（AND）。
- [ ] 助手可传 `activeToday: 1`。
