| 项        | 内容                                                                                         |
| --------- | -------------------------------------------------------------------------------------------- |
| 应用      | `apps/nongyu-web-admin`（依赖 Track dims / Node BFF 透传）                                   |
| 需求类型  | **业务**                                                                                     |

---

## 1. 背景

大屏「页面使用次数」轴标签仅为 pathname，运营难读。RN Telemetry 已对 `screen_view` leave 上报 `duration_ms`，埋点 Spec 明确 Admin 页均停留后置；本期在大屏落地映射展示与页均停留图，并修正使用次数双计。

---

## 2. 目标

1. `chart-screen-views` 类目：映射命中 → `页面名 (pathname)`；未命中 → `pathname（未映射）`。
2. 新增卡片 `chart-screen-dwell`：「页均停留时长」，横向柱、按均值降序、当日全部页面（limit 上限内）。
3. 数值：后端 `metric_value` 为平均毫秒（整数）；前端轴/柱显示为秒，保留 1 位小数；tooltip「平均停留 Xs」。
4. `screen_views` 请求改用进入次数口径的上游数据；两图 `limit` 提到接口允许上限（100）。
5. 新卡进默认布局；旧 localStorage 缺 id 时按现有规则补默认几何。

---

## 3. 边界（非目标）

- 不改 RN 上报协议；不把映射表下沉到 Track/Node/共享包。
- 不做按日切换器、多日趋势、中位数/P95 停留。
- 不强制回填历史 `daily_dims.screen_views`（旧双计数据）；新口径自部署后 live（今日）与之后日聚合生效。
- 智慧助手 Track 工具展示映射非本期必须。
- 不写独立技术方案文档。
- 不改 KPI 总 `screen_view_count`（overview 仍可为事件总条数）。

---

## 4. 详细需求

### 4.1 路由显示名

- 映射表维护在 Web Admin（如 `src/lib/rnRouteLabels.ts`），覆盖 `apps/nongyu-rn-app/app` 下可导航屏。
- **精确路径**优先；否则按 **最长前缀模式**（如 `/home/second/activities/*`）。
- 展示格式：
  - 命中：`{中文名} ({pathname})`，例 `首页 (/home)`。
  - 未命中：`{pathname}（未映射）`。
- `pathname` 与埋点 `event_name` 一致（Expo Router，`(tabs)` 不出现在 path）。

### 4.2 页面使用次数（既有卡增强）

| 项   | 要求                                                                  |
| ---- | --------------------------------------------------------------------- |
| 数据 | `GET /api/admin/track/dims?metric=screen_views&limit=100`（默认今日） |
| 口径 | 上游改为「进入次数」（见 Track Spec）；前端只做标签映射               |
| 图表 | 仍横向柱、按次数降序                                                  |
| 标签 | §4.1                                                                  |

### 4.3 页均停留时长（新卡）

| 项   | 要求                                                                          |
| ---- | ----------------------------------------------------------------------------- |
| id   | `chart-screen-dwell`                                                          |
| 标题 | 页均停留时长                                                                  |
| 数据 | `GET /api/admin/track/dims?metric=screen_dwell_avg&limit=100`                 |
| 口径 | 上游 AVG(`duration_ms`)，仅 leave 样本；`metric_value` 单位 ms（整数）        |
| 展示 | 横向柱；类目 §4.1；数值 `metric_value/1000`，一位小数；tooltip「平均停留 Xs」 |
| 排序 | 按平均停留降序（上游已排则保持）                                              |
| 空态 | 无样本 →「暂无数据」                                                          |
| 加载 | 与其它 Track 卡同组；失败同「埋点指标暂不可用」                               |

### 4.4 布局

- `WIDGET_IDS` / `DEFAULT_LAYOUTS` 增加 `chart-screen-dwell`。
- 建议 lg：紧挨「页面使用次数」下方或并排（学院行之后）；md/xs 堆叠。
- 缺 id 的旧 prefs：**补默认几何**，不丢其它卡布局。

### 4.5 数据加载

进入大屏 / 刷新时，Track 并行请求在原有基础上增加 `screen_dwell_avg`；`screen_views` / `screen_dwell_avg` / perf 的 `limit` 均为 **100**。

---

## 5. 业务流程

```text
进入 /dashboard
  → 并行拉 screen_views + screen_dwell_avg（limit=100）等
  → 类目经 rnRouteLabels 格式化
  → 停留图将 ms → 秒(1 位) 绘制
```

## 6. 验收标准与测试

### 6.1 UI

- [ ] 「页面使用次数」可见 `首页 (/home)` 类文案，而非纯 `/home`。
- [ ] 故意制造未知 path（或 mock）时轴为 `/unknown（未映射）`。
- [ ] 新卡「页均停留时长」出现在网格；可拖拽；刷新后布局可保留。
- [ ] 停留柱 tooltip 为「平均停留 Xs」形态；轴为秒级可读数。

### 6.2 功能

- [ ] 仅有 enter、无 leave 的页：可出现在使用次数，不出现在停留图（或停留无该页）。
- [ ] Track 不可用时：使用次数 + 停留 + DAU/性能/崩溃同组不可用提示；本库卡正常。
- [ ] 页面数少于 100 时两图展示全部有数据页面。

### 6.3 回归

- [ ] 其它大屏卡、布局持久化、恢复默认布局仍可用。
- [ ] `pnpm lint` / `type-check` / `format` 通过。
