---

## 1. 背景

校区信息当前仍出现在数据大屏「校区分布」、用户列表列、用户详情抽屉，以及助手问数话术中。产品决定校区数据**可继续获取，但管理端暂不展示**。同时窄屏（&lt; lg / 992px）壳层、大屏网格、用户表体验差，需要在不改信息架构的前提下做到「好用」。

---

## 2. 目标

1. 去掉管理端所有面向用户的校区展示与默认「校区分布」图表；文档明确「campus 先获取、暂不展示」。
2. `&lt;992px`：壳层触控可用；数据大屏单列可读且禁用拖拽/缩放；用户列表改为卡片；抽屉全宽、Modal 留边。
3. 助手系统提示与空态建议不再引导「校区分布」；工具仍保留 `dim=campus` 能力（不删 enum）。
4. 不改 Node/RN；不写独立 tech。

---

## 3. 边界（非目标）

- 删除后端字段、停止请求 `user-distribution` 中的 campus 数据、改 TypeScript 业务类型去掉 `campus`（类型可保留以匹配响应）。
- 从 `admin_user_distribution` 的 `dim` enum 移除 `campus`。
- 内容管理及其它未列页面的移动端重做。
- 改侧栏菜单项、路由、助手 Tabs 结构。
- 独立技术方案文档。

---

## 4. 详细需求

### 4.1 校区：暂不展示

| 位置                        | 行为                                                                         |
| --------------------------- | ---------------------------------------------------------------------------- |
| 数据大屏 `chart-campus`     | 从 `WIDGET_IDS`、默认布局、渲染分支移除；不再出现「校区分布」卡片            |
| 用户列表列                  | 去掉「校区」列                                                               |
| 用户详情抽屉档案区          | 去掉「校区」项                                                               |
| 助手系统提示 / 空态建议文案 | 不再把「校区」作为推荐问数维度；可保留性别/学院/年级等                       |
| API / 类型 `campus`         | **保留**；后端仍可返回；前端不渲染                                           |
| 工具 `dim=campus`           | **保留**；用户若显式追问仍可调用；图表卡片若绘 campus 数据允许（非默认引导） |

**文档口径（契约说明）**：校区字段与分布数据「先获取、暂不展示」——本 Spec 与同步修订的 `数据大屏.md` / `用户管理.md` / `智慧助手一期.md` 必须写明此条。

### 4.2 大屏布局（去校区后）

- 默认布局：原「性别 / 校区 / 年级 / 设备」一行改为 **性别 / 年级 / 设备** 三卡均分（lg 各约 `4×4`；md/xs 按断点重排，无 campus）。
- 读 localStorage：若 layouts 含 `chart-campus`，**过滤丢弃**该 id 后 compact；缺其它合法卡仍按现规则用默认几何补上。
- 「恢复默认布局」应用新的无 campus 默认布局。
- 布局 version 可仍为 `v1`（过滤未知/废弃 id 已足够）；不必强制 bump key，除非实现中发现与旧几何冲突需强制重置——若 bump，须在实施计划注明并迁移或丢弃旧 layouts。

### 4.3 窄屏数据大屏（&lt; lg 或网格 xs，与实现断点对齐）

- **禁用**拖拽改序与缩放；仅纵向滚动浏览。
- 卡片默认单列拉满（沿用 xs 4 列且 `w` 满宽）。
- 图表随容器宽度自适应，不得撑破卡片；崩溃表列可横向滚动但卡本身不溢出视口。
- 刷新 / 恢复默认 / 增长 range 控件触控热区 ≥44px。

### 4.4 窄屏用户管理（&lt;992px）

- **桌面（≥992）**：保持现有 Table（无校区列）。
- **窄屏**：卡片列表，每卡至少展示：姓名、学号、角色 Tag、状态 Tag；点击卡片打开详情抽屉（与点行等价）。
- 筛选与分页在窄屏仍可用：筛选项可纵向堆叠或折叠，不挤成不可点的单行。
- 详情抽屉：全宽（现有 `useDrawerWidth`）；档案区无校区。

### 4.5 壳层与抽屉/Modal（&lt;992px）

- 不改菜单结构与路由。
- 左栏：汉堡 + 遮罩抽屉；打开后点菜单项导航并关闭；遮罩可关；避免与主内容滚动手势死锁。
- 顶栏：标题可读、操作按钮不挤爆；智慧助手入口可点。
- 助手：窄屏全宽（已有行为优先）；打开时不导致主内容横向溢出。
- 全局 Modal：窄屏 `calc(100vw - 32px)` 或等价留边（沿用/统一 `useModalWidth`）。
- 安全区：尊重 `viewport-fit` / safe-area（若壳层已有则保持，缺失则补内容区内边距底栏不被 Home Indicator 遮挡）。

### 4.6 视觉

- 遵循 `design-system/web-admin/MASTER.md`（品牌绿、圆角、轻阴影）。
- 窄屏用户卡：白底、轻边框/阴影，非装饰性 Bento 堆砌；一卡一事。

---

## 5. 业务流程

```text
进入数据大屏
  → 读 prefs → 过滤 chart-campus → 渲染无校区网格
  → 窄屏：isDraggable/isResizable = false

进入用户管理
  → ≥992：Table（无校区列）
  → <992：卡片列表 → 点卡 → 抽屉（无校区项）

助手
  → 系统提示不引导校区
  → 用户显式问校区分布时仍可走 admin_user_distribution(dim=campus)
```

## 6. 验收标准与测试

### 6.1 校区隐藏

- [ ] `/dashboard` 无「校区分布」卡片；恢复默认后也不出现。
- [ ] 旧 localStorage 含 `chart-campus` 时打开大屏不报错，该卡消失。
- [ ] `/users` 列表与详情无「校区」文案/字段。
- [ ] 助手默认建议/系统提示不出现「校区」引导；类型与接口响应仍可含 `campus`。

### 6.2 窄屏壳层（&lt;992）

- [ ] 汉堡打开侧栏抽屉，点菜单可跳转并关闭；遮罩可关。
- [ ] 主内容无横向整页滚动条（个别表内部滚动除外）。
- [ ] Modal 左右留边；抽屉全宽可用。

### 6.3 窄屏大屏

- [ ] 卡片单列纵向可扫完；无法拖拽改序/缩放。
- [ ] KPI 与图表数字可读，不裁切标题条按钮。

### 6.4 窄屏用户

- [ ] 卡片展示姓名/学号/角色/状态；点开抽屉可改角色状态（权限规则不变）。
- [ ] 筛选+分页可用。

### 6.5 工程

- [ ] 仅改 `apps/nongyu-web-admin` + 相关文档；`pnpm lint` / `type-check` / `format` 通过。
