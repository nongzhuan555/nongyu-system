---

## 1. 背景

管理端壳与登录已落地。需支持约定超管学号在用户未建档时用环境默认密码登录（bootstrap），以及建档后自助修改农屿管理员密码；Admin JWT 永不过期，刷新页面仍依赖现有 `localStorage` 会话。

---

## 2. 目标

1. 使用超管学号 + 默认密码可登录（后端无 `users` 行时返回 bootstrap 用户）。
2. `GET /me` hydrate 支持 `id:0` / `bootstrap:true`，不因缺真实用户掉登录。
3. 提供「修改密码」入口：仅非 bootstrap 会话可提交；成功 Toast 提示。
4. 不把默认密码或明文密码写入仓库与 `localStorage`。

---

## 3. 边界

| 非目标                  | 说明                                |
| ----------------------- | ----------------------------------- |
| 登录页预填默认密码      | 禁止                                |
| 无库改密 UI 可用        | 后端 403；前端禁用或提示先 App 建档 |
| 改密后强制重新登录      | 不需要（旧票仍有效）                |
| 用户管理里改他人密码 UI | 可用现接口，本刀不做页面            |
| 视觉大改版              | 沿用 MASTER / 现壳                  |

---

## 4. 详细需求

### 4.1 登录与 hydrate

- 继续 `POST /api/admin/auth/login`；类型 `AdminUser` 扩展可选 `bootstrap?: boolean`。
- hydrate：`GET /api/admin/auth/me` 成功即维持登录；`bootstrap===true` 时工作台可进，侧栏点到需真实数据的占位/业务页时，若接口 403，展示后端建档提示（或统一空态说明）。
- 登录失败文案：沿用现映射；超管密码错误仍为管理员密码错误类提示。

### 4.2 修改密码

- 入口：壳顶栏用户区或设置入口（实现选一处明显位置），文案「修改密码」。
- 仅当 `!user.bootstrap` 时可点；bootstrap 时按钮禁用，Tooltip/说明：「请先在农屿 App 使用该学号登录完成建档」。
- 表单：新密码、确认密码；≥8 位；一致才提交。
- 调用 `PUT /api/admin/auth/password`，Body `{ adminPassword }`。
- 成功：Toast「密码已更新」；提醒「出厂默认密码仍可登录」（一句次要说明即可）。
- 失败：展示接口 message。

### 4.3 安全

- 不在前端代码、`.env.example` 写入真实默认密码。
- 记住学号功能可记住超管学号，**不**记住密码。

---

## 5. 验收

- [ ] 超管学号 + 正确默认密码，库无用户：登录成功进入工作台；`/me` 显示超级管理员。
- [ ] bootstrap 下修改密码入口不可用或提交被拒并提示建档。
- [ ] App 建档该学号后重新登录：可改密；新密码与默认密码均可再次登录。
- [ ] 刷新浏览器：Admin 会话仍在（永不过期票 + 本地存储）。
- [ ] 普通管理员（非超管）行为与现网一致；改密改的是自己的哈希。
