## 1. 背景

**Why**：管理端视觉 token 已落地，但壳层顶栏与 PageFrame 重复喊页名，筛选挤进标题行，相关网站白底套白底，工作台入口少于侧栏，管理员扫读与操作路径变长。  
**What**：在不改路由、接口、侧栏分组、助手对话内部的前提下，把「我在哪 / 能筛什么 / 能做什么」拆到固定层级，并补齐工作台入口。

**页面单一职责（全站）**：壳层负责导航与账号；页面负责本模块标题、主操作与数据。

---

## 2. 目标

1. 顶栏不再显示当前路由页名；统一显示产品名「农屿管理台」。各业务页页名只出现在 `PageFrame` 标题（22–24px / 600）。工作台无 PageFrame，欢迎区大标题承担页名。
2. `PageFrame.actions` 只放主操作（新建、刷新等）。搜索与筛选放在内容区顶部工具栏，用户 / 问候 / AI 建议 / 内容列表 / LLM Key 池结构一致。
3. 内容管理去掉列表内重复 `h2`（Tab 已标明当前列表）。
4. 相关网站去掉卡片套卡片；官网预览用 `bare` 页框落在画布上。
5. 工作台模块卡补齐「LLM Key 池」「相关网站」；去掉英文 eyebrow「Workspace」。
6. 修正埋点采样率条无效边框 token；KPI 标题去掉无意义 uppercase。
7. 同步 `MASTER.md` 与 `登录与管理端壳.md` 顶栏口径。不写独立 tech。

---

## 3. 边界（非目标）

- 侧栏菜单分组、增减菜单项、改路由 path、改后端接口与数据模型。
- 智慧助手面板内部：对话 / 会话 / 设置、消息气泡、输入条、工具卡片。
- 数据大屏拖拽网格、默认 layouts、用户窄屏卡片列表方案（已有 Spec，只动页头/工具栏层级）。
- 登录协议、handoff、鉴权、前台 60s 刷新。
- 换主色、换字体、取消侧栏选中绿条签名。
- 独立技术方案文档。

## 5. 设计计划（frontend-design × MASTER）

色板、字体、圆角、阴影、侧栏签名**沿用 MASTER**，本切片不另起视觉系统。自由度用在信息结构，不浪费在换肤。

| 轴        | 选择                                                                                           |
| --------- | ---------------------------------------------------------------------------------------------- |
| Color     | `#0A7C59` / `#D4E9DF` / `#FAFBFA` / `#FFFFFF` / `#1F2937` / `#424945` / `#CFE3DA`              |
| Type      | UI：Source Sans 3 + 苹方/雅黑。页标题仅 PageFrame 22–24px/600；正文 14；辅助 12–13 muted       |
| Layout    | 贴边侧栏 + sticky 顶栏 chrome；CRUD = PageFrame 标题行 + 白底内容 + 内工具栏；工作台轻量 Bento |
| Signature | 侧栏选中浅绿底 + 左侧品牌绿竖条；工作台欢迎卡左侧同宽绿条                                      |

**不用**：奶油底+衬线、黑底酸绿、报纸细线栏。这些与学院派科技感无关。

## 6. 详细需求

### 6.1 顶栏（`AdminShell`）

- 左侧文案（汉堡右侧，≥lg 无汉堡）：**「农屿管理台」**，`15px / 600`，截断。不是当前路由名。
- 右侧：智慧助手按钮、用户菜单。不新增折叠按钮（仍由侧栏内折叠）。
- 去掉 `PAGE_TITLES[pathname]` 作为顶栏标题的用法。`PAGE_TITLES` 若仅服务顶栏则可删；菜单 `selectedKeys` 仍按 `location.pathname`。
- 窄屏：汉堡 + 「农屿管理台」；页名在下方 PageFrame，不回到顶栏。
- 404：顶栏仍为「农屿管理台」；页内保留「页面不存在」。

**修订** `登录与管理端壳.md` §4.4：原「顶栏：当前页名称」改为「顶栏：产品名农屿管理台；页名在 PageFrame」。

**修订** `MASTER.md` Layout：写明「顶栏不重复页标题；页标题仅 PageFrame（22–24px）」。

### 6.2 PageFrame

- 标题：`text-[22px] sm:text-[24px] font-semibold leading-8 tracking-tight`（对齐 MASTER 22–24px / 600）。
- `actions`：**仅主操作**（`Button` 主/次）。禁止把 `Input` / `Select` 筛选项放进 `actions`。
- 新增可选 `toolbar`：渲染在白底内容区**内部顶部**（`bare` 时渲染在 children 之前），与标题行分离。
  - 工具栏：左筛选/搜索、右可空；`flex-wrap`；窄屏纵向拉满宽。
  - 触控：控件高度仍遵循现有 `pointer: coarse` ≥44px。
- 白底内容区：`rounded-xl` 或 `rounded-2xl`（12–16px）、`border-line-soft`、`shadow-panel`、`p-3 sm:p-4 md:p-5`。保持 `max-w-[1400px]`（大屏页可继续覆盖 `max-w-[1600px]`）。
- `bare`：无白底外壳（大屏、相关网站预览区所在页）。

### 6.3 各页对照

| 页面       | 标题行 actions              | toolbar                        | 其它                                                                           |
| ---------- | --------------------------- | ------------------------------ | ------------------------------------------------------------------------------ |
| 工作台     | 无 PageFrame                | 无                             | 见 6.4                                                                         |
| 数据大屏   | 刷新、恢复默认布局          | 无（range 仍在增长图卡片内）   | `TrackSampleRateBar` 边框改 `border-line-soft`；KPI 标题取消 uppercase         |
| 用户管理   | 无（无新建）                | 搜索 + 角色/状态/在线/今日活跃 | 桌面表 / 窄屏卡逻辑不变                                                        |
| 内容管理   | 无                          | 各 Tab 列表内：搜索等          | 去掉 `PostListPanel` 内层「官方公告/用户反馈/用户建议」`h2`；Tab 即名称        |
| 首页问候   | 新建问候语                  | 状态筛选 + 刷新                | 表格不变                                                                       |
| AI 建议    | 新建建议                    | 状态筛选 + 刷新                | 表格不变                                                                       |
| LLM Key 池 | 添加密钥（仅密钥 Tab 需要） | 状态筛选 + 刷新（密钥 Tab 内） | 失败记录 Tab 无这套工具栏；主操作随 Tab 显示或始终「添加密钥」只作用于密钥 Tab |
| 相关网站   | 无                          | 无                             | 见 6.5                                                                         |
| 登录       | —                           | —                              | 信息结构与文案不变；不改协议                                                   |
| 404        | —                           | —                              | 保持页内标题，不进顶栏                                                         |

**LLM Key 池主操作**：密钥 Tab 显示「添加密钥」；切到失败记录时隐藏该按钮（避免在失败 Tab 点出密钥表单）。筛选只出现在密钥 Tab 工具栏。

### 6.4 工作台

- 欢迎卡：去掉 `Workspace` 英文 eyebrow；可用中文「工作台」或直接从「你好，{name}」起。左侧品牌绿条保留。
- 模块卡必须覆盖侧栏除「工作台」外的全部入口，顺序与侧栏一致：

  数据大屏、用户管理、内容管理、首页问候、AI 建议、LLM Key 池、相关网站。

- 卡文案：标题 = 菜单名；一句说明，不写实现细节。
- 网格：`1 / sm:2 / lg:3` 列；轻 hover 位移可保留；触控有 `active` 态。

### 6.5 相关网站

- 使用 `PageFrame bare`：标题+说明在画布上，下面直接铺链接卡与手机预览，**不再套一层** `shadow-panel` 白底。
- 快捷跳转卡：单层白卡 `rounded-2xl border-line-soft shadow-panel`，落在 `bg-canvas` 上。
- 手机预览：外框直接落在画布；「新窗口打开」留在预览标题行。外链行为、iframe URL、失败兜底不变。

**修订** `相关网站.md`：页框改为 bare，禁止外层再套 PageFrame 默认白底。

### 6.6 内容管理标题层级

- 顶栏：农屿管理台（全站规则）。
- PageFrame：`内容管理` + 现有 description。
- Tabs：公告 / 反馈 / 建议。
- `PostListPanel` **不再渲染** `title` 作为可见标题（prop 可删或仅作 a11y，界面不出现第四层标题）。
- 「发布公告」留在公告 Tab 工具栏（与搜索同一行）。

### 6.7 数据大屏小修

- `TrackSampleRateBar`：`border-line-soft bg-surface`，禁止不存在的 `border-border`。
- `KpiCard` 标题：13px / 600 / `text-muted`，**不要** `uppercase` + 宽 tracking（中文指标名不是拉丁标签）。
- 网格、拖拽、断点、采样率功能不变。

### 6.8 登录页

- 保持现有文案、字段、handoff。
- 不改布局骨架；若存在与 MASTER 冲突的装饰本刀可微调，但**不以换肤为目的**改登录页。

---

## 7. 业务流程

无新业务流。管理员打开任一业务页：顶栏识别产品，PageFrame 识别模块，工具栏筛选，主按钮做事。

## 8. 验收标准

| 项       | 标准                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 顶栏     | 任意业务路由顶栏文案均为「农屿管理台」，不出现「用户管理」等页名        |
| 页名     | CRUD 页 PageFrame 标题 22–24px；与顶栏不重复                            |
| 筛选     | 用户管理标题行无 Select/Input；五项筛选在白底卡片顶部；窄屏可点、可换行 |
| 问候/AI  | 「新建」在标题行；状态筛选与刷新在内容区工具栏                          |
| 内容     | 公告 Tab 内看不到「官方公告」标题；仍能搜索、发布                       |
| Key 池   | 密钥 Tab 有筛选+添加；失败记录 Tab 无「添加密钥」                       |
| 工作台   | 7 张模块卡，含 Key 池与相关网站；无 Workspace 英文 eyebrow              |
| 相关网站 | 页面背景为 canvas，链接卡只有一层白底；预览不套在 PageFrame 默认白卡内  |
| 采样率   | 条有可见 `line-soft` 边框                                               |
| 助手     | 开/关、拖宽、对话交互与改前一致                                         |
| 回归     | 登录、鉴权、各页列表/抽屉/大屏拖拽（≥lg）仍可用                         |
| 文档     | MASTER、登录壳、相关网站 Spec 已同步顶栏/页框口径                       |

### 测试方案

1. 桌面 ≥992：走一遍侧栏每一页，目视顶栏与 PageFrame，点主按钮与筛选。
2. 窄屏 &lt;992：汉堡、顶栏产品名、PageFrame 标题、筛选纵向堆叠、用户卡片列表。
3. 工作台 7 卡均可进入对应路由。
4. 相关网站外链仍 `target=_blank`；iframe 行为不回归。
5. 打开智慧助手发一条建议问数，确认未改对话壳。
6. `pnpm lint` / `pnpm type-check` / `pnpm format` 通过（工作区对 web-admin 的检查方式与现仓库脚本一致）。

## 9. 实现备注（非契约，供计划引用）

- 颜色只走已有 Tailwind `brand` / `canvas` / `surface` / `ink` / `muted` / `line` / `line-soft`。
