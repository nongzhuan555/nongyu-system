| 项       | 内容                                                                      |

---

## 1. 背景

农屿 Web 管理端目前只是 Vite + React 脚手架占位页，无法登录、无鉴权、无布局壳。学生管理员需要用**教务网学号 + 农屿管理员密码**进入后台；后续用户管理、数据大屏、智慧助手都依赖本切片提供的登录态、路由守卫与响应式壳。

本需求解决的是「谁能进、进了之后站在哪」，不解决进了之后管什么。

---

## 2. 目标

1. 未登录用户只能看到登录页；登录成功进入管理端壳。
2. 对接现有 `POST /api/admin/auth/login`、`GET /api/admin/auth/me`、`POST /api/admin/auth/logout`，不另起鉴权协议。
3. 登录态写入带版本前缀的 `localStorage`，刷新不掉登录；多端不踢号（与后端 Admin JWT 策略一致）。
4. 提供 PC 侧栏 + 顶栏、平板/手机抽屉的响应式壳；落地 Ant Design Token（主色、圆角）与 MASTER 色板。
5. 预埋后续业务路由为可进入的占位页；预留 `loginType` 与自动填入注入口，本刀不接 RN WebView 通信。

---

## 3. 边界（非目标）

- 不实现数据大屏、用户管理、官方发帖、反馈/建议、智慧助手的真实业务与接口。
- 不实现 RN App ↔ WebView 的 `postMessage` 自动登录协议；不在本刀自动提交登录。
- 不改 Node 鉴权、JWT TTL、错误码；不新增管理端登录日志。
- 不存储教务网密码；不把管理员密码写入 `localStorage`（仅会话 Token 与公开用户字段）。
- 不在本刀编写独立技术方案文档；Spec 审查通过后由用户决定是否补 `docs/nongyu-web-admin/tech/`。
- 不做验证码、SSO、找回密码、修改管理员密码、注册。
- 不把智慧助手入口放进导航（PRD：默认隐藏，用户主动开启；后续切片再做）。

## 4. 详细需求

### 4.1 信息架构与路由

| 路由         | 名称     | 鉴权   | 本刀内容                    |
| ------------ | -------- | ------ | --------------------------- |
| `/login`     | 登录     | 公开   | 真实登录表单                |
| `/workspace` | 工作台   | 需登录 | 空态欢迎（默认落地）        |
| `/dashboard` | 数据大屏 | 需登录 | 占位页                      |
| `/users`     | 用户管理 | 需登录 | 占位页                      |
| `/`          | —        | —      | 重定向到 `/workspace`       |
| 其它未知路径 | —        | 需登录 | 壳内 404 空态，提供回工作台 |

- 侧栏/抽屉菜单顺序：**工作台 → 数据大屏 → 用户管理**。
- 已登录访问 `/login` → 重定向 `/workspace`。
- 未登录访问任何需登录路由 → 重定向 `/login`，并记住原目标；登录成功后回到该目标，若无则 `/workspace`。
- 占位页：页标题 + 一句说明 +「即将开放」，不请求业务接口。

### 4.2 登录页

**页面单一职责**：确认来者是农屿管理员，然后进入管理台。

**文案**

| 位置     | 文案                                           |
| -------- | ---------------------------------------------- |
| 产品名   | 农屿管理台                                     |
| 副文案   | 使用教务网学号与农屿管理员密码进入             |
| 学号标签 | 教务网学号                                     |
| 密码标签 | 农屿管理员密码                                 |
| 学号占位 | 9 位学号                                       |
| 密码占位 | 不是教务网密码                                 |
| 主按钮   | 进入管理台                                     |
| 提交中   | 正在验证管理员身份…                            |
| 底部提示 | 管理员密码仅用于本后台，与教务网密码不是同一套 |

**字段与校验**

- 学号：必填；提交前须为 **9 位数字**；非法时表单项错误「请输入 9 位学号」，不发请求。
- 密码：必填；可显隐；空密码不发请求。
- 记住学号：默认勾选；成功后把学号写入 `localStorage`；下次打开登录页回填学号、不回填密码。取消勾选则清除已记学号。
- 主按钮在校验未通过或请求进行中时不可重复提交。

**`loginType` 与注入口（预留）**

- 请求始终带 `loginType`：缺省 `"browser"`。
- 若 URL 查询参数 `loginType=in_app`，则发 `"in_app"`；其它值忽略，仍用 `"browser"`。
- 注入口（本刀只读、不接 RN）：页面加载时若存在

  `window.__NONGYU_ADMIN_PREFILL__ = { studentNo?: string; adminPassword?: string }`

  则把已给字段填入表单。本刀**不自动点击登录**。该全局对象仅作未来 WebView 填入约定，不写入仓库业务逻辑之外的文档即可（实现时加中文注释说明来源）。

**登录失败提示（展示在表单上方，不弹模态）**

| 后端情况                                               | 界面文案                     |
| ------------------------------------------------------ | ---------------------------- |
| `40303` 密码错 / `40401` 用户不存在 / `40302` 非管理员 | 学号或密码错误               |
| `40301` 账号已禁用                                     | 账号已禁用                   |
| `40001` 且 message 含「过于频繁」                      | 登录尝试过于频繁，请稍后再试 |
| `40001` 其它（如学号格式）                             | 请输入 9 位学号              |
| 网络失败                                               | 网络异常，请稍后重试         |
| `50000` 或其它未知                                     | 服务异常，请稍后重试         |

成功：保存会话 → 跳转目标路由。

### 4.3 会话与鉴权

**存储（`localStorage`，须 `try/catch`）**

| Key                                   | 内容                                             |
| ------------------------------------- | ------------------------------------------------ |
| `nongyu-admin:v1:session`             | `{ token, user: { id, studentNo, name, role } }` |
| `nongyu-admin:v1:rememberedStudentNo` | 学号字符串或删除该项                             |

禁止存密码。`role` 必须为 `1` 才视为有效会话。

**启动**

1. 读 `session`；无 Token → 未登录。
2. 有 Token → 请求 `GET /api/admin/auth/me`（`Authorization: Bearer <token>`）。
3. 成功 → 用返回用户覆盖本地 `user`，进入壳。
4. 失败（含 401 / 403）→ 清除 `session`，视为未登录。启动校验期间壳内显示简短加载，不闪登录页再跳入。

**运行中**

- 所有 `/api/admin/*` 请求带 Admin JWT。
- 任一请求返回 `40101` / `40102`：清会话、跳 `/login`。
- 登出：调用 `POST /api/admin/auth/logout`（失败也清本地）；清 `session`（不自动清记住的学号）；跳 `/login`。
- 多端同时登录允许；本端不因其它端登录而主动失效。

### 4.4 壳层布局

**PC（≥992px，Ant Design `lg`）**

```
+------------------+----------------------------------+
| 农屿管理台        | 当前页标题          姓名  登出   |
|                  +----------------------------------+
|  工作台           |                                  |
|  数据大屏         |         内容区（Bento 空态）      |
|  用户管理         |                                  |
+------------------+----------------------------------+
```

- 左侧栏悬浮感：大圆角、浅描边、轻阴影；选中项用主色浅底 + 主色文字，不用纯黑实心块。
- 顶栏：当前页名称；右侧显示 `user.name`，下挂「登出」。
- 内容区背景 `#F8FAFC`，内边距 `p-4 md:p-6`。

**平板 / 手机（&lt;992px）**

- 无常驻侧栏；顶栏左侧汉堡（触摸热区 ≥ 44×44px）打开抽屉菜单，条目与 PC 侧栏一致。
- 禁止仅 hover 才能完成的操作。

**工作台空态**

- 欢迎语：「你好，{name}」。
- 副文案：「管理台壳层已就绪，业务模块即将开放。」
- 2～3 张 Bento 占位卡片（数据大屏 / 用户管理），可点击进入对应占位路由；卡片不可堆砌成仪表盘假数据。

**数据大屏 / 用户管理占位页**

- 标题与一句话（例如「数据大屏即将开放」），无图表、无表格、无请求。

### 4.5 视觉与 Token

严格使用 MASTER，不另起色板：

| Token          | 值        | 用途                                   |
| -------------- | --------- | -------------------------------------- |
| Primary        | `#10B981` | 主按钮、选中态                         |
| Secondary      | `#FBBF24` | 登录卡顶沿高光（细条，不做大面积黄底） |
| Background     | `#F8FAFC` | 页面底                                 |
| Card           | `#FFFFFF` | 登录卡、Bento                          |
| Text Primary   | `#1E293B` | 标题                                   |
| Text Secondary | `#64748B` | 说明                                   |

- Ant Design `ConfigProvider`：`colorPrimary: #10B981`，`borderRadius: 16`。
- 登录卡与壳卡片：圆角 16～24px（`rounded-2xl` / `rounded-3xl`），柔和阴影。
- 登录页签名：一张「准入卡」——白底大圆角卡片，顶沿一条 3px 琥珀高光，表示值班台准入，而不是通用居中 AntD 登录框。
- 字体：系统无衬线 / Inter；标题字重 ≥ 600。
- 尊重 `prefers-reduced-motion`：加载态可用，不强动画。
- `index.html`：`lang="zh-CN"`；标题「农屿管理台」；保留正确 `viewport`。

### 4.6 后端对接（WHAT，不规定目录结构）

| 方法 | 路径                     | 本刀用途 |
| ---- | ------------------------ | -------- |
| POST | `/api/admin/auth/login`  | 登录     |
| GET  | `/api/admin/auth/me`     | 启动校验 |
| POST | `/api/admin/auth/logout` | 登出     |

登录请求体：`{ studentNo, adminPassword, loginType }`。  
成功 `data`：`{ token, loginType, user: { id, studentNo, name, role: 1 } }`。  
统一响应包：`{ code, message, data }`；`code === 0` 为成功。  
HTTP 状态与业务 `code` 以接口文档为准，前端以 `code` + HTTP 共同判断。

## 5. 业务流程

### 5.1 浏览器登录

```
打开管理端
  → 有 session？
       否 → /login（可回填记住的学号）
       是 → GET /me
              失败 → 清 session → /login
              成功 → 进入壳（默认 /workspace）
填写学号、管理员密码 → 客户端校验
  不通过 → 表单项错误，不请求
  通过 → POST /login（loginType=browser 或 URL 指定 in_app）
           失败 → 按 §4.2 文案展示
           成功 → 写 session →（可选写记住学号）→ 目标路由
```

### 5.2 登出

```
点击登出 → POST /logout（忽略失败）→ 清 session → /login
```

### 5.3 运行中 401

```
任意管理端 API 401 → 清 session → /login（可带原目标）
```

## 6. 验收标准与测试方案

### 6.1 登录页 UI（理想描述）

- 浅石板底，中央（或偏上）一张大圆角白卡片；顶沿一条细琥珀线；产品名「农屿管理台」；副文案明确密码不是教务网密码。
- 两个输入 + 密码显隐 + 「记住学号」+ 主色胶囊按钮「进入管理台」。
- 手机宽度下卡片仍完整可见，不出现横向滚动；按钮与输入高度适合手指。
- 不是 Ant Design Pro 默认登录模板，也不是深色霓虹控制台。

### 6.2 功能操作

- [ ] 错误学号/密码：提示「学号或密码错误」，停在登录页。
- [ ] 非 9 位学号：不发请求，提示「请输入 9 位学号」。
- [ ] 正确管理员账号：进入工作台，顶栏显示姓名。
- [ ] 刷新工作台：仍为登录态（Token 未过期时）。
- [ ] 直接访问 `/dashboard`、`/users`：未登录先登录，成功后落到原路径的占位页。
- [ ] 已登录打开 `/login`：进入工作台。
- [ ] 登出后回到登录页；再访问 `/workspace` 被拦回登录。
- [ ] 「记住学号」勾选时，登出后再打开登录页学号仍在、密码为空。
- [ ] 侧栏三项可切换；大屏/用户管理为占位文案，网络面板无对应业务请求。
- [ ] 窄屏：汉堡打开抽屉，可切换路由；触摸目标足够。
- [ ] `?loginType=in_app` 登录时请求体为 `in_app`；无该参数时为 `browser`。
- [ ] 启动时若本地 Token 已失效：不进入壳，停留登录页。

### 6.3 非功能

- [ ] 主题主色为翠绿、卡片大圆角，与 MASTER 一致。
- [ ] 密码与 Token 不出现在 URL、控制台主动 `console.log`、或除 session key 外的存储。
- [ ] `pnpm lint` / `pnpm type-check` / `pnpm format` 在本应用改动后可通过。
