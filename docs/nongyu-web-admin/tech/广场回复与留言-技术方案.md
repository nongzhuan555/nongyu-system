## 1. 技术选型

沿用既有栈，不引入新依赖：

- React + Antd + Tailwind
- axios `adminApi`（无 React Query，手动 `useEffect` + `loadList`）
- 既有 `AdminApiError` / `unwrapData` / `Modal.confirm` / `message`

## 3. 关键设计

### 3.1 详情数据拉取

`PostDetailDrawer` 当前接收 `post: AdminPostItem`（来自列表）。回复/留言数据需详情接口提供：

- 方案：`PostListPanel` 行点击时调 `getAdminPostDetail(id)`（新增详情 API 或复用既有 `GET /api/admin/posts/:id`）拉取含 `adminReply` / `comments` 的完整数据，再传给 Drawer。
- 或：列表项已含 `replyCount`，Drawer 打开时单独拉 `adminReply` / `comments`。

采用：Drawer 打开时调 `getAdminPostDetail(id)` 拉完整详情（含回复），存组件 state，关闭即清。

### 3.2 管理员回复编辑 Modal

`AdminReplyEditModal`（Antd `Modal` + `Form` + `Input.TextArea`）：

```tsx
<Modal
  title="管理员回复"
  open={open}
  onCancel={onCancel}
  onOk={handleSubmit}
  okText="保存"
  confirmLoading={submitting}
  destroyOnClose
>
  <Form form={form} layout="vertical" requiredMark={false}>
    <Form.Item
      name="content"
      rules={[
        { required: true, message: "请输入回复" },
        { max: 2000, message: "不超过2000字" },
      ]}
    >
      <Input.TextArea rows={6} maxLength={2000} showCount placeholder="请输入回复内容" />
    </Form.Item>
  </Form>
</Modal>
```

- 创建态：调 `createAdminPostReply(postId, {content})`，遇 409 → `message.warning("该帖已有回复，已刷新")` → 父组件刷新详情 → 切编辑态。
- 编辑态：调 `patchAdminPostReply(postId, {content})`，遇 404 → `message.warning("回复不存在，已刷新")` → 父刷新。
- 成功：`message.success` → `onSaved()` → 父刷新详情。

### 3.3 AdminReplyPanel（反馈墙详情区块）

```tsx
// post.adminReply 非空：展示内容 + 时间 + 作者实名 + [编辑][删除]
// post.adminReply 为空：展示「暂无回复」+ [添加回复]
```

- 删除：`Modal.confirm` → `deleteAdminPostReply(postId)` → 刷新详情。
- 作者实名展示：`{authorName}（{authorStudentNo}）`。
- **不展示** `updatedAt` / 修改人（无操作留痕）。

### 3.4 AdminCommentList（大院详情区块）

```tsx
// 标题「留言 · N」+ 列表（内容 + 时间 + 作者实名 + [删除]）
// 空态：「暂无留言」
```

- 单条删除：`Modal.confirm` → `deleteAdminPostComment(postId, commentId)` → 刷新详情。
- 排序：服务端 `created_at ASC`。

### 3.5 列表回复列（可选）

`PostListPanel` 的 `Table` 新增 `replyCount` 列：

- feedback：`replyCount > 0` → `<Tag color="success">已回复</Tag>`；否则 `<Tag>未回复</Tag>`。
- courtyard：展示「N 条留言」文字。
- announcement：展示「—」。

## 5. 注意事项

- **无 React Query**：手动 `loadList` / 详情 state，注意 loading / error 态完整。
- **409/404 处理**：业务码错误转可读 message，并刷新详情避免脏状态。
- **已删帖**：`deletedAt` 非空时回复/留言区块不展示操作按钮（只读）。
- **Modal destroyOnClose**：避免脏数据残留。
- **实名展示**：与既有帖子作者展示一致 `authorName（authorStudentNo）`。
- **样式**：Tailwind + 设计 token，对齐既有 Drawer / Tag 风格。
- **表单校验**：Antd Form rules 内联，maxLength 2000 + showCount。
