## 2. 实施步骤

### 2.1 数据大屏

1. `dashboardLayout.ts`：从 `WIDGET_IDS` / `DEFAULT_LAYOUTS` 去掉 `chart-campus`；lg 性别/年级/设备三卡均分。
2. `DashboardGrid.tsx`（及 prefs 读取处）：过滤 `chart-campus`；窄屏关闭拖拽与缩放。
3. 确认无其它入口渲染「校区分布」。

### 2.2 用户管理

1. `UsersPage.tsx`：去校区列；`useIsLg` 分支卡片列表。
2. `UserDetailDrawer.tsx`：去校区 Descriptions 项。

### 2.3 壳层与响应式

1. 复查 `AdminShell.tsx`、`responsive.ts`、PageFrame：窄屏溢出、抽屉关闭、safe-area。
2. 统一业务 Modal 走 `useModalWidth`。

### 2.4 助手

1. `assistant/agent.ts` 等系统提示：去掉「校区」推荐维度表述。
2. `assistant/tools/dashboard.ts`：保留 `campus` enum；description 可不强调校区为常用维。

### 2.5 验收与收尾

按 Spec §6 勾选；工程三件套通过；更新 Spec/本计划状态为已实现。

---

## 3. 注意事项

- 类型字段 `campus` 可保留，避免与 API 响应脱节；UI 层不展示即可。
- 不 bump localStorage key 除非实装时发现必须；优先 filter 废弃 widget id。
- 窄屏「好用」优先于桌面拖拽能力对等。
