## 1. 实施计划

一人交付；前端按现有 Ant Design + Tailwind 壳扩展，对齐 `vercel-react-best-practices`。

| 步骤 | 内容                                                                         | 风险 / 缓解                 |
| ---- | ---------------------------------------------------------------------------- | --------------------------- |
| 1    | posts 类型 + `adminApi` CRUD 封装                                            | 低                          |
| 2    | `/content` 三 Tab 列表（筛选/分页/覆盖率）                                   | 中：Tab 与 URL `?tab=` 同步 |
| 3    | 公告发布/编辑抽屉 + 详情/软删                                                | 低；非公告禁编辑            |
| 4    | 壳层菜单「内容管理」+ 工作台入口卡                                           | 低                          |
| 5    | `assistant/` 契约 + `AssistantPanel` 占位 + 顶栏开关（PC 右抽屉 / 窄屏全屏） | 中：断点与壳层 z-index      |
| 6    | type-check / oxlint / 本包 format；手工验响应式                              | 须已建档 Admin              |

**改动面**：`apps/nongyu-web-admin/**` + Spec/本计划状态。不改 Node、不接真实 Agent。

**不写**：独立 tech；大屏；版本管理；模型密钥。

## 2. 实施步骤

### 2.1 API 与类型

1. `src/types/posts.ts`：`AdminPostItem`、`PostType`、列表 Query、`PageResult` 复用或与 users 共享泛型。
2. `constants.ts`：`ROUTES.content = "/content"`；`ADMIN_POSTS_PATH`。
3. `adminApi.ts`：`listAdminPosts` / `fetchAdminPost` / `createAdminAnnouncement` / `patchAdminAnnouncement` / `deleteAdminPost`。
4. `format.ts`：补充 `formatCoverageRate(rate: number)`（×100，一位小数 + `%`）。

### 2.2 目录

```text
src/pages/ContentPage.tsx
src/components/content/PostListPanel.tsx      # 可按 tab 传 postType
src/components/content/PostDetailDrawer.tsx
src/components/content/AnnouncementFormDrawer.tsx
src/assistant/types.ts                       # AssistantMessage / Adapter / PanelProps
src/assistant/placeholderAdapter.ts
src/assistant/AssistantPanel.tsx
```

禁止 barrel `index.ts` 再导出（沿用项目习惯）。

### 2.3 内容管理页

- `ContentPage`：`Tabs` 三页；`useSearchParams` 读写 `tab=announcement|feedback|suggestion`。
- 每 Tab：`PostListPanel` 固定对应 `postType`（suggestion → `courtyard`）。
- 公告工具栏「发布公告」→ `AnnouncementFormDrawer`（create）。
- 行点击 → `PostDetailDrawer`；公告未删除可「编辑」打开同一表单（edit）。
- 软删确认文案按 Spec；成功刷新列表。
- 表格 `scroll.x`；筛选区 `flex-wrap`。

### 2.4 壳层与导航

- `AdminShell` 菜单增加内容管理（`FileTextOutlined` 或同类）。
- `PAGE_TITLES` / 选中态支持 `/content`。
- `WorkspacePage` 增加「内容管理」Bento 卡。
- `AppRouter` 注册 `/content` → `ContentPage`。

### 2.5 智慧助手预留

- 顶栏入口按钮（≥44px），`open` 局部 state。
- `AssistantPanel`：`Grid.useBreakpoint`——`lg+` 右侧 Drawer ~400px，否则全屏 Drawer。
- 默认 `placeholderAdapter`；输入禁用或发送 Toast「暂未接入」。
- `types.ts` 导出契约，中文注释标明后续可接 `nongyu-agent-sdk`，本刀不安装运行时依赖。

### 2.6 验证

- `pnpm --filter nongyu-web-admin type-check`
- `pnpm exec oxlint apps/nongyu-web-admin`
- `pnpm exec oxfmt apps/nongyu-web-admin docs/nongyu-web-admin --write`（勿全仓 fmt）
- 手工：三 Tab、发公告、编辑、删反馈、助手开关、窄屏布局

### 2.7 文档

- Spec → **已实现**；本计划 → **已完成**

## 3. 注意事项

- bootstrap 会话 403 提示与用户管理一致。
- 列表项已含 `content` 时可先用列表数据填详情，避免多余请求；需要时再 `GET :id`。
- 覆盖率后端为 0–1 小数，勿二次除以 100 再错。
- 助手 z-index 须高于侧栏遮罩，避免被挡。
- 不自动 git commit。
