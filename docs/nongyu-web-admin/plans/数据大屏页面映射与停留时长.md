| 步骤 | 内容                                                            | 风险 / 缓解                                   |

## 2. 实施步骤

### 2.1 Track（Go）

1. `CountByName` 拆出或新增：
   - enter：`screen_view` + `duration_ms IS NULL`
   - dwell avg：`screen_view` + `duration_ms IS NOT NULL` → `ROUND(AVG(duration_ms))` 为 int64
2. `LiveDims`：`screen_views` 走 enter；`case "screen_dwell_avg"` 走平均。
3. `RunAggregate`：`screen_views` 用 enter；`ReplaceDims(..., "screen_dwell_avg", ...)`。
4. `allowedDims` 增加 `screen_dwell_avg`。
5. 单测：enter+leave 计数=1；两 leave 平均；非法 metric 400。

### 2.2 Node（BFF）

1. `dimMetricSchema` 增加 `screen_dwell_avg`。
2. 确认 `limit` 最大 100 已存在，无需改默认。

### 2.3 Web Admin

1. 新增 `src/lib/rnRouteLabels.ts`：精确表 + `/*` 最长前缀；`formatRnRouteLabel(path)`。
2. `dashboardCharts`：dim 柱类目走 `formatRnRouteLabel`；停留图另做秒格式化（或共用 helper）。
3. `fetchTrackDims` 类型联合增加 `screen_dwell_avg`；调用处 `limit: 100`。
4. `DashboardPage` / `DashboardGrid`：增加 `screenDwell` 数据与 `chart-screen-dwell` 卡。
5. `dashboardLayout`：`WIDGET_IDS` + 默认布局（lg：使用次数旁/下并排停留；md/xs 堆叠下移 crashes）。
6. prefs 缺卡补全逻辑沿用现有。

### 2.4 验收自检

对照两份 Spec §6 清单；本机可打 Track dims 与大屏目视。

---

## 3. 注意事项

- `metric_value` 停留为 **ms 整数**；秒转换只在前端。
- 旧 localStorage 布局：新增卡用默认几何插入，勿整表重置用户其它卡位置。
- 部署后历史日 `screen_views` 仍可能双计，直至运维重跑 aggregate；今日 live 立即正确。
- 编码后跑 `pnpm lint` / `type-check` / `format`；Track `go test`。
