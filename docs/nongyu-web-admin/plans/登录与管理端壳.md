## 2. 实施步骤

### 2.1 工程可运行

当前缺口：无 `vite.config`、无 Tailwind/PostCSS 配置、无 `.env.example`。

1. 新增 `vite.config.ts`
   - `@vitejs/plugin-react`
   - 开发代理：`/api` → `http://127.0.0.1:3000`（与联调指南默认端口一致）
   - 不把生产 API 地址写死在源码
2. 新增 `tailwind.config.ts`、`postcss.config.js`；`content` 覆盖 `index.html` 与 `src/**/*.{ts,tsx}`
3. `.env.example`：`VITE_API_BASE_URL=`（开发留空，走代理；直连时再填 Node 根地址，无尾斜杠）
4. `index.html`：`lang="zh-CN"`，标题改为「农屿管理台」，保留 `viewport`
5. `package.json`：脚手架里已有的、catalog 已收录的依赖改为 `"catalog:"`（`vite`、`@vitejs/plugin-react`、`autoprefixer`、`postcss`、`tailwindcss`、`react`、`react-dom`、类型包）；`vite` / 插件放 `devDependencies`
6. 应用 `tsconfig` 覆盖 `baseUrl`/`paths`（避免继承根配置后 `@/` 指到仓库根）；本刀**优先相对路径导入**，不建 barrel `index.ts`

### 2.3 主题

- `antdTheme.ts`：`colorPrimary: #10B981`，`borderRadius: 16`；页面底用 Tailwind `bg-[#F8FAFC]`
- `main.tsx`：`ConfigProvider` 包住路由；`locale` 用 `antd/locale/zh_CN`
- 不引入额外 UI 库；不用 Ant Design Pro

### 2.4 请求与会话

- `adminApi.ts`：`baseURL` = `import.meta.env.VITE_API_BASE_URL ?? ""`；超时合理（如 15s）；请求头 `Authorization: Bearer <token>`（有 token 时）
- 响应：只认 `{ code, message, data }`；`code !== 0` 当失败
- 响应拦截：`40101` / `40102` 且当前不是登录接口 → 清会话并跳 `/login`；登录接口的 401/403 **只交给表单**
- `storage.ts`：
  - `nongyu-admin:v1:session`
  - `nongyu-admin:v1:rememberedStudentNo`
  - 不写密码
- `authStore.ts`（Zustand）：`token`、`user`、`isHydrated`、`isAuthenticated`
  - `hydrate()`：读 session → `GET /api/admin/auth/me` → 成功写 user，失败清 session
  - `login` / `logout` 按 Spec §4.3、§5
- 为 `window.__NONGYU_ADMIN_PREFILL__` 补类型（`src/types` 或 `vite-env.d.ts`），登录页挂载时只回填、不自动提交

### 2.5 页面与壳

1. **LoginPage**：准入卡（顶沿 3px `#FBBF24`）；字段与文案严格按 Spec §4.2；密码显隐；记住学号默认勾选；`loginType` 来自查询参数否则 `browser`
2. **AdminShell**：`lg`（992px）以上常驻侧栏；以下顶栏汉堡 + Drawer；菜单三项；顶栏右侧姓名 + 登出
3. **守卫**：`RequireAuth` 等 `hydrate` 结束再判断，避免先闪登录页；`GuestOnly` 已登录则去 `/workspace` 或 `location.state.from`
4. **占位页**：工作台欢迎 + 两张可点 Bento 卡；大屏/用户管理仅标题与「即将开放」；未知路径壳内 404
5. 路由表与 Spec §4.1 一致：`/login`、`/workspace`、`/dashboard`、`/users`、`/` → `/workspace`

## 3. 注意事项

- **安全**：禁止 `console.log` token/密码；密码只走登录请求内存；存储失败（隐私模式）须降级提示，不能白屏。
- **性能**：直引 `antd` 具体组件，不封装巨型布局库；登录页不预加载 ECharts。
- **样式**：Tailwind 管布局/间距，AntD 管表单/菜单；登录卡不是 `Card` 默认皮肤堆出来的 Pro 登录页。
- **401 循环**：登录失败不得触发全局登出跳转。
- **CORS**：开发优先走 Vite 代理，不依赖浏览器直连 CORS；直连时才需要 Node `CORS_ORIGIN` 包含管理端 Origin。
- **Git**：本切片是管理端基建；按仓库规范由你决定主分支或项目分支。Agent 不自动 commit。
- **后续切片**：用户管理 / 大屏只填现有路由，不改壳的信息架构。
