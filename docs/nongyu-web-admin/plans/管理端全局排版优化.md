## 2. 实施步骤

### 2.1 文档先行

1. `MASTER.md` Layout：顶栏不重复页标题；页标题仅 PageFrame 22–24px。
2. `登录与管理端壳.md` §4.4：顶栏改为产品名「农屿管理台」。
3. `相关网站.md`：页框 `bare`，禁止默认白底再套一层卡。

### 2.2 PageFrame

文件：`src/components/layout/PageFrame.tsx`

1. 增加可选 `toolbar?: ReactNode`。
2. 标题 class：`text-[22px] sm:text-[24px] font-semibold leading-8 tracking-tight`。
3. `actions` 容器只服务按钮：窄屏 `button` 拉满；**不再**把 Input/Select 设成标题行动作。
4. `toolbar` 画在内容区内顶部（`bare` 则 children 之前）：`mb-4 flex flex-col gap-2 sm:flex-row sm:flex-wrap sm:items-center`；筛选控件窄屏拉满宽。
5. 注释改为：标题行 = 页名 + 主操作；工具栏 = 筛选/搜索。

### 2.3 壳层顶栏

文件：`src/layouts/AdminShell.tsx`

1. 顶栏左侧文案写死「农屿管理台」。
2. 删除仅服务顶栏的 `PAGE_TITLES`（若无其它引用）。
3. 菜单选中、抽屉、助手、折叠、拖宽均不改。

### 2.4 工作台

文件：`src/pages/WorkspacePage.tsx`

1. 去掉英文 `Workspace`。
2. `MODULES` 追加 LLM Key 池、相关网站，顺序与 `AdminShell` `MENU_ITEMS`（除工作台）一致。

### 2.5 业务页工具栏

| 文件                                    | 调整                                                                             |
| --------------------------------------- | -------------------------------------------------------------------------------- |
| `UsersPage.tsx`                         | 原 `actions={filterBar}` → `toolbar={filterBar}`；标题行无 actions               |
| `HomeGreetingsPage.tsx`                 | `actions` = 新建问候语；`toolbar` = 状态 Select + 刷新                           |
| `AgentChatSuggestionsPage.tsx`          | 同上（新建建议 / 筛选+刷新）                                                     |
| `ContentPage.tsx` + `PostListPanel.tsx` | 去掉列表内 `h2`/`title` 展示；搜索行保留为面板工具栏                             |
| `LlmKeysPage.tsx`                       | 受控 Tabs：`keys` 时 `actions`=添加密钥、`toolbar`=筛选+刷新；`fails` 时两者皆空 |

Key 池：`Tabs` 提到页面级 `activeKey` state，失败记录 Tab 不得出现「添加密钥」。

### 2.6 相关网站与大屏小修

1. `RelatedSitesPage.tsx`：`PageFrame bare`；链接卡单层落在 canvas。
2. `TrackSampleRateBar.tsx`：`border-line-soft`，去掉 `border-border`。
3. `KpiCard.tsx`：标题 `text-[13px] font-semibold text-muted`，去掉 `uppercase` 与宽 `tracking`。

登录页：核对后无 MASTER 冲突则不改结构。

### 2.7 验收与收尾

1. 桌面 + 窄屏按 Spec §8 走一遍路由。
2. 根目录或 `apps/nongyu-web-admin` 跑 `pnpm lint`、`pnpm type-check`、`pnpm format`（与仓库现行脚本一致）。
3. Spec / 本计划 / PRD 状态改为已实现。

## 3. 注意事项

- 颜色只使用已有 Tailwind token（`brand` / `canvas` / `surface` / `ink` / `muted` / `line` / `line-soft`）。
- 不改 Ant Design `antdTheme` 主 token，除非某控件在新工具栏里明显撑破（再局部 class）。
- `PageFrame` 的 `[&_.ant-select]:w-full` 曾让筛选在标题行拉满；移到 `toolbar` 后标题行不应再对 Select 生效。
- 助手 `AssistantPanel` 本切片零改动。
