# 怎么丢进 135

1. 打开 [135 编辑器](https://www.135editor.com/)，新建图文，选一个偏绿 / 校园感的模板（主色尽量接近 `#0A7C59`）。
2. 打开同目录 `正文-粘贴到135.md`，**全选复制正文**（可从「建议标题」下面开始，也可整篇粘贴后删掉元信息区）。
3. 粘贴进 135 后，按文中 `【插图：xx.jpg】` 标记，到 `images/` 文件夹上传对应图片，删掉那行文字占位。
4. 封面图建议用 `images/01-home.jpg`。
5. 在 135 里微调：标题样式、分隔线、段间距；满意后「同步到公众号」或复制到微信后台。

## 建议标题 / 摘要（发文时填）

- 标题：农屿上线｜专属川农er的校园助手
- 作者：农屿工作室
- 摘要：无广告课表、教务与二课聚合、农屿 AI。川农同学自己的校园助手来了。
