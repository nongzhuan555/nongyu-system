# 农屿公众号推文 · 直出（免 135）

## 怎么用（约 30 秒）

1. 用浏览器打开预览页（二选一）：
   - 推荐：在本目录执行 `npx --yes serve -l 8765 .`，再打开 http://127.0.0.1:8765/preview.html（复制更稳）
   - 或直接双击 `preview.html`
2. 点页面上的 **「一键复制正文」**。
3. 打开 [微信公众平台](https://mp.weixin.qq.com) → 新建图文消息 → 在正文区域 **Ctrl+V 粘贴**。
4. 封面图单独上传：`images-compressed/01-home.jpg`。
5. 建议标题：`农屿上线｜专属川农er的校园助手`  
   摘要：`无广告课表、教务与二课聚合、农屿 AI。川农同学自己的校园助手来了。`

## 说明

- 正文已是公众号友好的 **全内联 style HTML**，配图为压缩后的 JPEG（base64 内嵌）。
- 粘贴进微信编辑器时，微信一般会把图片转存到自家 CDN；若某张图未显示，在编辑器里对该位置重新插入本地图即可（图在 `images-compressed/`）。
- 改文案或换图后，在本目录执行：`node generate.mjs` 重新生成预览页。

## 文件

| 文件                 | 作用                                  |
| -------------------- | ------------------------------------- |
| `preview.html`       | 手机框预览 + 一键复制（日常只用这个） |
| `article-body.html`  | 纯正文 HTML 片段                      |
| `images-compressed/` | 封面与补传用图                        |
| `generate.mjs`       | 重新打包生成脚本                      |
