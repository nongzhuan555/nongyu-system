# 农屿官网 PRD

> 状态：已确认（2026-08-17 grill 共识）  
> 需求类型：**业务需求**  
> 应用：`apps/nongyu-web-site`

## 背景

农屿 RN 客户端当前版本能力已基本成型，需要品牌官网承载：**功能展示、下载引导、团队联系**。旧站继续可用，本需求为正式落地页重建；功能 GIF 由产品后续提供，开发期用占位。

## 目标

1. 单页官网，让川农学生快速理解农屿是什么、有哪些核心能力、如何下载、如何联系团队。
2. 视觉对齐 RN 客户端「川农新绿」浅色主题，风格高级简约，带克制的流畅动效。
3. 功能区预留 GIF 位；未到图前清晰占位，到图后可替换且不改版式。

## 非目标

- 不做产品内嵌体验（课表/Agent 在线试用）
- 不做暗色模式 / 粉樱主题切换
- 不做多页文档站、博客、后台
- 不做邮箱联系（本轮）
- 暂不展示 ICP（有备案号后再补）
- 不做 iOS 真实下载（无链接时「即将开放」）

## 页面形态

单页落地，自上而下：

1. **固定顶栏**：Logo「农屿」+ 锚点（功能 / 下载 / 联系）+ 「立即下载」
2. **Hero**：品牌名 + 副标题 + 一句说明 + CTA「立即下载」
3. **功能展示**：6 块，桌面左右交替（文/图），移动端上文下图；GIF 占位
4. **下载**：Android APK；iOS 即将开放；链接可配置
5. **联系**：公众号、QQ 群（可复制）
6. **页脚**：农屿工作室 + 版权年

## 功能展示六块（顺序固定）

1. **智能课表** — 周视图、自定义日程、共享与 Diff、桌面小组件
2. **教务聚合** — 通知、成绩、排名、考试、培养方案等一站查询
3. **二课查询** — 活动浏览与个人学分/综测（只读，不含报名）
4. **农屿 AI** — 自然语言查询教务、二课、课表与广场（含教师/教室课表）
5. **校园广场** — 公告、反馈墙、大院
6. **主题与个性化** — 川农新绿等外观与课表偏好

每块后续对应一张 GIF；未到位时同尺寸圆角占位（功能名 +「动图占位」）。

## 下载

- Android：可配置 APK URL；未配置时按钮禁用或标「即将开放」
- iOS：本轮「即将开放」
- 禁止假外链

## 视觉

- 配色：RN 川农新绿浅色（primary `#0A7C59`，container `#D4E9DF`，background `#FAFBFA` 等）
- 风格：高级简约，圆角/轻阴影/留白，接近 App 气质；顶栏可有轻毛玻璃
- 动效：滚动显现、CTA/卡片 hover、顶栏滚动态；尊重 `prefers-reduced-motion`

## 验收（产品向）

1. 桌面/移动首屏可读，品牌「农屿」为主视觉信号
2. 六功能块齐全，占位尺寸稳定，替换 GIF 不挤版
3. 锚点与「立即下载」可滚到对应区
4. 联系两项可复制并有成功反馈
5. 无链接时下载按钮不可点虚假地址
