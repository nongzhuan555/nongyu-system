# 用户管理今日活跃筛选 PRD

> 来源：2026-09-02 需求对齐。业务需求。  
> 状态：已实现。

## 背景

用户管理已有「仅当前在线」筛选；管理员还需查看「今日活跃」用户名单。大屏日活是 Track `app_open` 去重人数，用户表无对应字段。

## 目标

按 **方案 A**：用 MySQL `last_active_at` 落在上海业务日筛选「仅今日活跃」；列表 API + 管理端筛选项 + 助手工具。

## 非目标

- 与 Track DAU 100% 一致（需 Track 联动，见评估结论）
- 与 `status` 合并为同一控件
- `activeToday=0`（仅不活跃）

## Grill 共识

| 项   | 结论                                         |
| ---- | -------------------------------------------- |
| 口径 | `last_active_at` ∈ 今日业务日（BUSINESS_TZ） |
| UI   | 独立筛选项：全部 / 仅今日活跃                |
| 说明 | 文案注明近似活跃，不等同大屏 DAU             |
