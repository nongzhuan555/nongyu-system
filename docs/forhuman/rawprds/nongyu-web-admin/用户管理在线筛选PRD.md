# 用户管理在线筛选 PRD

> 来源：2026-09-01 需求对齐会话。业务需求。  
> 状态：已实现。

## 背景

管理端数据大屏只能看到「当前在线」人数；用户列表虽有 `isOnline` 列，但不能按在线筛选，人多时无法快速查看「现在谁在线」。

## 目标

1. 用户管理列表增加「在线」筛选项：全部 / 仅当前在线。
2. 后端 `GET /api/admin/users` 支持对应 query；口径与大屏 `onlineUsers` 一致。
3. 智慧助手 `admin_users_list` 同步支持该参数。

## 非目标

- 大屏点 KPI 跳转/弹窗在线名单
- 「仅离线」筛选项
- 改在线态写入路径 / 心跳超时时长

## 需求类型

业务

## Grill 共识

| 项     | 结论                                                     |
| ------ | -------------------------------------------------------- |
| 归类   | 业务                                                     |
| 口径   | 与大屏一致：清超时在线后，`is_online=1` 且近 10 分钟活跃 |
| 筛选项 | 全部 / 仅当前在线                                        |
| 范围   | 仅用户管理页 + 列表 API + 助手工具                       |
| 文档   | 短 PRD + Spec/接口文档/计划；跳过 tech                   |
| 助手   | `admin_users_list` 同步 `isOnline`                       |
