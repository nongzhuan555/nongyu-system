# 管理端壳层与智慧助手 UI 对齐 PRD

> 来源：2026-08-17 需求对齐会话。基建需求。  
> 状态：已实现（含前台静默刷新）。

## 背景

管理端智慧助手一期已可用，但对话壳层交互落后于 RN 农屿 Agent（重试/重新生成语义、停止态、生成中可输入等）。左侧导航固定 220px、不可收起、不可拖宽，长页面滚动体验与桌面生产力工具习惯不一致。业务页仅进页或手动刷新拉数，前台停留时数据易过时。

## 目标

1. Web 智慧助手对话 UI/交互对齐 RN Agent（交互 + 视觉，不做结构大改）
2. 左侧导航：可拖拽调宽、可收起为图标栏、`position: fixed` 滚动固定
3. 右侧助手抽屉：可拖拽调宽
4. 展开/收起与宽度偏好全局 `localStorage` 持久化
5. 浏览器标签页前台时，当前业务页每 1 分钟静默刷新数据

## 非目标

- 改问数工具、图表卡片业务逻辑
- 助手 Tabs（对话/会话/模型）结构重构
- RN 式离页保活
- 收起快捷键
- 按管理员账号分桶壳层偏好（全局即可）
- 登录页 / 工作台空态 / 版本管理 iframe / 智慧助手对话 的定时轮询
- WebSocket / SSE 推送

## 需求类型

基建（管理端壳层 + Agent 对话壳层 + 前台数据新鲜度）

## Grill 共识

| 项        | 结论                                                                                      |
| --------- | ----------------------------------------------------------------------------------------- |
| 归类      | 基建                                                                                      |
| 助手对齐  | 交互 + 视觉（B）；Tabs/会话结构不动                                                       |
| 拖宽      | 左导航 + 助手 Drawer                                                                      |
| 左栏收起  | 桌面 → 约 64px 图标栏；小屏保持现有抽屉                                                   |
| 固定      | `position: fixed` + 主内容区让位                                                          |
| 宽度      | 左展开默认 220、范围 180–360；收起固定 64；助手默认 420、范围 320–720                     |
| 拖拽      | 右缘热区；双击恢复默认；拖拽中禁选中                                                      |
| 收起入口  | 左栏内折叠按钮（非顶栏、无快捷键）                                                        |
| 持久化    | 全局 localStorage                                                                         |
| 助手验收  | 重试/重新生成、已停止、打断并发送、思考中、无气泡全宽 + Markdown                          |
| 前台刷新  | 并入本期；`visibilityState===visible`；业务页静默 60s；编辑中跳过；`useForegroundRefresh` |
| tech 文档 | 本期跳过                                                                                  |

## 验收要点

1. 桌面左栏可拖宽、可收起为图标栏，滚动时左侧固定；刷新后宽度与收起态恢复
2. 助手抽屉可拖宽；刷新后宽度恢复
3. 失败/停止/空回复 →「重试」；正常完成 →「重新生成」；停止保留正文并标「已停止」
4. 生成中可打字；发送 = 先停再发新问题
5. 小屏左栏行为与现网抽屉一致，不强制桌面拖宽/收起
6. 业务页前台停留约 1 分钟数据静默更新；标签隐藏时停止；回来可补刷；Modal/Drawer 编辑中不打断
