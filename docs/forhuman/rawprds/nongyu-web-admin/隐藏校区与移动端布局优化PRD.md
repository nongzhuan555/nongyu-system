# 隐藏校区与移动端布局优化 PRD

> 来源：2026-09-01 需求对齐会话。业务需求。  
> 状态：已实现。

## 背景

Web 管理端数据大屏、用户管理仍展示「校区」字段与「校区分布」图表；校区数据虽仍可从后端获取，但产品侧决定**暂不展示**。同时窄屏（手机/平板竖屏）壳层、大屏网格、用户表与抽屉/弹窗体验差：图表过密可拖不可用、表格难扫、触控热区与遮挡问题明显。

## 目标

1. 管理端 UI 与助手引导中隐藏校区相关展示；接口/类型仍保留 `campus`，文档标明「先获取、暂不展示」。
2. `<992px`（与现有 `useIsLg` 一致）下壳层、数据大屏、用户管理、抽屉/Modal 达到「好用」：单列优先、关键信息卡片化、减少横向滚动、触控可点。
3. 不改后端契约；不写独立 tech 文档。

## 非目标

- 删除后端 `campus` 字段或停止拉取 user-distribution 中的 campus 数组
- 从助手工具 enum 移除 `dim=campus` 能力
- 改菜单信息架构 / 路由
- 内容管理及其它未点名业务页的移动端重做
- Node / RN / Track 上报口径变更

## 需求类型

业务（管理端展示与窄屏体验）

## Grill 共识

| 项           | 结论                                                           |
| ------------ | -------------------------------------------------------------- |
| 归类         | 业务                                                           |
| 校区范围     | 大屏图 + 用户列/详情 + 助手不再引导；类型与 API 保留           |
| 文档         | 独立 PRD/Spec/计划 + 同步改现有数据大屏/用户管理/智慧助手 Spec |
| 移动端页面   | 壳层 + 数据大屏 + 用户管理 + 抽屉/Modal                        |
| 断点与体验   | `<992px`；体验偏「好用」（卡片化、优先级清晰）                 |
| 大屏去校区后 | 性别/年级/设备三卡均分；旧布局含 `chart-campus` 过滤并 compact |
| 窄屏大屏交互 | 禁用拖拽改序与缩放，仅纵向滚动                                 |
| 用户列表     | 桌面表格不变；窄屏卡片列表                                     |
| 壳层         | 只修布局与触控，不改菜单结构                                   |
| 助手         | 工具仍可 `dim=campus`；系统提示与空态建议不引导问校区          |
| Tech         | 跳过                                                           |

## 验收要点（摘要）

- 大屏无「校区分布」卡；用户列表/详情无校区展示
- 文档写明 campus 暂不展示
- 窄屏：汉堡抽屉可用；大屏不可拖缩放；用户为卡片；抽屉全宽、Modal 留边
