# 数据大屏：页面路由映射与页均停留时长 PRD

### 需求背景

管理端数据大屏「页面使用次数」目前只展示 RN 原始 pathname，可读性差。RN 已上报带 `duration_ms` 的页面离开事件，但大屏尚未展示页均停留，不利于分析。

### 需求类型

业务需求（管理端大屏增强；Track dims 口径补齐为支撑）。

### 目标

1. 页面使用次数、页均停留等维度图的类目名：有映射时展示 `页面名 (原始路由)`，无映射时展示 `原始路由（未映射）`。
2. 新增「页均停留时长」横向柱状图：按页面平均停留，降序，展示当日全部页面。
3. 「页面使用次数」改为进入次数口径（只计 enter），避免 enter+leave 双计。

### 范围要点

- 只映射 RN 端路由；映射表放 Web 管理端展示层；动态路由支持模式匹配。
- 平均停留：仅 `screen_view` 且 `duration_ms` 非空；值以秒展示（一位小数）。
- Track 新增 dim metric（如 `screen_dwell_avg`），今日 live + 历史日聚合均支持；大屏仍默认看今日。
- 使用次数与停留图均按「全部页面」拉取（在现有 dims limit 上限内，当前路由规模视为全部）。
- 不写独立技术方案文档；历史已聚合的旧 `screen_views` 不强制回填。
