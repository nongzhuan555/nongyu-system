# 管理端相关网站 PRD

> 应用：`apps/nongyu-web-admin`  
> 需求类型：**业务**

## 背景

侧栏「相关网站」提供运营常用外链。曾移除 Pushy 嵌入；现补回 **Pushy 外链便捷跳转**（仍不 iframe）。

## 目标

1. 侧栏菜单文案为「相关网站」
2. 页内快捷外链：阿里云、腾讯云、农屿官网、**Pushy**
3. 农屿官网手机框 iframe 实时预览（`http://101.43.34.229/`）
4. Pushy **仅新窗口外链**，不嵌入

## Grill 共识

| 项    | 结论                                                                                                                                         |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Pushy | 外链便捷跳转；不 iframe                                                                                                                      |
| 路由  | `/related-sites`；`/versions` 重定向                                                                                                         |
| URL   | 阿里云 `https://www.aliyun.com`；腾讯云 `https://cloud.tencent.com`；农屿官网 `http://101.43.34.229/`；Pushy `https://pushy.reactnative.cn/` |
| 布局  | 四外链 + 仅农屿官网手机 iframe                                                                                                               |
| 更正  | 预览对象为**农屿官网**，不是川农官网                                                                                                         |
