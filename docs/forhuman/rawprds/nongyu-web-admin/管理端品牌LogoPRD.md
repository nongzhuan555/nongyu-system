# 管理端品牌 Logo PRD

> 应用：`apps/nongyu-web-admin`  
> 需求类型：**业务**

## 背景

管理台浏览器标签与页内品牌位仍用纯色占位 / 文字「NY」「Nongyu」，与 App 农屿 logo 不一致。

## 目标

1. Favicon 使用农屿 logo（与 RN `assets/icon.png` 同源）。
2. 侧栏品牌区、登录页品牌区展示同一 logo 图。
3. 不改侧栏业务菜单的 Ant Design 功能图标。

## 共识（Grill · 全部按推荐）

| 项                      | 结论                                             |
| ----------------------- | ------------------------------------------------ |
| 范围                    | 仅 web-admin                                     |
| 素材                    | RN `icon.png`，拷贝压缩后放入 `public/`          |
| 替换点                  | favicon、侧栏 BrandBlock（含收起）、登录页标题旁 |
| 菜单图标                | 不换                                             |
| 智慧助手入口 Robot 图标 | 不换（功能入口，非品牌位）                       |
| 技术方案文档            | 跳过                                             |
