# 管理端全局排版优化 PRD

> 来源：2026-09-02 需求对齐会话。业务需求。  
> 状态：已实现。

## 背景

Web 管理端色板、圆角、侧栏选中绿条已对齐 `design-system/web-admin/MASTER.md`，但页内信息层级重复、筛选挤在标题行、白底套白底、工作台入口不全，扫读成本高。本需求只修排版与一致性，不改路由、接口、侧栏分组。

## 目标

1. 每页只有一层页名：顶栏是壳层 chrome，页标题只出现在 PageFrame（工作台用欢迎区大标题）。
2. 标题行只放主操作；搜索/筛选下沉到内容区工具栏；同类 CRUD 页结构一致。
3. 去掉无意义的卡片套卡片；工作台补齐侧栏已有、工作台缺失的入口。
4. 视觉仍以 MASTER 为唯一准则；不写独立技术方案文档。

## 非目标

- 侧栏菜单分组、改路由、改接口/数据模型
- 智慧助手对话内部 UI（Tabs / 消息列表 / 输入条）
- 重做数据大屏网格交互、用户窄屏卡片方案（已有切片）
- 换色板、换字体、换签名元素

## 需求类型

业务（现有页面排版与密度）

## Grill 共识

| 项       | 结论                                                                                          |
| -------- | --------------------------------------------------------------------------------------------- |
| 归类     | 业务                                                                                          |
| 范围     | 登录页、壳层顶栏、工作台、大屏、用户、内容、问候、AI 建议、LLM Key 池、相关网站；助手内部不动 |
| 双标题   | 顶栏不再重复页名；页名只留 PageFrame，字号 22px（可至 24）                                    |
| 侧栏分组 | 本期不分组；只补工作台入口                                                                    |
| 筛选位置 | 标题行 = 主操作；筛选/搜索 = 内容区顶部工具栏                                                 |
| 技术方案 | 跳过                                                                                          |
