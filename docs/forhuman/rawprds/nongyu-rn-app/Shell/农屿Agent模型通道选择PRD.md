# 农屿 Agent 模型通道选择 PRD（草稿）

## 一句话

用户配置了自有 API Key 后，仍可在设置里选择继续使用农屿后台（平台 LLM 代理），且不必清除已保存的 Key。

## 背景

当前解析规则是「有自有 Key 则强制走自有；否则走农屿后台」。用户想临时用免费后台、或后台排队时再切回自有 Key，却只能清掉 Key，体验差。

## 目标

1. Agent 设置页增加「模型通道」二选一：农屿后台 / 自有 Key。
2. 切到农屿后台时**保留**本地 SecureStore 凭据。
3. 保存自有 Key 成功后自动切到「自有 Key」通道；之后仍可手动切回农屿后台。
4. 轻量整理设置页分区顺序与文案。

## 非目标

- 管理后台同步改造
- 改 `settings_get` 工具契约
- 多模型/多通道并行、云端同步偏好

## Grill 共识摘要

| 项               | 结论                                |
| ---------------- | ----------------------------------- |
| 归类             | 基建                                |
| 范围             | 仅 RN App                           |
| 交互             | 列表单选；保留 Key                  |
| 默认             | 无偏好时：有 Key→自有，无 Key→后台  |
| 存储             | MMKV 设备偏好；登出/清 Key 不清偏好 |
| 无 Key 时        | 「自有 Key」选项禁用                |
| 偏好自有但无凭据 | 回退后台（有 JWT）                  |
| Tech 文档        | 跳过                                |
