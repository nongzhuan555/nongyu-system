# 底部导航 / App Shell PRD（草稿）

> 来源：2026-08-11 需求对齐会话。基建需求。页面内容均为占位。

## 背景

农屿学生端需要统一的底部主导航壳，承载首页、课表、广场、我的四个主入口，并提供「农屿 AI」快捷入口。视觉参考悬浮胶囊 + 玻璃拟态底栏（左侧圆形 AI、右侧胶囊 Tab）。

## 目标

- 落地可复用的自定义底部导航组件与路由骨架
- 四个 Tab 页与 AI 占位页可切换
- 视觉接近参考图：悬浮、毛玻璃、主题色选中圆底
- AI 进入动效为淡入 + 轻微放大（约 320ms）

## 非目标

- 不实现各 Tab / AI 真实业务
- 不完成 AI 入口最终视觉（头像等），先用「农屿AI」四字占位
- 不改登录鉴权流
- 不编写独立技术方案文档（本需求跳过 tech）

## 信息架构

| 位置                      | 名称                      | 说明                                 |
| ------------------------- | ------------------------- | ------------------------------------ |
| 底栏左侧圆形              | 农屿 AI                   | 文案「农屿AI」占位；点击进入 AI 栈页 |
| 底栏右侧胶囊（约 70% 宽） | 首页 → 课表 → 广场 → 我的 | 四个 Tab，filled 实心图标 + 短文案   |

- 冷启动默认：首页
- AI 页：Stack push，底栏隐藏；返回回到原 Tab

## 视觉与交互

- 整体悬浮：距左右与底部安全区有边距；AI 圆钮与右侧胶囊有间隙
- 右侧条：胶囊形；`expo-blur` 真毛玻璃（Android 用 BlurTargetView；旧机 blurMethod 降级）
- 图标：Ionicons filled；选中态为实心圆底 + 白图标，颜色跟当前主题 brand
- 未选中：主题次要文字色实心图标 + 文案

## AI 转场

- 呈现：根 Stack 压入 AI 占位页
- 动效：opacity + scale（轻微放大），约 320ms，ease-out
- 返回：对称或系统返回，体感一致即可

## 验收（草稿）

1. 底栏布局与参考图结构一致（左圆 + 右胶囊）
2. 四 Tab 顺序正确，默认首页
3. 选中圆底用主题色；切换正确
4. 毛玻璃在 Dev Client 新壳上可见（需含 expo-blur）
5. 点「农屿AI」进入占位页，有淡入+缩放；AI 页无底栏
6. 各页仅为占位文案，无业务逻辑
