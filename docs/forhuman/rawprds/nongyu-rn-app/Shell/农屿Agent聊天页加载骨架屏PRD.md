# 农屿 Agent 聊天页加载骨架屏 PRD

> 来源：2026-08-15 需求对齐会话。基建需求。  
> 状态：已落地（待人工回归）。

## 背景

用户重新进入农屿 Agent 聊天页时，需等待 `getOrCreateNongyuAgent` 异步就绪；当前整页仅显示「加载中」文案，体验空洞，与课表等模块已有的 `SkeletonBox` 脉冲骨架不一致。

## 目标

- 用聊天页形态的骨架屏替代「加载中」文字
- 视觉上贴近真实对话布局（消息区气泡占位 + 底部输入栏），降低等待焦虑

## 非目标

- 不改侧栏切会话、新对话等同步路径的加载态（本期无独立等待 UI）
- 不改生成中 / 工具调用中的消息内骨架或流式态
- 不引入新依赖

## 需求类型

基建（Agent 聊天壳层体验）

## Grill 共识

| 项       | 结论                                                              |
| -------- | ----------------------------------------------------------------- |
| 归类     | 基建                                                              |
| 触发范围 | 仅 `agent === undefined` 的整页等待                               |
| 骨架形态 | 保留真实 Header；中间气泡占位；底部输入栏灰条；复用 `SkeletonBox` |
| 空会话   | 首次进入 / 无历史同样用同一套骨架                                 |
| tech     | 跳过                                                              |

## 验收要点

1. 进入 / 重新进入 `/ai` 且 agent 未就绪时，不再出现居中「加载中」文案
2. 可见脉冲骨架：气泡列表 + 底部输入栏占位；顶栏「农屿 AI」仍为真实 Header
3. agent 就绪后正常进入聊天面板或「暂不可用」面板，无骨架残留
