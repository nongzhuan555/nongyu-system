# PRD：农屿 Agent 空态快捷建议（运营可配）

> 来源：2026-08-17 需求对齐（聊天 Grill）；需求类型：**业务**  
> 涉及：`nongyu-rn-app` / `nongyu-node-server` / `nongyu-web-admin`

## 背景

AI 聊天新对话空态（`ChatEmptyState`）的快捷建议目前写死在客户端：

- 查一下我的成绩
- 本周有哪些二课活动
- 看看我的课表
- 帮我改成深色主题

运营改文案必须发版。首页打招呼第二句已走「表 + Admin CRUD + App 只读」链路，空态建议应对齐同一运营能力。

## 目标

1. 管理端可配置 AI 空态 chip 文案（多条同时启用 + 排序），无需发版。
2. App 登录后拉取当前启用列表，点选仍直接作为用户消息发起对话（现有行为不变）。
3. 拉取失败 / 未登录 / 无启用项时，回落到上述 4 条本地文案。
4. 问候标题与副标题仍本地生成，本期不配。

## 范围外

- 空态标题 / 副标题 / 头像运营配置
- 管理端智慧助手面板里的本地建议（`AssistantPanel`）
- 按用户/学院/时段个性化建议
- 拖拽排序、图标、副文案等富字段
- 技术方案文档（克隆首页问候语，无新架构）

## 关键约定（Grill 共识）

| 项       | 约定                                                                |
| -------- | ------------------------------------------------------------------- |
| 归类     | 业务                                                                |
| 范围     | Node 表 + Admin CRUD + App 只读 + Web Admin 配置页 + RN 空态拉取    |
| 可配面   | 仅快捷建议文案                                                      |
| 数据     | 多条记录：文案 + 启用 + `sortOrder`；可同时启用多条                 |
| App 展示 | 按 `sortOrder` 升序、同序按 `id`，最多 **6** 条；Admin 可启用超过 6 |
| 文案长度 | trim 后 1～24 字                                                    |
| 鉴权     | App GET 需 App JWT                                                  |
| 兜底     | 当前 4 条本地常量                                                   |
| 加载     | 问候立即显示；chip 区先骨架，成功或失败后再出列表（失败走兜底）     |
| 排序 UI  | 管理端填整数 `sortOrder`，不拖拽                                    |
| Seed     | 迁移写入当前 4 条并全部启用                                         |
| 管理端   | 侧栏新页「AI 建议」，放在「首页问候」后面                           |

## 建议契约（供 Spec 展开）

- 表：`agent_chat_suggestions`（`id` / `text` / `enabled` / `sort_order` / 时间戳）
- App：`GET /api/app/agent/chat-suggestions` → `{ items: [{ id, text }] }`；无启用项时 `items: []`（客户端兜底）
- Admin：`/api/admin/agent-chat-suggestions` 列表 / 创建 / 更新 / 删除；更新含 `text`、`enabled`、`sortOrder`
- 启用不互斥（与首页问候不同）
- 点选 chip：把 `text` 交给现有 `onSuggestion`，不改发送链路

## 验收要点

1. 管理端能新建 / 编辑 / 启停 / 改序 / 删除；侧栏可进入「AI 建议」。
2. 启用列表变更后，App 新对话空态 chip 随之变化（最多 6 条）。
3. 断网或接口失败时仍显示本地 4 条，且不先闪错误运营文案。
4. 空文案 / 超 24 字被拒；无 JWT 不可读 App 接口、不可写 Admin 接口。
5. 标题「{姓名}你好！我是农小屿~」与副标题行为不变。
