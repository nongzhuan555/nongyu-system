# 农屿 AI 入口气泡提示 PRD（草稿）

> 来源：2026-08-13 需求对齐会话。基建需求。

## 背景

底栏左侧「农屿 AI」入口易被忽略，需要用聊天气泡做轻量引导，提示用户可点击使用。

## 目标

- 从农屿 AI 圆钮附近冒出聊天气泡，文案固定：「点击此处使用农屿AI功能」
- 每次进入 App（冷启动、回前台、进入带底栏主壳）均提示一次
- App 在前台时每隔 3 分钟再提示一次

## 非目标

- 不做可配置文案后台、不做「不再提示」持久开关（本版）
- 不编写独立技术方案 / 实施计划文档（仅 Spec）
- 不改变 AI 页业务能力

## 触发与抑制

| 场景                        | 是否提示                            |
| --------------------------- | ----------------------------------- |
| 冷启动进入主壳（有底栏）    | 是                                  |
| 从后台回到前台且当前有底栏  | 是                                  |
| 登录后进入主壳              | 是（同进入主壳）                    |
| 当前在 `/ai` 或其它无底栏页 | 否                                  |
| 前台每隔 3 分钟             | 是（仅前台计时；无底栏时不计/不弹） |

## 交互与视觉

- 气泡从 AI 圆钮右上方伸出，尖角指向圆钮；轻微弹出缩放
- 展示约 4–5 秒后自动淡出
- 点击气泡 = 点击 AI 入口（关闭气泡并进入 AI）
- 点击 AI 圆钮：关闭气泡并进入 AI

## 验收（草稿）

1. 进入主壳可见气泡文案正确
2. 回前台（有底栏）会再冒一次
3. 前台约 3 分钟再冒一次；后台不计时
4. 在 AI 页不冒泡；返回带底栏页后恢复计时逻辑
5. 自动消失与点击提前关闭行为符合上述约定
