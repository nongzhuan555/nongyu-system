# 农屿 Agent 工具 UI 显示开关 PRD

> 来源：2026-08-30 需求对齐会话。基建需求。  
> 状态：Grill 已对齐，待 Spec 审查通过后实施。

## 背景

农屿 Agent 支持 A2UI（Controlled）：工具声明 `render` 并在前端注册 UI 后，工具调用会在 AI 回复下方内联展示对应组件。

多步工具链里，中间工具常只为后续核心工具取前置数据。这些中间调用若也注册了 UI，仍会全部展示，用户并不关心，造成回复下方卡片过多、干扰核心结果。

## 目标

- 模型可按用户意图，为**每一次**带渲染声明的工具调用决定是否最终展示 UI
- 前置取数类调用可关闭 UI；面向用户的核心结果保留卡片
- 默认行为与现状兼容（漏传时仍显示）

## 非目标

- 不改业务工具的业务入参语义（开关为元参数，执行前剥离）
- 不做 Declarative / 模型写 JSX
- 不在本期重做折叠交互产品形态（仅规定与 `showUI` 的组合顺序）
- 不写独立技术方案文档

## 需求类型

基建（`nongyu-agent-sdk` + RN / Web Admin A2UI 渲染）

## Grill 共识
