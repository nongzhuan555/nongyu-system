# 农屿 Agent 交互优化 PRD

> 来源：2026-08-15 需求对齐会话。基建需求。  
> 状态：Grill 已对齐，待 Spec 审查通过后实施。

## 背景

农屿 Agent 对话已具备生成保活与输入栏「停止」能力，但失败 / 打断 / 空回复后缺少一键重试，也无法对已完成回复「重新生成」；生成中输入框锁定，体验与 ChatGPT / Claude 等主流助手有差距。

## 目标

- **重试**：失败、用户停止、空回复后，可一键用同一条 user 消息再生成（不重复插入 user 气泡）
- **重新生成**：对最近一条成功完成的 assistant，可丢弃该条后重新生成
- **打断打磨**：停止后保留已生成内容，明确「已停止」状态，并可重试
- **打断并发送**：生成中可继续编辑输入；发送时先停当前流再发新问题

## 非目标

- 编辑历史 user 消息并从中间重跑
- 复制消息 / 长按菜单 / 建议追问 chips
- 网络失败自动静默重试
- 多路并行生成

## 需求类型

基建（Agent 聊天壳层交互）

## Grill 共识

| 项           | 结论                                                             |
| ------------ | ---------------------------------------------------------------- |
| 归类         | 基建                                                             |
| 本期范围     | 重试、Stop 打磨、重新生成、错误态按钮、「已停止」；二期能力不做  |
| 重试触发     | error / stopped / 空回复 →「重试」；主观不满意 →「重新生成」     |
| 历史处理     | 去掉坏的 / 目标 assistant，不重复插 user，再流式生成新 assistant |
| 生成中再发送 | 先 stop 再立刻用新内容开一轮                                     |
| 操作入口     | 最近一条 assistant 下方操作条                                    |
| 停止状态     | 新增 `stopped`；保留已生成正文                                   |
| 空回复       | `done` 且正文 trim 空且无成功 tool 结果 → 露出「重试」           |
| tech 文档    | 本期跳过                                                         |

## 验收要点

1. 失败 / 停止 / 空回复后，最近一条 assistant 下可见「重试」，点后不新增 user 气泡并重新流式输出
2. 正常完成后可见「重新生成」，点后替换该条 assistant
3. 点停止：内容保留，标「已停止」，可重试
4. 生成中可打字；点发送 = 打断并发送新问题
5. 输入栏 Stop 在工具执行中仍可打断
