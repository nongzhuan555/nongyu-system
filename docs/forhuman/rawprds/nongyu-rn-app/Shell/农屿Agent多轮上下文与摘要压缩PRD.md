# PRD：农屿 Agent 多轮上下文与摘要压缩

| 项   | 内容                             |
| ---- | -------------------------------- |
| 应用 | 农屿 RN App + `nongyu-agent-sdk` |
| 类型 | 基建                             |
| 来源 | 2026-08-15 对话确认（Grill）     |
| 状态 | 草稿（作为 Spec 信息源）         |

## 问题

农屿 AI 聊天页会把多轮消息画在界面上、也会本地存会话，但每次调大模型只带当前这一句。用户上一句说的内容，下一句模型完全不记得。

## 要做什么

1. 每次请求把**当前会话已有历史全量**交给模型（含工具调用与工具结果），加上本轮新消息。
2. 会话变长、接近上下文上限时，用**同一个已配置的对话模型**对旧段做摘要压缩（hybrid：摘要 + 最近若干轮原文）。
3. 摘要跟会话一起落盘；界面上的完整气泡历史不删。
4. **每次真正完成一次压缩时** Toast：「当前会话过长，已做摘要压缩」。
5. 摘要失败则丢掉旧段、只留近轮原文，另 Toast 告知压缩失败已降级，不堵住本轮回复。

## 不做

- 设置页暴露 token 上限 / 压缩开关
- 单独再配一套摘要模型
- 云端记忆、跨会话记忆
- 在聊天列表里插入「正在整理」气泡
