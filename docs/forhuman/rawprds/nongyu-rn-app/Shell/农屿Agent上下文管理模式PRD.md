# 农屿 Agent 上下文管理模式 PRD

> 来源：2026-08-15 需求对齐。基建需求。  
> 状态：Grill 已对齐，按推荐实施。

## 背景

用户希望在农屿 Agent 设置中选择上下文管理方式：默认多轮带记忆，或每次提问无记忆（省 token / 避免历史干扰）。

## 目标

- 设置页提供两种模式，默认「完整上下文」
- 每种模式下方有简短区别说明
- 「无记忆」：调用模型时仅当前问题 + 系统提示词；聊天 UI 仍显示会话气泡与落盘

## 非目标

- 按会话单独设置模式
- 改系统提示词内容
- 云端同步该偏好
- 清除 API Key 时重置该偏好

## Grill 共识

| 项      | 结论                                      |
| ------- | ----------------------------------------- |
| 归类    | 基建                                      |
| 命名    | 完整上下文（默认）/ 无记忆                |
