# 农屿 Agent 生成保活不中断 PRD

> 来源：2026-08-15 需求对齐会话。基建需求。  
> 状态：Grill 已对齐，待 Spec 审查通过后实施。

## 背景

用户与农屿 Agent 对话时，若将 App 切到后台，或离开 AI 页，当前可能因系统挂起网络/JS，或因离页时主动 `stop()`，导致大模型生成中断。期望在轻量尽力保活前提下尽量不中断；若仍中断，回前台时用 Toast 告知。

## 目标

- **范围 C**：切后台、离开 AI 页时，均不主动中断进行中的生成
- **轻量保活**：申请短时后台执行窗口（尽力而为，不承诺无限后台）
- **失败告知**：回前台时若发现本次生成已因挂起/断流等异常中断，Toast 提示用户
- **主动停止仍有效**：停止按钮、登出、`invalidateNongyuAgent` 等仍立即中断

## 非目标

- 不做 Android 前台常驻通知服务等强保活
- 不做服务端代跑 Agent / 云端续跑
- 不保证杀进程、系统强制杀后台后仍能续跑
- 本期不改造为真正多 Agent 并行多路流

## 需求类型

基建（Agent 运行时 / AI 页壳层）

## Grill 共识

| 项                    | 结论                                       |
| --------------------- | ------------------------------------------ |
| 不中断范围            | C：后台 + 离 AI 页                         |
| 保活深度              | 轻量尽力                                   |
| 失败提示              | 回前台发现已异常中断 → Toast               |
| 流式状态归属          | 模块级单例 Runner（按会话订阅；页只订阅）  |
| 生成中切会话 / 新对话 | 旧会话后台继续跑完并落盘；回来可见完整结果 |
| 他会话再发送          | 禁止；Toast「请等待当前回复完成」          |
| 离页/后台遇工具审批   | 挂起等待；回 AI 前台后再弹 confirm         |
| 主动停止              | 停止按钮 / 登出 / invalidate 仍立即停      |
| 技术方案文档          | 本期跳过                                   |

## 验收要点

1. 生成中按 Home 再回前台：若系统保住则继续出字/出卡；若中断则 Toast，可重试
2. 生成中返回上一页再进 AI：该会话生成未主动 stop；完成后已落盘；再进入可见完整结果
3. 生成中切到其他会话仅查看：旧会话继续；在新会话点发送被拦截并 Toast
4. 点停止 / 登出仍立即中断
5. 需审批工具在离页期间不自动拒绝；回 AI 页后可继续确认
