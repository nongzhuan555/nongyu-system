# PRD：广场回复与留言（反馈墙管理员回复 + 大院留言 + 轮询通知）

| 项       | 内容                                                           |
| -------- | -------------------------------------------------------------- |
| 来源     | 用户口头需求（2026-08-17）+ 澄清问答                           |
| 涉及端   | `nongyu-rn-app` / `nongyu-node-server` / `nongyu-web-admin`    |
| 需求分类 | 业务需求                                                       |
| 关联     | `docs/nongyu-rn-app/specs/广场功能.md`（既有广场三区基础能力） |

---

## 1. 背景

农屿广场目前由统一 `posts` 表 + `post_type`（announcement / feedback / courtyard）承载公告、反馈墙、大院三类内容，**完全不支持回复与留言**。本期为反馈墙与大院补齐「回复 / 留言」能力，并引入轻量轮询让用户及时感知自己帖子被回复的情况。公告墙不参与本次变更。

## 2. 需求概述

### 2.1 反馈墙管理员回复

- 反馈墙帖子（`post_type = feedback`）**只可由管理员在管理端进行回复**，且每个帖子**仅可有一条回复**。
- 管理员可对该条回复进行**增 / 删 / 改**；各管理员对此回复的权限**完全平等**（任一管理员可改、可删其他管理员的回复），**无需操作留痕**（不记录由谁改、何时改）。
- 该条管理员回复对**所有用户可见**，但管理员身份对用户**匿名化**：用户侧统一看到「管理员回复」字样，不暴露具体管理员姓名。

### 2.2 大院用户留言

- 大院帖子（`post_type = courtyard`）支持用户之间在帖子下**留言**。
- 留言为**顶层留言**，**不支持嵌套回复**（不支持楼中楼）。
- 留言对用户之间**完全匿名**：用户看不到留言者任何标识（无昵称、无头像、无学号），仅自己能识别自己发的留言（通过 `isMine` 标记）。
- 用户可**删除**自己的留言；**不支持编辑**。
- 用户可删除自己发的帖子（既有能力，保留）。

### 2.3 管理端审核

- 管理员可在管理端**看到全站帖子**（含反馈墙、大院、公告）以及**对应帖子下的留言信息**。
- 对大院留言，管理员可**单独删除任意一条留言**（不删帖）。
- 管理员可**删除任意帖子**；帖子被删除后，其下**所有留言 / 回复连带删除**。
- 管理端对管理员**实名**展示留言者 / 帖子作者真实身份（学号 + 姓名）。

### 2.4 用户查看自己帖子被回复的情况

- 用户可查看：
  - 自己的**反馈墙帖子**被管理员回复的情况（是否有回复、回复内容）；
  - 自己的**大院帖子**被用户留言的情况（留言列表）。
- 大院留言场景下，用户对自己帖子下的他人留言仍为匿名（看不到留言者身份）。

### 2.5 轮询与通知

- 用户在 RN 端**前台状态**时，以 **30s** 为间隔：
  1. 轮询**反馈墙、大院列表**的最新状态并渲染（公告墙**不轮询**，由用户自行下拉刷新）；
  2. 轮询**自己的帖子是否被回复**，若有**新的回复**则 **toast** 通知用户。
- 列表轮询仅在**广场 Tab 处于前台**时进行；自己帖子被回复的轮询在 **App 任意页面前台**时均进行。
- 「新的回复」由服务端判定：服务端为每条回复 / 留言维护针对帖子作者的**「是否已通知」标记，通知后置位**，避免重复 toast。

## 3. 澄清结论（grill）

| 项                         | 结论                                                         |
| -------------------------- | ------------------------------------------------------------ |
| 需求分类                   | 业务需求                                                     |
| 反馈墙管理员回复可见性     | 所有用户可见，但管理员身份匿名化（统一「管理员回复」）       |
| 大院留言层级               | 仅顶层留言，不支持嵌套                                       |
| 大院留言匿名形式           | 完全匿名（仅 `isMine` 自识）                                 |
| 管理员对大院留言的审核权限 | 可单独删除任意留言（不删帖）                                 |
| 用户对自己留言的管理       | 可删除，不可编辑                                             |
| 轮询范围                   | 列表轮询仅在广场 Tab 前台；自己帖子被回复轮询在 App 任意前台 |
| 新回复判定                 | 服务端维护「是否已通知」标记，通知后置位                     |
| 管理员回复身份展示         | 统一「管理员回复」，不暴露具体管理员                         |

## 4. 非目标（本期不做）

- 不做留言 / 回复的点赞、举报、富文本、图片。
- 不做嵌套回复（楼中楼）。
- 不做管理员回复的操作留痕（不记录修改人 / 修改时间）。
- 不做公告墙的回复 / 留言。
- 不做推送通知（仅前台轮询 + toast）。
- 不做后台轮询（App 进入后台 / 失活时停止轮询）。
- 不做留言数量上限的强约束（仅做内容长度上限的合理默认）。
