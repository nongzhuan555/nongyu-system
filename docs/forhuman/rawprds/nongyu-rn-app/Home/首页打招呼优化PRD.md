# PRD：首页打招呼模块优化

> 来源：2026-08-16 需求对齐（聊天整理）；需求类型：**业务**

## 背景

首页打招呼目前为本地固定句式（`姓名你好，现在是{时段}，祝你学习顺利`）+ 打字机，无骨架屏、无后端运营文案。希望改为更自然的「称呼 + 时段问候」，并支持后台配置第二句问候语。

## 目标

1. 第一段本地生成：`{姓名}，{时段}好`（无姓名：`你好，{时段}好`）；时段沿用现有 7 档。
2. 第二段由后端配置；App 拉取当前启用的一条。
3. 时段问候后加中文逗号，再接运营第二句，同一打字机连续播放。
4. 打招呼区接入骨架屏：数据齐（含兜底）后再撤骨架并开打字机。
5. 补齐 Node：表 + Admin CRUD API + App 读接口（本期不做 Web Admin UI）。

## 范围外

- Web 管理端配置页
- AI / 天气拼进问候
- 改通知栏与其它首页区块

## 关键约定（Grill 共识）

| 项     | 约定                                          |
| ------ | --------------------------------------------- |
| 启用   | 全局最多一条 `enabled`；启用新的自动关掉旧的  |
| 鉴权   | App 读接口需 JWT；未登录/失败走本地第二句兜底 |
| 长度   | 后端问候语 ≤48 字                             |
| 兜底   | 本地默认第二句（如「祝你今天学习顺利」）      |
| 分隔   | 时段问候后中文逗号再接第二句                  |
| 骨架   | 仅打招呼区域；与通知栏独立                    |
| 管理端 | Admin API + Web「首页问候」配置页 + seed      |
