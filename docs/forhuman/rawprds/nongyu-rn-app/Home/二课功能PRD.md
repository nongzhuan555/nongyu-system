| 项       | 内容                                                             |
| -------- | ---------------------------------------------------------------- |
| 应用     | `apps/nongyu-rn-app` + `packages/nongyu-tool-second` + Agent     |
| 需求类型 | 基建 + 业务                                                      |
| 来源     | `docs/forhuman/records/all-prd.md` 二课段落；2026-08-15 对话对齐 |
| 状态     | 草稿                                                             |

## 一句话

补齐 `nongyu-tool-second`（含大模型可调用的 tool 面），在 RN App 接入只读二课业务页；活动推荐仅通过 Agent 使用。

## 范围

### 工具库（全部做成可调用能力 / Agent Tool）

- 登录与会话（Cookie / 凭据桥接，对齐教务工具库模式）
- 个人二课信息：二课分学分分布、附加分记录、累计二课分、综测得分、二课排名等
- 活动列表：关键词搜索、按部落 / 分类筛选
- 活动详情
- （原子能力供 Agent 组合）活动推荐所需查询面；**不做报名等写操作**

### App（用户点击使用）

- 二课入口页（替代现占位）
- 个人二课信息页
- 活动列表页（搜索 + 筛选）
- 活动详情页

### 仅 Agent

- 活动推荐：用户提需求 → Agent 结合个人二课情况与毕业所需，调用二课原子 tool 推荐活动并附理由

## 非目标

- 二课活动报名 / 取消报名等写操作的**代码实现**（旧版报名接口契约写入技术文档，供后续版本，本轮不实现）
- App 内独立「活动推荐」页
- 把推荐策略冻进工具库（推荐编排在 Agent）

## 验收直觉

- 包可被 RN 与 Agent SDK 引用；有使用文档
- 真机至少跑通登录 + 一项核心查询
- App 可从首页进二课，查看个人信息和活动列表/详情（只读）
