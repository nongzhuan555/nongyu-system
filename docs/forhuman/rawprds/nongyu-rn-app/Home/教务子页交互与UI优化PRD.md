# PRD：教务子页交互与 UI 优化（草稿）

| 项       | 内容                              |
| -------- | --------------------------------- |
| 应用     | `apps/nongyu-rn-app`              |
| 需求类型 | 业务                              |
| 来源     | 2026-08-14 对话对齐（全部走推荐） |
| 状态     | 草稿                              |

## 一句话

优化教务系统各子功能页：统一渐变背景、列表页前端搜索、学业进度可视化进度条。

## 范围

- 七个子功能页：通知、竞赛、学业进度、成绩、专业排名、考试、培养方案
- 渐变背景：七页全部对齐主 Tab（首页/广场/我的）的 `TabScreenBackground`
- 搜索：除「专业排名」（单卡无列表）外的六页；纯前端、不区分大小写、子串匹配
- 学业进度：在卡片上增加横向进度条
- 不做：教务首页搜索；后端/接口改动；技术方案单独文档

## 搜索字段（推荐）

| 页        | 匹配字段                         |
| --------- | -------------------------------- |
| 通知/竞赛 | 标题、日期                       |
| 学业进度  | 类型                             |
| 成绩      | 课程名、学期、课程类型、成绩来源 |
| 考试      | 课程名、考场、时间、考核方式     |
| 培养方案  | 课程名、课程代码、课程类型       |

## 交互要点

- 搜索条统一放在子页壳顶栏下方
- 无匹配时文案区分于「暂无数据」：显示「未找到相关结果」
- 进度条：解析进度字符串中的百分比；解析失败则仅保留文字

## 验收直觉

- 进任意教务子页，背景与首页等 Tab 渐变一致
- 列表页可输入关键词即时过滤
- 学业进度卡片有直观进度条
