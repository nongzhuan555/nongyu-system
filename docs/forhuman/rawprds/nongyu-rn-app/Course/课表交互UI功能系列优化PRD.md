# 课表交互 UI 功能系列优化（短 PRD）

| 项   | 内容                                                                 |
| ---- | -------------------------------------------------------------------- |
| 应用 | 农屿 RN App（含 Node course-ext / Track 埋点）                       |
| 类型 | **混合**：主归业务；性能懒加载与首屏埋点为同批非功能项               |
| 日期 | 2026-08-15                                                           |
| 关联 | `课表模块PRD.md`；修订其中「日程不可与课程同格」约定为本期可冲突叠卡 |

## 背景

课表周视图与自定义日程/备注/待办已落地，但日程卡片观感偏弱、日程与课程不能同格、缺考勤、全学期矩阵预构建偏重、首屏无性能埋点，页头「查看他人 / 刷新」顺序与刷新误触体验也不理想。

## 要做什么

1. **日程卡片 UI**：高级简约，与课程卡同体系但可区分（浅底、细边、弱图标，避免厚重阴影）。
2. **冲突叠卡 + 翻牌**：允许日程时间与课程冲突；同格多卡（课程 + 若干日程）时默认优先展示课程；单击翻牌切换（翻卡牌动画）；双击打开当前正面详情；单卡无堆叠时单击直接开详情；重新进入课表 / 切周后再回该格时正面重置为课程优先。
3. **冲突添加入口**：有课格可长按 ActionSheet「添加日程」；课程详情可「在此时间添加日程」；日程表单提交时允许与课程时间重叠，不再因冲突拒绝。
4. **课程考勤**：签到 / 迟到 / 缺勤 / 请假；粒度 = 课程实例（courseId + 教学周 + 星期）；入口仅本人课程详情弹层；本地 MMKV + 远程 Node（course-ext 同轨 Outbox/Tombstone）；查看他人课表不可见、不拉取。本轮不做 Agent 考勤 tool。
5. **加载性能**：懒构建周矩阵（当前周 ±2），避免一次算全学期。
6. **首屏埋点**：`CourseScreen` mount → 当前周 `WeekGrid` 首次 layout；`perf` + `duration_ms`；仅本人课表、非 peer/diff。
7. **页头操作**：对调「查看他人课表」与「刷新课表」位置；刷新前用全局确认框确认。

## 不做

- Agent 考勤 tools / 快照卡片扩展（下轮）
- 上课提醒、海报、二维码分享
- 单周网格竖向虚拟化（5 行收益低，本期不做）
- 教务课编辑/屏蔽

## 验收直觉

- 日程卡看起来干净高级，一眼能和课程卡区分
- 同格冲突：默认见课程；点一下翻到日程；双击进详情；重进课表又回到课程正面
- 考勤只在自己的课程详情里；别人课表看不到
- 切周更跟手，进课表首帧不卡在「算完全部周」
- Track 能收到课表首屏 `perf` 耗时
- 刷新会先确认；按钮顺序为刷新在左、查看他人在右（或按实现对调后的最终顺序：原查看他人与刷新互换）
