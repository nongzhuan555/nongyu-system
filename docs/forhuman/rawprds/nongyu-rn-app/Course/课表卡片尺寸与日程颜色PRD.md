# 课表卡片尺寸与日程颜色（短 PRD）

| 项   | 内容                                          |
| ---- | --------------------------------------------- |
| 应用 | 农屿 RN App + Node course-ext                 |
| 类型 | **业务**                                      |
| 日期 | 2026-08-16                                    |
| 关联 | 课表交互 UI 功能系列优化；课表扩展-自定义日程 |

## 要做什么

1. **卡片尺寸**：中档、大档课程/日程行高适当减小（小档不动）；字号档不变。
2. **日程颜色**：新增/编辑日程时可从预设色板选色（或选无色）；颜色写入日程实体并本地 + 远程持久化。

## 不做

- 自由取色器、自定义 hex
- 本轮 Agent `course_schedule_*` 暴露颜色参数
- 技术方案文档（本需求跳过）
