# 课表期末默认考试安排（短 PRD）

| 项   | 内容                         |
| ---- | ---------------------------- |
| 应用 | 农屿 RN App                  |
| 类型 | **业务**                     |
| 日期 | 2026-08-16                   |
| 关联 | 课表模块 PRD；教务考试安排页 |

## 要做什么

1. 检测到本学期教务课已上完后，用户进入课表 Tab **默认展示考试安排**（本人）。
2. 提供按钮切回正常课表周视图；周视图下（仍满足已上完）可再切回考试。
3. 不影响查看他人课表 / Diff；不做他人考试。

## 不做

- 查看他人考试
- 持久化「用户偏好周视图」（离开 Tab 再进仍默认考试）
- 技术方案文档（本需求跳过）
