# 课表考勤：未考勤（nocheck）与卡片双信息（短 PRD）

| 项   | 内容                                                         |
| ---- | ------------------------------------------------------------ |
| 应用 | `nongyu-rn-app` + `nongyu-node-server`（course_attendances） |
| 类型 | **业务需求**                                                 |
| 日期 | 2026-08-16                                                   |
| 关联 | `课表交互UI功能系列优化PRD.md` 考勤增补                      |

## 背景

现有考勤四态（签到/迟到/缺勤/请假）无法表达「老师本节未点名」；「清除记录」文案偏弱；课程卡仅有学期异常汇总，看不到**本节**状态。

## 要做什么

1. 新增与四态平等的落库状态 **`nocheck`（未考勤）**：老师没有检查本节上课情况。
2. 详情考勤区：五态可切换；增加 **「重置」** 按钮，仅删除**本节**记录（`courseId + week + day`），不是整门课清空。
3. 本人课程卡一行同时展示：**本节短标签**（有记录才显示）+ **学期汇总**（含未考勤次数；不含签到次数）。
4. Node：`status` 枚举 / CHECK / Zod 同步支持 `nocheck`。

## 不做

- Agent 考勤 tools
- 考勤统计报表页
- 按课程批量重置全学期考勤
