# 课表桌面小组件（短 PRD）

| 项   | 内容                                                                    |
| ---- | ----------------------------------------------------------------------- |
| 应用 | 农屿 RN App                                                             |
| 类型 | **基建**                                                                |
| 日期 | 2026-08-16                                                              |
| 关联 | 课表模块；课表期末默认考试安排；底部导航；登录门禁；旧版 Android Widget |

## 要做什么

1. Android 桌面小组件：学期未结束时，实时展示用户**下一节**或**正在上**的一堂课（教务课 + 自定义日程）；布局与旧版卡片接近；状态标签「即将上课 / 正在上课」；今日课已上完则显示「今天的课已经上完」。
2. 本学期教务课全部上完后，小组件改展示考试：即将考 / 正在考；当天考试结束后展示下一场（可跨天）；全部考完文案「本学期结束，下学期再见」；考试文字缩小以保证完整。
3. 约每 10 分钟刷新展示；课表/考试数据变更时立即同步。
4. 点击小组件打开农屿 App，并切到课表 Tab（`/(tabs)/course`）。

## 不做

- iOS 小组件
- 多尺寸 / 多 Widget / 独立 Widget 设置页 / 深色主题跟随
- 点击仅刷新不进 App
- 技术方案文档（本需求跳过，除非后续要求）
