# 课表共享与 Diff（短 PRD）

| 项   | 内容                                                 |
| ---- | ---------------------------------------------------- |
| 应用 | 农屿 RN App                                          |
| 类型 | 业务需求                                             |
| 日期 | 2026-08-15                                           |
| 关联 | 课表模块 PRD「分享课表」的细化落地（本期不做二维码） |

## 背景

用户想远程看同学课表、对比有没有空档，截图来回传很麻烦。系统应支持在对方同意的前提下，用学号查到对方**原始课表**，并在周视图上直观对比差异。

## 要做什么

1. **共享开关**：用户可在课表设置中开启「允许课表共享」；开启后把本人**原始课表**上传到远端一份；关闭后远端不可查且删除远端副本。
2. **查看他人课表**：课表处可输入学号查找；仅能拿到对方原始课表（不含备注、待办、自定义日程）；以只读周视图查看。
3. **Diff**：在查看他人课表时，可一键对比自己与对方课表（同网格叠色）；支持「冲突叠色」与「空闲交集」两种模式。
4. **Agent**：用户可用自然语言对比某学号课表（如「帮我对比一下某某学号的课表，找出我们错开的课」）；Agent 只读调用共享查找 + Diff，对话内出对比卡片，可跳转课表打开对比。不开/关共享。

## 不做

- 二维码分享、海报导出（查看他人时）
- 历史学期快照、昵称体系
- 共享备注/待办/自定义日程
- 通过 Agent 开启或关闭课表共享

## 验收直觉

- 未开共享的人：别人用学号查不到
- 开了共享：别人能按学号看到只读周课表，且看不到对方的自定义数据
- Diff 能一眼看出「谁有课 / 谁没空 / 是否撞课」
