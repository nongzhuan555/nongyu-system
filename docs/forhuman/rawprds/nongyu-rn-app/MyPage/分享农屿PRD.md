## 要做什么

在「我的 → 分享农屿」打开分享面板，支持：

1. 分享到微信好友（网页分享）
2. 分享到朋友圈（网页分享）
3. 复制官网链接

分享落地页：`https://nongyu-app.github.io/index.html`。

## 已确认决策

1. 入口：仅「我的」更多服务「分享农屿」；课表不挂 App 分享
2. 能力：微信好友 + 朋友圈 + 复制链接；**不做**海报、系统分享
3. 文案与缩略图沿用旧版网页分享（标题 / 描述 / App icon）
4. 平台：本期以 **Android** 为主验收；iOS Universal Link 可后续补齐，但代码侧应预留 `registerApp` 配置
5. 沿用现有微信开放平台移动应用（包名 `com.nongyu.app`）；签名变更时在开放平台更新，不重新申请 App
6. 不写独立技术选型长文；Spec 确认后直接编码

## 非目标

- 生成海报 / 截屏 / 保存相册
- 系统分享面板
- 课表页 App 分享入口
- 微信登录 / 支付 / 小程序分享
- Web Admin / Web Site
