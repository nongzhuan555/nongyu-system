# App 打开管理后台 PRD（草稿）

> 来源：需求澄清对话（2026-08-16）。跨 RN App / Node / Web Admin。

## 要做什么

管理员在「我的 → 更多服务」看到「农屿管理台」入口；点击后按系统「网页跳转」偏好打开 Web 管理后台，并自动完成管理端登录，无需再输入管理员密码。

## 为什么

管理员已在 App 登录且具备 `role=1`，再让其手输农屿管理员密码体验差。远程库只存密码哈希，不能「抓明文密码」，因此用 App 会话换短时票据完成 handoff。

## 范围

- RN：条件渲染入口；点击申请 ticket；`openAppUrl` 打开管理端。
- Node：App JWT → 短时单次 ticket；ticket → Admin 会话。
- Web Admin：识别 `loginType=in_app` + `ticket` 后自动登录进入工作台。

## 不做

- 本地存储管理员密码 / 设置页改密（与本需求无关的自助改密仍按原 Spec）。
- 非管理员展示入口。
- 超管未建档 bootstrap 会话的 handoff（仅已建档且 `role=1`）。

## 关键约定（产品）

| 项          | 约定                                                                           |
| ----------- | ------------------------------------------------------------------------------ |
| 入口文案    | 农屿管理台                                                                     |
| 展示条件    | 已登录且 `role === 1`                                                          |
| 打开方式    | **强制应用内 WebView**（不受全局「网页跳转」偏好影响；防 ticket 进外置浏览器） |
| 管理端地址  | `https://nongyu.site/admin`（现网可为部署 IP）                                 |
| 登录方式    | 一次性 ticket **经 WebView 注入**自动登录；**禁止** ticket 出现在 URL          |
| `loginType` | 复用已有 `in_app`                                                              |

## 联调期望

管理员点入口 → 短暂 loading → **应用内 WebView** 打开管理台 → 已登录工作台。失败时 App Toast 说明原因。外置浏览器打开管理端链接不得免密登录。
