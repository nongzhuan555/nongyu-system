| 需求分类 | 业务需求                                                                      |
| 关联     | `docs/forhuman/rawprds/nongyu-rn-app/Center/广场回复与留言PRD.md`（既有能力） |

---

## 1. 背景

广场回复 / 留言能力（反馈墙管理员回复、大院顶层匿名留言、前台 toast 轮询、「我的帖子」角标）已落地。用户除 toast 点进帖子详情、或从「我的帖子」进详情外，**缺少「我的」页内对留言历史的固定入口**：无法方便回看「我对他人帖子的留言」与「他人对我帖子的留言 / 管理员回复」。

## 2. 需求概述

### 2.1 「我的」入口

- 「更多服务」在「我的帖子」旁增加入口：**「留言与回复」**。
- 进入后为单页双 Tab：
  - **收到的**：他人对我帖子的留言 + 管理员对我反馈帖的回复（按回复时间倒序 inbox）。
  - **我发出的**：我对他人大院帖子的留言（仅 `comment`，不含自己帖下的自留言）。
- 默认 Tab：**收到的**。
- 本期不做入口未读角标（新回复感知仍靠既有 toast）。

### 2.2 列表与跳转

- 列表项展示：帖标题 + 内容摘要（约 80 字截断）+ 时间；「收到的」另有类型标签（「管理员回复」/「留言」）。
- 大院留言场景继续匿名：不展示留言者任何身份。
- 点击列表项进入对应帖子详情。
- 「我发出的」支持列表内删除（二次确认，复用既有删留言接口）。

### 2.3 后端

- 新增分页列表接口（发出 / 收到）；仅返回帖子与回复均未软删的记录。
- 不改 Admin；不改表结构（复用 `post_replies`）。

## 3. 澄清结论（grill）

| 项           | 结论                                       |
| ------------ | ------------------------------------------ |
| 需求分类     | 业务需求                                   |
| 入口形态     | 单一入口「留言与回复」+ 页内双 Tab         |
| 收到的语义   | 全量历史 inbox（按回复时间倒序），非仅未读 |
| 我发出的范围 | 仅大院 `comment`，且目标帖作者 ≠ 当前用户  |
| 列表删除     | 「我发出的」可删（二次确认）               |
| 软删过滤     | 帖或回复任一软删则不出现在列表             |
| 未读角标     | 本期不做                                   |
| 涉及端       | Node + RN；Admin 不动                      |
| 文档流程     | 新建 PRD → Spec → 跳过 tech → plan → 编码  |

## 4. 非目标（本期不做）

- 不做推送、未读角标、未读数接口。
- 不做楼中楼、点赞、举报、富文本、图片。
- 不做公告墙回复相关入口。
- 不做「收到的」列表内删除（管理员回复 / 他人留言不可由用户在 inbox 删）。
- 不做 Admin 变更；不做新表 / 迁移。
