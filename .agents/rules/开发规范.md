# 开发规范

## 宪法规范

- 本项目严格遵循SDD（规格驱动开发）规范，严禁Agent在没有相关文档作为开发依据的情况下，生成任何代码。
  具体SDD规范请参考./agents/rules/sdd-guidelines.md。
- 凡有Bug修复、需求调整、效果优化、新需求开发等一切需改动代码的场景和需求时，都必须保证先同步文档修改再实际改动代码，严格贯彻文档先行的策略
- 所有代码都必须符合TypeScript规范，包括但不限于接口定义、类定义、函数定义等。
- 所有代码都必须符合ES6规范，包括但不限于变量定义、函数定义、类定义等。
- 人类必须参与技术方案的设计和实现，包括但不限于数据库设计、API设计、前端设计等，Agent作为决策辅助。
- 代码应该符合工程化实践。
- 代码附近必须包含必要的中文注释，包括但不限于函数、类、接口等。
- 变量名必须符合驼峰命名法，包括但不限于函数参数、循环变量、条件判断变量等。

## 工程化约束

- 每次代码改动后必须通过 oxlint 检查，确保代码质量，运行`pnpm lint`命令，如果 oxlint 检查失败，必须修复 oxlint 报错，运行`pnpm lint:fix`命令。
- 每次代码改动后必须通过 TypeScript 检查，确保代码类型安全，运行`pnpm type-check`命令。
- 每次代码改动后必须通过 oxfmt 格式化工具，确保代码格式一致，运行`pnpm format`命令。

## Code Review约束

三层门禁，**开发者操作顺序**如下（勿颠倒）：

1. **完成改动**（可选：本地先跑 `pnpm lint` / `pnpm type-check` / `pnpm format`；未跑则依赖下一步 husky）
2. **AI Review（软门禁）** — **每次 `git commit` 之前**由开发者显式触发
   - **主入口**：调用专家 subagent `code-reviewer`（`C:\Users\TANGLEI\.cursor\agents\code-reviewer.md`）
   - 标准：仓库 `.cursor/BUGBOT.md` + 改动路径对应的项目 Skills（Web→`vercel-react-best-practices`，RN→`react-native-best-practices`，Node→`nodejs-backend-patterns`，Go→`golang-*`，Schema→`database-schema-designer`，Seed→`db-seed`）
   - **只审**：逻辑、安全、数据/鉴权、Skills 中 CRITICAL/HIGH 级性能与架构问题
   - **不审**：基础语法、格式、可由 oxlint/oxfmt/TypeScript 处理的风格问题（交给 husky）
   - Cursor **无官方 hook 保证**本步一定执行；漏跑风险自负。可选补充：本地 `/review` 或 PR Bugbot（同一套 `BUGBOT.md`）
   - 存在 **Critical**（安全、数据损坏、鉴权绕过、明确逻辑错误等）时，**必须先修复再 commit**
3. **`git commit` → husky（硬门禁）** — commit 时自动触发
   - pre-commit：`lint-staged`（oxlint + oxfmt）
   - commit-msg：commitlint
   - 负责较底层的语法、格式、代码风格；**不负责**业务对错与 Skill 级架构/性能审查
4. **人工审核（硬门禁）** — 合入前由人确认 Spec/业务意图、架构、权限与数据风险；不重复抠 AI/husky 已覆盖的格式与清单项

说明：系统只能硬保证 husky（及团队若启用的 PR 检查）；AI Review 依赖显式调用 `code-reviewer`。

## 协作规范

- 本版本开发暂时为仅一人团队，无实际团队协作开发
- 无PR/MR流程，代码直接在本地或远程仓库进行merge操作即可，如有冲突需人为解决
- 分支操作规范为：通用代码、文档以及全局基础建设、项目初始化等操作直接在主分支进行，其他具体项目的业务开发必须在对应的项目分支上进行，一般一个功能或一个页面为一个提交，需合并代码时直接往主分支合并即可，主分支可改动项目代码文件夹，如项目初始化或基础建设开发，但严格禁止反过来在项目分支改动全局性质的代码

## Agent编码规范

- 严格遵循.agents\skills\sdd-guidelines\SKILL.md
- 代码发现与检索严格遵循 `.agents/rules/代码检索策略.md`（CodeGraph 与 Cursor Grep/Glob/Read 的选用顺序）
